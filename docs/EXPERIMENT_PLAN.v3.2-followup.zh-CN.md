# v3.2 追加机制实验

日期：2026-10-13。协议：`jev-chunk-depth-v3.2-followup`。

本实验按用户指定的顺序补齐两个交叉评价、核验并复用已完成的冻结 SCHED-A 读出、执行 E-G/E-C 匹配训练。v3.2 阶段一未通过放行门槛的结论保留。本实验研究加入控制梯度后的变化，不据此宣布原协议进入正式实验。

## 1. 固定日程的交叉评价

令两组 LoRA 为 θS 与 θE，其各自已校准的位置日程为 πS 与 πE。已有对角线 L(θS,πS)、L(θE,πE)。补测 L(θE,πS)、L(θS,πE)，日程参数及文档混合权重均取 v3.1 已保存结果。

固定日程下比较 L(θE,π)-L(θS,π)。同一文档执行深度相同，成本相同。逐文档配对 bootstrap 10,000 次，报告均值与双侧 95% 区间。原 505 篇先导筛选集在此作为开发诊断集。

## 2. 已完成的读出实验

v3.2 已在冻结 θS 上训练标准化线性读出，λ=1、γ=0.01、τ=0.05。主读出相对位置日程的筛选效应为约 0.0038 nat/token，未通过门槛。复用其 head.pt，逐项核验文件哈希、参数维度、有限性与现有回执。复用不等于新增独立重复实验。

## 3. 匹配训练

两臂共同初始化为 θS，读出为上述 head.pt，读出参数冻结。这个初始化与原 v3.2 阶段二的零 LoRA 设定不同。研究对象是已经适配的生成模型继续训练时，控制梯度对生成和路由的总影响。

两臂使用同一批 373 篇文档、种子 17、相同文档排列，训练两轮，有效批量 8，执行 93 次更新。AdamW 学习率由 10⁻⁴ 余弦下降至 10⁻⁵，预热 5%，权重衰减 0.01，梯度裁剪阈值 1。两臂均从新的优化器状态开始。

生成目标为 G = ΣcΣd stopgrad(p_cd)L_cd / N。E-G 只优化 G；E-C 增加当前行期望成本及辅助目标：0.1 CE(s,p)、0.01 Brier、0.1 KL(p||p_ref)。参考分布固定为初始 θS 在各上一行深度下的输出。KV 修正沿用 κs=0.013、κe=−0.00228。

历史深度按各臂当前策略无梯度抽样，抽样种子规则相同。后续策略随参数分化是控制目标总效应的一部分。本实验不把训练梯度解释为顺序总回报的无偏梯度。

## 4. 评价与判据

使用桶 75–77、85–89 的 612 篇文档校准。分别为两臂扫描 b∈[−20,20]，步长 0.05，查表仅用于候选筛选；最终用在线执行的预算两侧策略计算混合权重。校准参数保存后才打开桶 95–99 的 378 篇筛选文档。

主差值为 g_joint = L(E-G,πEG)−L(E-C,πEC)。附加固定日程比较 h_gen = L(E-C,πR)−L(E-G,πR)，πR 取已有 v3.2 的 R.pt 和已保存混合权重，两臂完全相同。

诊断达到门槛要求：筛选集成本比在 [0.98,1.02]，g_joint≥0.005 nat/token，单侧 90% bootstrap 下界大于零。无论结果如何，原阶段一不放行记录保留。官方测试集不使用。

## 5. 梯度诊断与资源

在 E-G 更新前的 0、23、46、92 步保存 LoRA 和完整优化器状态。固定预热集前八篇，组成四个两篇批次，分别测生成与控制梯度、范数及内积。在相同优化器状态上构造仅生成和联合目标的一步更新，报告参数位移与固定代理生成损失的实际变化。诊断后恢复原参数与优化器状态。

全部新增运行上限为 8 GPU 小时。复用旧特征及检查点，新增结果写入 `results/chunk-depth-v32-followup/`，参数和逐篇结果写入 `artifacts/chunk-depth-v32-followup/`。每份回执记录协议配置、代码与输入文件哈希。
