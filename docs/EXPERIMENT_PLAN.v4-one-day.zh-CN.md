# v4 两亿 token 训练与一天实验方案

本方案采用[新版 v4 架构](ARCHITECTURE.v4.zh-CN.md)：Qwen3-30B-A3B-Instruct-2507，32 层共享前缀、12 层循环段、两个四层生成尾，以 $R_4/H_4$ 为主要控制器。每条生成训练臂固定训练 2 亿 token，单随机种子，目标是在 8 张 H200 上用约 24 小时完成一次先导实验。

24 小时从模型、数据与执行器就绪后上机计时。旧版 27B 混合注意力与工具路由计划使用另一套结构和成本；本方案的执行依据为上述新版架构与[数学附录](ARCHITECTURE_MATH.v4.zh-CN.md)。

## 1. 两条生成训练臂

| 项目 | $G_{\rm loop}$ | $G_{\rm plain}$ |
|---|---|---|
| 生成结构 | 首轮冻结，按行执行 1–4 轮，追加轮次使用共享 LoRA | 第 32–43 层执行一次，并在这次前向使用 LoRA |
| 生成尾 | 两套四层 LoRA 尾 | 相同结构与秩的两套尾 |
| 可训练参数 | 351,602,688 | 351,600,640 |
| 训练量 | 200,000,000 token | 200,000,000 token |
| 数据与随机性 | 相同数据顺序、分词、初始化种子和尾分配 | 与左列相同 |
| 控制器 | 生成训练后在同一冻结检查点上拟合 $R/H$ | 默认固定 $T_0$ 评价，作为生成质量参考 |

参数差额仅为 2048 维混合系数。两臂的 LoRA 形状与秩相同；循环臂重复调用共享参数，训练 FLOPs 高于单次前向臂。因此本比较控制数据机会和适配容量，另行报告两臂训练 FLOPs 与墙钟。

2 亿 token 按累计实际处理的非填充输入 token 计数，不乘循环次数，不计控制标签的候选重复计算。监督目标 token 数、独立文档数及每篇重复次数分别记录。最后一个批次通过填充和损失掩码精确达到目标，不把预算取整成较小值。

序列长度固定 4096；短文档拼接时按文档隔离注意力与行级状态。采用 BF16 激活、秩 16、缩放 32、零 LoRA 输出初始化、零混合初始化、无随机失活及激活重算。两臂都使用 AdamW，学习率从零经前 5% 更新升至 $10^{-4}$，随后余弦降至 $10^{-5}$；LoRA 权重衰减 0.01，混合系数衰减为零，梯度范数裁剪阈值为 1。全局有效输入批量以 131,072 token 为起点，显存短跑后只通过梯度累积调整批量组织。

## 2. 两尾分工与数据角色

生成训练的输入 token 配额为通用文本 1 亿、数学解答 1 亿。数学样本保留题目、完整解答与最终答案；问题部分参与前向，解答部分提供生成监督。数据清单、版本、去重和长度处理在上机前锁定。

通用文本使用 $T_0$。数学解答按行哈希均衡分配到 $T_0/T_1$；同一行的全部预测使用同一个尾，实际监督 token 份额另外统计。$T_0$ 因而接受通用与数学监督，$T_1$ 接受数学监督。领域标签只用于训练分配；部署控制器读取合法文本与执行状态。尾的专长由验证数据测量。

循环次数在训练中按行均衡覆盖 1–4，深度日程由固定种子和样本、行标识决定。$G_{\rm plain}$ 使用完全相同的输入和尾分配，执行一次适配循环段。

数据分成生成训练、控制拟合、预算校准、独立评价四种角色。文档及其重复版本按同组处理。已有 GSM8K 原始文本可作为复用基准；Qwen 重新分词，并保留最终答案。已参与 v3.3 分析的数据只报告为复用基准，新确认集在训练、拟合与校准之外预先锁定。预训练污染与本实验划分隔离分别报告。

## 3. 控制器迁移

每条生成训练臂只执行一次。$R_4/H_4$ 都使用同一个冻结的 $G_{\rm loop}$ 检查点，其比较只改变损失预测器可见的输入特征。岭回归拟合、候选评分和价格校准的 token 与运算量单列，不包含在每臂 2 亿 token 内。

迁移按两个协议依次进行：

1. 固定 $T_0$，动作仅为四种循环次数。以四动作历史采集标签并拟合 $R/H$，测量循环调度与首轮表示的作用。
2. 开放 $T_0/T_1$，动作扩展为八个联合选择。在包含尾切换的历史下采集新标签，重新拟合 $R/H$，评价新增尾的可访问性与路由收益。

两个协议复用同一个双尾生成检查点。该比较衡量开放第二个尾后的部署收益；第二尾训练已经通过共享循环参数影响生成器，因此它不单独隔离第二尾训练的作用。

控制拟合阶段以原始目标行 token 合计最多 200 万为初始配额：四动作协议 100 万、八动作协议 100 万。每条参考行从同一个边界快照评估全部合法动作，两个协议最多产生约 1200 万候选目标 token 的评分工作。读取提示词、推进历史、克隆、保存、重复行计算和校准执行全部另计。

标签历史的采样规则按文档哈希固定：一半文档随机选择一个合法动作并整篇沿用，另一半文档在每行均匀选择合法动作。每次评分后提交采样规则指定的动作；候选损失不参与提交选择。四动作协议的尾始终为 $T_0$，八动作协议覆盖两尾。完整轨迹校准检验这些采样历史与部署历史之间的差异。

$R/H$ 使用相同的行表、文档权重和交叉验证折；每折标准化参数只从训练部分估计。共享成本预测器只读取 26 维执行状态，已知追赶与补写费用从完整缓存元数据直接计算。旧 Huginn 表示、LoRA、岭回归系数、覆盖修正系数和预算比例全部在 Qwen 上重建。

$D_4$ 为可选额外计算对照，使用相同生成检查点和候选标签。其分支 LoRA、输入梯度处理、每 token 四层费用和部署价格均独立记录。一天内先完成 $R/H$ 主比较，余量再用于 $D_4$。

## 4. 评价与结论

教师强制主评价比较各协议下的均匀深度 $U$、$R_4$ 和 $H_4$。$U$ 以固定 $T_0$ 的深度 1–4 构成成本曲线。分别报告 $U-R$、$R-H$ 以及开放第二尾前后的差值。

所有预算价格在校准集完整执行后锁定。各策略族用实际成本形成共同可达预算，按文档随机混合相邻策略作同成本插值；每次文档 bootstrap 重算成本、夹逼与混合权重。夹逼失败时报告不可估。主指标为文档等权 NLL，另报 token 加权 NLL。行总 NLL 回归属于局部选择代理。

自由生成使用同一组题目，默认 128 题，每题输出上限 512 token；预算允许时扩至 256 题。保留七个设置：原基座、$G_{\rm plain}$、均匀深度、单尾 $R_4$、单尾 $H_4$、双尾 $R_4$、双尾 $H_4$。报告逐题正确率差、配对置信区间、长度、截断比例和实际成本；教师强制校准后的价格在自由生成阶段保持固定，并报告其成本偏移。

NLL 评价题数和每族价格端点数由短跑吞吐锁定，优先保留共同预算两侧的策略。自由生成题目顺序在运行前固定，各设置覆盖相同题目。单种子结果属于先导；样本量与置信区间共同限定结论强度。

比较同一生成结构的不同检查点时，另用相同的每行 $(r,e)$ 序列执行，分离参数更新与策略变化。跨 $G_{\rm loop}/G_{\rm plain}$ 比较时，保持相同输入和尾分配，分别使用各自合法执行路径并记录实际成本；共同的单轮对照固定 $r=1$，此时两者在循环段是否启用 LoRA 上仍有差异。旧 v3.3 的独立优化器诊断作为机制依据保留；当前冻结生成器的读出拟合直接实现梯度隔离。

## 5. 固定两亿 token 的吞吐条件

设 $v_{\rm loop},v_{\rm plain}$ 为 8 卡合计的实测输入 token/s，测量包含同步，并摊入检查点保存与数据读取。两臂固定训练量所需时间为

$$
T_{\rm train}
=\frac{2\times10^8}{v_{\rm loop}}
+\frac{2\times10^8}{v_{\rm plain}}.
$$

为 10 小时训练槽留 20% 余量，准入条件是

$$
T_{\rm train}\le0.8\times10\times3600=28\,800\ {\rm s}.
$$

| 两臂吞吐，token/s | 两臂计算时长 | 10 小时槽的判断 |
|---|---:|---|
| 5000 / 8000 | 18.06 小时 | 超出训练槽 |
| 10,000 / 16,000 | 9.03 小时 | 可放入，但未满足 20% 余量 |
| 两臂同为 13,889 | 约 8 小时 | 满足余量条件 |

序列 4096、冻结基座、双尾都计算及激活重算的保守矩阵乘账本给出：$G_{\rm plain}$ 约 15.69 GF/token；$G_{\rm loop}$ 平均 2.5 轮约 20.37 GF/token，全四轮约 29.13 GF/token。该估算只用于短跑前排期，实际准入采用上式的实测吞吐。

R/H 主路线按需执行生成尾；它们的训练阶段不运行 D。循环与混合专家的调度、补写、重算和通信影响实际速度，FLOPs 比例只用于核对执行成本。

## 6. 二十四小时安排

| 时段 | 工作 | 完成条件 |
|---|---|---|
| 0–6 小时 | 上机核验、等价性与梯度检查、显存与吞吐短跑 | 核心正确性通过，实测两臂训练预算与候选评分吞吐 |
| 6–16 小时 | 两条生成训练臂 | 每臂完成 2 亿 token 并锁定检查点 |
| 16–18 小时 | 同历史候选标签、R/H 拟合与预算校准 | 四动作、八动作均使用真实历史，读出与价格锁定 |
| 18–22 小时 | NLL 与自由生成配对评价 | 保留核心对照和同一组评价题目 |
| 22–24 小时 | 核验、保存、报告与必要余量 | 输出检查点、逐篇指标、成本与阶段完成记录 |

全流程约束为 $T_{\rm 核验}+T_{\rm 训练}+T_{\rm 标签与校准}+T_{\rm 评价}+T_{\rm 汇总}\le24$ 小时。训练吞吐准入只约束其中一项；短跑还须估计全部候选评分、完整轨迹校准和七设置评价的总时间。控制样本配额与共同评价题数据此锁定，两个协议均保留同历史标签和 R/H 对照。

吞吐不足时，优先延期 $D_4$、256 题扩展及额外价格端点。缩减评价量时保持各策略相同的题目集合，保留共同预算所需的夹逼端点。两臂各 2 亿 token 为固定要求，价格读出 $R/H$ 和均匀深度对照为核心比较。

若上述缩减仍无法满足 24 小时，就报告预计延长时间并保留固定训练量。第 22 小时停止新增可选实验；到时尚未完成的核心阶段如实记录。数值异常或正确性检查失败时保存状态并停止相应阶段，成功完成的检查不能替代未通过的检查。
