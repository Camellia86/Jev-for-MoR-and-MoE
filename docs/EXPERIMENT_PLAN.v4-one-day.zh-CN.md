# v4 两亿 token 训练与一天实验方案

协议 ID 为 `jev-v4-rowloop`，状态为设计定稿、待实现执行器（2026-10-15）。机器可读配置见 [`EXPERIMENT_CONFIG.v4-rowloop.json`](EXPERIMENT_CONFIG.v4-rowloop.json)；第 4 节的门槛、判据与样本量依据见[实验依据审核](ARCHITECTURE_REVIEW.v4.zh-CN.md)。

本方案采用[新版 v4 架构](ARCHITECTURE.v4.zh-CN.md)：Qwen3-30B-A3B-Instruct-2507，32 层共享前缀、12 层循环段、两个四层生成尾，以 $R_4/H_4$ 为主要控制器。每条生成训练臂固定训练 2 亿 token，单随机种子，目标是在 8 张 H200 上用约 24 小时完成一次先导实验。

24 小时从模型、数据与执行器就绪后上机计时。旧版 27B 混合注意力与工具路由计划使用另一套结构和成本；本方案的执行依据为上述新版架构与[数学附录](ARCHITECTURE_MATH.v4.zh-CN.md)。

## 1. 两条生成训练臂

| 项目 | $G_{\rm loop}$ | $G_{\rm plain}$ |
|---|---|---|
| 生成结构 | 首轮冻结，按行执行 1–4 轮，追加轮次使用共享 LoRA | 第 32–43 层执行一次，并在这次前向使用 LoRA |
| 生成尾 | 两套四层 LoRA 尾 | 相同结构与秩的两套尾 |
| 可训练参数 | 351,602,688 | 351,600,640 |
| 训练量 | 200,000,000 token | 200,000,000 token |
| 数据与随机性 | 相同数据顺序、分词、初始化种子和尾分配 | 与左列相同 |
| 控制器 | 生成训练后在同一冻结检查点上拟合 $R/H$ | 默认固定 $T_0$ 评价，作为生成质量参考 |

参数差额仅为 2048 维混合系数。两臂的 LoRA 形状与秩相同；循环臂重复调用共享参数，训练 FLOPs 高于单次前向臂。因此本比较控制数据机会和适配容量，另行报告两臂训练 FLOPs 与墙钟。

2 亿 token 按累计实际处理的非填充输入 token 计数，不乘循环次数，不计控制标签的候选重复计算。监督目标 token 数、独立文档数及每篇重复次数分别记录。最后一个批次通过填充和损失掩码精确达到目标，不把预算取整成较小值。

序列长度固定 4096；短文档拼接时按文档隔离注意力与行级状态。采用 BF16 激活、秩 16、缩放 32、零 LoRA 输出初始化、零混合初始化、无随机失活及激活重算。两臂都使用 AdamW，学习率从零经前 5% 更新升至 $10^{-4}$，随后余弦降至 $10^{-5}$；LoRA 权重衰减 0.01，混合系数衰减为零，梯度范数裁剪阈值为 1。全局有效输入批量以 131,072 token 为起点，显存短跑后只通过梯度累积调整批量组织。

## 2. 两尾分工与数据角色

生成训练的输入 token 配额为通用文本 1 亿、数学解答 1 亿。数学样本保留题目、完整解答与最终答案；问题部分参与前向，解答部分提供生成监督。数据清单、版本、去重和长度处理在上机前锁定。

通用文本使用 $T_0$。数学解答按行哈希均衡分配到 $T_0/T_1$；同一行的全部预测使用同一个尾，实际监督 token 份额另外统计。$T_0$ 因而接受通用与数学监督，$T_1$ 接受数学监督。领域标签只用于训练分配；部署控制器读取合法文本与执行状态。尾的专长由验证数据测量。

循环次数在训练中按行均衡覆盖 1–4，深度日程由固定种子和样本、行标识决定。$G_{\rm plain}$ 使用完全相同的输入和尾分配，执行一次适配循环段。

数据分成生成训练、控制拟合、预算校准、独立评价四种角色。文档及其重复版本按同组处理。已有 GSM8K 原始文本可作为复用基准；Qwen 重新分词，并保留最终答案。已参与 v3.3 分析的数据只报告为复用基准，新确认集在训练、拟合与校准之外预先锁定。预训练污染与本实验划分隔离分别报告。

## 3. 控制器迁移

每条生成训练臂只执行一次。$R_4/H_4$ 都使用同一个冻结的 $G_{\rm loop}$ 检查点，其比较只改变损失预测器可见的输入特征。岭回归拟合、候选评分和价格校准的 token 与运算量单列，不包含在每臂 2 亿 token 内。

迁移按两个协议依次进行：

1. 固定 $T_0$，动作仅为四种循环次数。以四动作历史采集标签并拟合 $R/H$，测量循环调度与首轮表示的作用。
2. 开放 $T_0/T_1$，动作扩展为八个联合选择。在包含尾切换的历史下采集新标签，重新拟合 $R/H$，评价新增尾的可访问性与路由收益。

两个协议复用同一个双尾生成检查点。该比较衡量开放第二个尾后的部署收益；第二尾训练已经通过共享循环参数影响生成器，因此它不单独隔离第二尾训练的作用。

控制拟合阶段以原始目标行 token 合计最多 200 万为初始配额：四动作协议 100 万、八动作协议 100 万。每条参考行从同一个边界快照评估全部合法动作，两个协议最多产生约 1200 万候选目标 token 的评分工作。读取提示词、推进历史、克隆、保存、重复行计算和校准执行全部另计。

标签历史的采样规则按文档哈希固定：一半文档随机选择一个合法动作并整篇沿用，另一半文档在每行均匀选择合法动作。每次评分后提交采样规则指定的动作；候选损失不参与提交选择。四动作协议的尾始终为 $T_0$，八动作协议覆盖两尾。完整轨迹校准检验这些采样历史与部署历史之间的差异。

$R/H$ 使用相同的行表、文档权重和交叉验证折；每折标准化参数只从训练部分估计。共享成本预测器只读取 26 维执行状态，已知追赶与补写费用从完整缓存元数据直接计算。旧 Huginn 表示、LoRA、岭回归系数、覆盖修正系数和预算比例全部在 Qwen 上重建。

$D_4$ 为额外计算对照，分 D-reg 与 D-ec 两个变体，使用相同生成检查点和候选标签。D-reg 与 $R/H$ 使用相同的损失回归目标与部署规则，D-ec 使用带熵正则的期望代价目标（[架构正文](ARCHITECTURE.v4.zh-CN.md)第 6 节）。其分支 LoRA、输入梯度处理、每 token 四层费用和部署价格均独立记录。一天内先完成 $R/H$ 主比较，再运行两个 D 变体。第一轮中 D 只做教师强制 NLL 评价，不进入自由生成。吞吐不足时按第 6 节的顺序延期，D 排在 256 题自由生成扩展之后。D 的训练设置见第 4.4 节。

## 4. 评价与结论

教师强制主评价比较各协议下的均匀深度 $U$、$R_4$、$H_4$，以及八动作协议下的 D-reg 与 D-ec。$U$ 以固定 $T_0$ 的深度 1–4 构成成本曲线。分别报告 $U-R$、$R-H$、$H$ 与 D-reg 之差、D-reg 与 D-ec 之差，以及开放第二尾前后的差值。

所有预算价格在校准集完整执行后锁定。各策略族用实际成本形成共同可达预算，按文档随机混合相邻策略作同成本插值；每次文档 bootstrap 重算成本、夹逼与混合权重。夹逼失败时报告不可估。主指标为文档等权 NLL，另报 token 加权 NLL。行总 NLL 回归属于局部选择代理。

自由生成使用同一组题目，默认 128 题，每题输出上限 512 token；预算允许时扩至 256 题。保留七个设置：原基座、$G_{\rm plain}$、均匀深度、单尾 $R_4$、单尾 $H_4$、双尾 $R_4$、双尾 $H_4$。报告逐题正确率差、配对置信区间、长度、截断比例和实际成本；教师强制校准后的价格在自由生成阶段保持固定，并报告其成本偏移。

NLL 评价篇数由第 4.3 节固定，每族价格端点按第 4.4 节选取，优先保留共同预算两侧的策略。自由生成题目顺序在运行前固定，各设置覆盖相同题目。单种子结果属于先导，结论限于这一次生成训练。

比较同一生成结构的不同检查点时，另用相同的每行 $(r,e)$ 序列执行，分离参数更新与策略变化。跨 $G_{\rm loop}/G_{\rm plain}$ 比较时，保持相同输入和尾分配，分别使用各自合法执行路径并记录实际成本；共同的单轮对照固定 $r=1$，此时两者在循环段是否启用 LoRA 上仍有差异。旧 v3.3 的独立优化器诊断作为机制依据保留；当前冻结生成器的读出拟合直接实现梯度隔离。

### 4.1 放行门槛

两道门槛在读取确认集之前判定，只使用拟合文档与校准文档。

GL1 检验不同深度之间是否存在 NLL 差异。在拟合文档上教师强制计算 $G_{\rm loop}$ 固定 $T_0$ 的均匀深度 NLL $L_U(r)$，$r=1,\ldots,4$，选出 $r^\ast=\arg\min_{r\ge2}L_U(r)$；再在校准文档上计算逐篇配对差 $L_U(1)-L_U(r^\ast)$ 的均值 $\Delta_{\rm loop}$。GL1 要求 $\Delta_{\rm loop}\ge0.005$，且文档 bootstrap 单侧 95% 下界大于零。$r\ge2$ 才启用循环 LoRA，$\Delta_{\rm loop}$ 同时包含额外轮次与循环 LoRA 的作用，所以 GL1 检验的是不同深度之间存在可分配的 NLL 差异；评价同时报告 $G_{\rm plain}$ 与 $G_{\rm loop}(r=1)$ 之差作对照。GL1 未通过时，不同深度在这一训练量下没有可分配的差异：停止控制器比较，只报告均匀深度曲线以及 $G_{\rm loop}$ 与 $G_{\rm plain}$ 的对照。

GL2 检验按行分配是否有空间。在校准文档的四动作标签表上，对每个候选预算 $B$ 计算可分配空间

$$
\Gamma(B)=L^{\rm tab}_U(B)-\sup_{\lambda\ge0}\left[O(\lambda)-\lambda B\right],
\qquad
O(\lambda)=\sum_cv_c\min_a\left[\ell_c(a)+\lambda C_c(a)\right],
$$

定义与证明见[数学验证](ARCHITECTURE_MATH.v4.zh-CN.md)第 14 节。$\Gamma(B)$ 是任何控制器在标签表上相对均匀深度改善的上界。主预算取使 $\Gamma(B)$ 最大的候选，并列取较小预算；GL2 要求所选预算处 $\Gamma(B)\ge0.005$。GL2 未通过时，控制器照常运行，但全部比较只报告估计与区间，不作确认性结论。

### 4.2 主比较与判定

两个主检验在主预算 $B$ 处以严格同成本计算，正值表示后者 NLL 更低：

1. P1：$g_{UR}=L_U(B)-L_R(B)$，衡量执行状态信息的分配价值。
2. P2：$g_{RH}=L_R(B)-L_H(B)$，衡量首轮表示的预测价值。

两者各自检验 $H_0:g\le0$，按 Holm 法在单侧 0.05 下控制族错误率：较小的 p 值对 0.025，通过后较大的 p 值对 0.05。p 值为文档 bootstrap 重采样中估计值不大于零的比例。P1、P2 在四动作协议上检验；八动作协议的同名比较只报告估计与区间。

以下比较只报告估计、单侧 95% 下界与双侧 95% 区间：

1. $H$ 对 D-reg：额外决策计算的净价值。
2. D-reg 对 D-ec：目标函数的作用。
3. 八动作对四动作：第二生成尾的可访问性。
4. $G_{\rm loop}$ 上在校准集锁定的主预算 $H$ 策略对 $G_{\rm plain}$：总效应；两者成本不同，同时报告 NLL 差与成本差。

每个比较按下表下结论。$\delta_{\min}=0.005$ nat/token 为实用门槛，$u$ 为双侧 95% 区间上端，$\ell$ 为单侧下界。P1、P2 的 $\ell$ 取 Holm 调整后的水平：p 值较小的一项用 2.5% 分位；另一项在前一项被拒绝时用 5% 分位，否则用 2.5% 分位。这样表中的“有增益”与 Holm 拒绝一致。其余比较的 $\ell$ 用 5% 分位。

| $\ell$ | $u$ | 结论 |
|---|---|---|
| $\ell\ge\delta_{\min}$ | 任意 | 有增益，达到门槛 |
| $0<\ell<\delta_{\min}$ | $u\ge\delta_{\min}$ | 有增益，是否达到门槛未确定 |
| $0<\ell<\delta_{\min}$ | $u<\delta_{\min}$ | 有增益，低于门槛 |
| $\ell\le0$ | $u<0$ | 后者 NLL 更高，区间整体在零以下 |
| $\ell\le0$ | $0\le u<\delta_{\min}$ | 未检出，增益低于门槛 |
| $\ell\le0$ | $u\ge\delta_{\min}$ | 未检出，门槛未确定 |

任一次重采样夹逼失败时，区间不可估，不下结论。单侧检出而双侧区间含零时（v3.3 实验 A 即属此类），报告中同时写出两种口径。每个比较另报相对改善 $g/L_U(B)$。

### 4.3 评价规模

确认文档至少 1,410 篇。这一数字按数学验证第 15 节计算：逐篇差标准差取 0.067，Holm 法下较小 p 值的水平为 0.025，真实效应 0.005 时功效 80%。若真实效应约为 0.002（v3.3 中 H 相对 R 的增益），1,410 篇下的检出概率约为 0.20，结论预期为“未检出”或“增益低于门槛”；这一点在运行前写明。

默认评价数据为 GSM8K 训练集，按 SHA256(UTF-8(`jev-v4-rowloop`) ‖ 0x00 ‖ UTF-8(题目原文)) 的 32 字节摘要作大端整数 mod 100 重新分桶（与 v3.1 `experiments/chunk_depth_v31/data.py` 的写法相同）：桶 0–44 为拟合，45–59 为校准，60–99 为确认，预计约 2,990 篇确认文档。评价缩减时，确认集按桶号从小到大保留，不少于 1,410 篇。控制拟合配额（每个协议至多 100 万目标 token）先用 GSM8K 拟合桶，不足部分由数学训练语料中预留、不参与生成训练的部分补足。GL2 所需的校准文档四动作标签另计，不占这一配额。GSM8K 测试集已在 v3.3 作过确认集，只作复用基准，单独报告。生成训练的数学数据须对上述评价文档做 13-gram 去污染。数据集的最终选择由用户确认（实验依据审核第 4.2 节）。

### 4.4 预算、网格与随机种子

成本取完整账本扣除提示词位置上所有策略共同执行的共享前缀与首轮前向，这与 v3.1–v3.3 不把题目段计入预算的做法一致；D 的逐 token 分支在提示词位置上的开销属于 D 族自身，仍然计入。成本单位取 $G_{\rm loop}$ 在同一文档上全部行取 $r=1$、尾 $T_0$ 时的这部分成本。按答案位置的层调用数估计，均匀深度 1–4 的相对成本约为 1、1.25、1.5、1.75；首行触发的提示词补写会使深层动作的相对成本略高，实际值由账本确定。候选预算为 1.125、1.25、1.375、1.5，按第 4.1 节的 $\Gamma(B)$ 选出主预算；超出均匀深度在校准集上实际成本范围的候选在读取确认集前剔除并记录。

岭系数网格以数学验证第 9.3 节的权重归一化 $\sum_i\omega_i=1$ 为基准：R 与成本头取 $\{10^{-6},\ldots,10^{1}\}$，H 与 D-reg 头取 $\{10^{-4},\ldots,10^{3}\}$，各 8 个十倍点。选中网格边缘时，向该侧扩展两个十倍点一次，然后锁定。交叉验证误差并列时取较小的岭系数。

每个策略族在校准集上按预测成本选 12 个价格，目标成本为 $B$ 加偏移 $\pm\{0.002,0.006,0.012,0.02,0.03,0.045\}$。在线执行后，若夹住 $B$ 的相邻两点实际成本相差超过 0.02，在校准阶段于两点之间补点，每族至多 4 个。确认集运行全部锁定的价格，不再追加。D 两个族的预测成本按含 D 逐 token 开销的完整账本计算；目标成本低于该族可达下限时截到下限，截断后重复的价格依次顺延到下一个未用的偏移，沿用 27B 计划的截断与顺延规则。D 族达不到某个候选预算时，该预算下 D 的比较记为不可估。

D 两个变体的训练使用 AdamW：学习率从零经前 5% 更新升至 $10^{-4}$，余弦降至 $10^{-5}$，权重衰减 0.01，梯度范数裁剪 1，对八动作控制集训练 3 遍，每步 32 篇文档，种子 17。拟合文档按文档哈希留出 10% 作验证集，取验证损失最低的检查点。D-ec 的训练价格 $\lambda_D$ 取 $H_4$ 已锁定的 12 个价格中预测成本最接近主预算的一个。

生成训练的初始化、数据顺序与深度、尾日程使用种子 17。行为策略的随机数生成器以 SHA256(UTF-8(`jev-v4-rowloop-behavior`) ‖ 0x00 ‖ UTF-8(文档标识) ‖ 0x00 ‖ UTF-8(`17`)) 前 8 字节的大端无符号整数为种子，与 v3.1 派生种子的写法相同。文档 bootstrap 重采样 10,000 次，种子 20261015。

## 5. 固定两亿 token 的吞吐条件

设 $v_{\rm loop},v_{\rm plain}$ 为 8 卡合计的实测输入 token/s，测量包含同步，并摊入检查点保存与数据读取。两臂固定训练量所需时间为

$$
T_{\rm train}
=\frac{2\times10^8}{v_{\rm loop}}
+\frac{2\times10^8}{v_{\rm plain}}.
$$

为 10 小时训练槽留 20% 余量，准入条件是

$$
T_{\rm train}\le0.8\times10\times3600=28\,800\ {\rm s}.
$$

| 两臂吞吐，token/s | 两臂计算时长 | 10 小时槽的判断 |
|---|---:|---|
| 5000 / 8000 | 18.06 小时 | 超出训练槽 |
| 10,000 / 16,000 | 9.03 小时 | 可放入，但未满足 20% 余量 |
| 两臂同为 13,889 | 约 8 小时 | 满足余量条件 |

序列 4096、冻结基座、双尾都计算及激活重算的保守矩阵乘账本给出：$G_{\rm plain}$ 约 15.69 GF/token；$G_{\rm loop}$ 平均 2.5 轮约 20.37 GF/token，全四轮约 29.13 GF/token。该估算只用于短跑前排期，实际准入采用上式的实测吞吐。

R/H 主路线按需执行生成尾；它们的训练阶段不运行 D。循环与混合专家的调度、补写、重算和通信影响实际速度，FLOPs 比例只用于核对执行成本。

## 6. 二十四小时安排

| 时段 | 工作 | 完成条件 |
|---|---|---|
| 0–6 小时 | 上机核验（[架构正文](ARCHITECTURE.v4.zh-CN.md)第 8.2 节的验收标准）、显存与吞吐短跑 | 验收通过，实测两臂训练吞吐与候选评分吞吐 |
| 6–16 小时 | 两条生成训练臂 | 每臂完成 2 亿 token 并锁定检查点 |
| 16–17 小时 | GL1：校准文档上的均匀深度曲线 | 判定 GL1；未通过时转入生成对照报告 |
| 17–18.5 小时 | 同历史候选标签、GL2 与主预算、R/H 与成本头拟合、价格校准 | 四动作、八动作均使用真实历史，读出与价格锁定 |
| 18.5–20 小时 | D-reg、D-ec 的表示缓存、训练与价格校准 | 两个变体的读出与价格锁定；吞吐不足时延期 |
| 20–23 小时 | NLL 与自由生成配对评价 | 保留核心对照和同一组评价文档 |
| 23–24 小时 | 核验、保存与报告 | 输出检查点、逐篇指标、成本与阶段完成记录 |

全流程约束为 $T_{\rm 核验}+T_{\rm 训练}+T_{\rm GL1}+T_{\rm 标签与校准}+T_{D}+T_{\rm 评价}+T_{\rm 汇总}\le24$ 小时。训练吞吐准入只约束其中一项；短跑还须估计全部候选评分、完整轨迹校准和七设置评价的总时间。控制样本配额与共同评价题数据此锁定，两个协议均保留同历史标签和 R/H 对照。

吞吐不足时依次延期 256 题自由生成扩展、D-ec、D-reg；仍不足时把每族价格点从 12 个减为偏移 ±{0.002, 0.006, 0.012} 的 6 个（补点照常），再缩减确认集，但不少于 1,410 篇。缩减评价量时保持各策略相同的文档集合，保留共同预算所需的夹逼端点。两臂各 2 亿 token 为固定要求，价格读出 $R/H$ 和均匀深度对照为核心比较。

若上述缩减仍无法满足 24 小时，就报告预计延长时间并保留固定训练量。第 20 小时停止新增可选实验；到时尚未完成的核心阶段如实记录。数值异常或正确性检查失败时保存状态并停止相应阶段，成功完成的检查不能替代未通过的检查。
