# 分步深度控制的实验计划 v3.1

版本：v3.1，2026-10-12。协议标识 `jev-chunk-depth-v3.1`。状态：RTX 5080 先导已运行并判定不放行，E 相对位置日程 R 的同成本改善为 −0.0064 nat/token，见[先导报告](PILOT_REPORT.v3.1.zh-CN.md)；第 0 阶段已按在线执行语义重做，只用冻结模型。v3.1 取代 [v3](EXPERIMENT_PLAN.v3.zh-CN.md)，v3 第 0 阶段报告的收益数字全部作废，原因见第 2.1 节，修订清单见第 11 节。固定参数见[协议配置](EXPERIMENT_CONFIG.v3.1.json)，第 0 阶段代码在 `experiments/chunk_depth_v3/`，回执在 `results/chunk-depth-v3/`。

## 1. 研究问题

### 1.1 从 v2.1 到 v3.1

v2.1 先导在通用文本续写上判定不放行。整请求只决策一次、预算等于全用深度 16 的成本时，即使用真实后缀逐文档挑深度，也只比纯深度 16 好 0.0019 nat。v3 据此提出五条设计原则，v3.1 保留它们，并修正第二条的依据：

| 原则 | 依据 | v3.1 的做法 |
|---|---|---|
| 换到深度确有收益的推理任务 | Huginn 论文：多选题在 16 次循环附近饱和，GSM8K 思维链在 32 次循环后仍提升 | 主任务改为 GSM8K 参考解答 |
| 按步骤决策 | 每次切换深度都可能造成 KV 缺口，切换越频繁代价越多；行是 GSM8K 解答的自然推理步骤；讨论中提出 chunk 级决策 | 解答的每一行是一个 chunk，每行开始前决策一次 |
| 决策要读到足够的上下文 | 讨论中提出 Jev 需要足够上下文 | 决策读取题目和已经写出的全部步骤 |
| 控制开销要远小于可分配空间 | v2.1 先导：1.4% 的控制开销造成 0.0024 nat 损失，超过全部空间 | 决策复用上一行最后一个位置已经算出的末端表示，额外计算只有读出 |
| 先测空间再训练，负结果限定适用范围 | v2.1 的教训；讨论中提出负结果往往实验不充分 | 第 0 阶段在正式协议的执行语义下测量；参照策略取真实执行下最好的位置日程 |

### 1.2 主问题与次问题

本协议设一个主问题和一个次问题。

1. 主问题。在 GSM8K 参考解答上，计算预算取全部步骤用深度 16 的一半。联合训练共享末端与深度读出的控制器 E，在真实执行混合深度的条件下，每 token NLL 能否优于位置日程族中真实执行最好的成员 R？位置日程只按"第几步"和"上一步多长"分配深度，与内容无关。预期方向是 E 优于 R。
2. 次问题。用 Jev 式 Dirichlet 采样梯度训练的 J 与 E 的差异。J 的局部梯度与 E 的局部梯度条件同均值，预期两者无差异。本协议只训练一个 J 种子，报告双侧区间，J 不参与样本量规划和主结论。

"Jev 式"的含义与 v2 计划第 1.2 节相同，指 Canopy-Jev 固定版本 `b71f97b` 公开的 Dirichlet 留一策略梯度配方。

### 1.3 适用范围

本实验的结论覆盖以下条件：

- 冻结 Huginn-0125 的循环核心，只训练末端两层 LoRA 与深度读出。
- 输入是 GSM8K 风格、逐行书写的解答。
- 深度在每行开始前选定，按 Huginn 原生的 KV 复用规则执行混合深度。
- 质量用教师强制下的逐 token NLL 衡量，生成正确率作为次要指标。
- 主结论限定在第 6.1 节定义的位置日程族之内。

专家路由、以文本候选形式输入的 Jev 读出、ARC 一类带候选答案的任务，留给后续协议。

## 2. 第 0 阶段

### 2.1 v3 原测量为何作废

v3 第 0 阶段报告了三组收益：chunk 级 0.117 与 0.052，探针 0.0169 与 0.0150。它们都不能作为目标部署策略的收益证据，原因有五条。

1. **决策用到了尚未生成的行长。** 探针的选择规则为 $\widehat d_c=\arg\min_d\{\widehat L_d(x_c)+\nu f_c(d)\}$，其中 $\widehat L_d$ 预测整行总 NLL，$f_c(d)$ 却按当前行的真实长度计算。按成本账本，一层在一个位置上的线性投影成本为 $A=8H^2+6HM$，多一轮循环在位置 $t$ 增加 $Q+16H(t+1)$，$Q=4H^2+4A$。当前行从位置 $a$ 开始、共 $m$ 个位置时，

   $$
   f_c(d_2)-f_c(d_1)=(d_2-d_1)\,G(a,m),\qquad
   G(a,m)=mQ+16H\Big(m(a+1)+\tfrac{m(m-1)}2\Big).
   $$

   取 $a=100$、$d_1=6$、$d_2=8$、$\nu=10^{-12}$、预测改善 0.1 nat：$m=10$ 时右侧为 0.0657，选深度 8；$m=30$ 时右侧为 0.1971，选深度 6。同样的决策前信息因为未来行长不同而产生不同动作，策略不满足"只用之前上下文"的约束。
2. **离线重放代替了在线决策。** 探针先用整篇固定深度 8 的表示定好全部动作，再在混合深度下重放；正式方案要求每行读取实际历史下的表示再决策。两者的输入与动作生成过程不同。
3. **题目段深度不一致。** 动态策略实跑时题目段用深度 16，静态对照取自整篇固定深度表，题目段跟随深度 $d$。报告的收益混入了 $\sum_dw_d[L_d^{(d)}-L_d^{(16)}]$ 这一项。
4. **可行集合不同。** 0.117 与 0.052 的计算把题目段和未计分的答案行也当作决策单位并计入预算。正式方案固定题目段为深度 16、排除其成本，并删除答案行。两个"预算 0.5"对应不同的可行集合。
5. **"上界"的称呼不成立。** 设 $\Pi_B$ 是预算内策略集合，静态参照 $R\in\Pi_B$，最优收益 $G^\star=L(R)-\inf_{\pi\in\Pi_B}L(\pi)$。由 $R\in\Pi_B$ 得 $\inf_{\pi\in\Pi_B}L(\pi)\le L(R)$，所以 $G^\star\ge0$。文中出现的负值只是某条交叉拟合选择规则迁移后的表现，不能证明最优分配空间为负。

### 2.3 重做的设定

重做的测量与正式协议使用同一套执行语义：

- **数据。** 第 0 阶段的 720 题按序号分为三份：拟合集 300 题，校准集 120 题，测试集 300 题。
- **执行。** 题目段固定用深度 16；解答每行在开始前决策，深度取 4、6、8、12、16 之一；按 `latest-m4` 规则真实执行混合深度。
- **决策规则。** 预测器给出该行在各深度下的每 token 平均 NLL $\widehat\ell_d(\mathcal H_c)$，决策为 $\arg\min_d\{\widehat\ell_d(\mathcal H_c)+\nu\,r(d)\}$，$r(d)$ 是第 2.2 节的相对成本，与行长无关。行的实际长度只用于事后核算成本。
- **在线。** 每行写完后读取实际历史下的末端表示，再决定下一行。
- **预测器。** 位置策略用行序号与上一行长度做岭回归；表示策略再加上决策位置的末端输出与该输出所在深度。训练行取自拟合集各深度的固定深度运行。问题级策略只在题目末尾用题目段的表示决定全题深度，对应原始设想。
- **校准。** 每个策略族在校准集上真实执行，扫描一组 $\nu$。取成本跨过预算的相邻两个 $\nu$，在文档层面按权重混合，使校准集的期望成本恰为预算；同一对 $\nu$ 和权重用于测试集。静态参照用同样方式混合两个统一深度。
- **指标。** 每篇文档决策行全部计分 token 的平均 NLL；配对文档 bootstrap 10,000 次。

| 0.5 | 表示策略 | 1.0273 | 0.500 | 0.0358 | [0.0291, 0.0426] |
| 0.5 | 问题级策略 | 1.0196 | 0.510 | 0.0436 | [0.0348, 0.0520] |
| 0.6 | 静态混合，深度 8 与 12 | 0.9509 | 0.600 | 无 | 无 |

三点结论：

1. **按行分配深度有效。** 只看位置的日程比统一深度混合好 0.034 nat。按第 2.2 节的曲线斜率，每单位相对成本约换 1.93 nat，这相当于把预算 0.5 提高约 3.5%。
2. **冻结表示在位置之外没有可检出的增益。** 预算 0.5 的区间上限为 0.007，点估计 0.0016。主问题要求 E 相对 R 至少好 0.005，因此联合训练至少要再贡献约 0.0034。
3. **问题级决策同样明显优于统一深度，与按行决策相差不大。** 问题级在测试集上的实际成本为 0.510，比预算高 2%，表中 0.0436 的改善有一部分来自多用的预算。在相同成本下比较，结果见下表。

### 2.5 KV 代价与历史覆盖

KV 缓存是否存在要按每个历史位置判断。设此前第 $j$ 行有 $m_j$ 个位置、执行深度为 $d_j$，当前行运行到深度 $d$。需要借用更早一轮 KV 的"位置—循环层"条目数为

$$
N_{\rm missing}(d)=4\sum_{j<c}m_j(d-d_j)_+,\qquad (x)_+=\max(x,0),
$$

系数 4 来自每轮的四个核心层。题目段固定为深度 16，候选深度不超过 16，题目段不贡献缺失条目。以历史位置平均，定义缺失轮数与超出轮数：

$$
s_c(d)=\frac{\sum_{j<c}m_j(d-d_j)_+}{\sum_{j<c}m_j},\qquad
e_c(d)=\frac{\sum_{j<c}m_j(d_j-d)_+}{\sum_{j<c}m_j}.
$$

在拟合集前 120 题上，每题做两次随机深度执行，共 578 行，测量实跑与查表的每 token NLL 差：

| 情形 | 行数 | 平均差（nat/token） |
|---|---:|---:|
| 不比此前最深行更深，且无缺失 | 267 | −0.0172 |
| 不比此前最深行更深，但有缺失 | 143 | 0.0338 |
| 比此前最深行更深 | 168 | 0.1001 |

按 token 加权线性拟合得

$$
\Delta\ell\approx-0.0003+0.0157\,s_c(d)-0.0032\,e_c(d),
$$

残差标准差 0.098。第二行说明以"此前最大深度"判断是否缺失并不充分：历史深度为 $(16,4)$、当前行为 12 时，$d-\max_j d_j=-4$，但第 2 行缺失 $32m_2$ 个条目。第一行的负值说明历史更深时当前行略好，查表会低估它。

### 2.6 对设计的约束

1. 决策粒度定为步骤级。问题级策略在主预算上与按行策略相差约 0.01 以内，作为免训练对照报告，也作为第 10 节的一个判读依据。
2. 主预算取 0.5，候选深度取 {4, 6, 8, 12, 16}。
3. 主参照 R 取位置日程族中真实执行最好的成员；它已经比统一深度好约 0.034，E 必须在此之外再赢。
4. 所有策略都在线执行，并按第 3.4 节对齐预算。
5. 训练标签的 KV 修正按 $s_c(d)$ 与 $e_c(d)$ 计算。

## 3. 一次请求的定义

### 3.1 文本与 chunk

文本格式为 `Question: {问题}\nAnswer: {解答}`。解答去掉计算器注释 `<<…>>`，并删去 `#### 答案` 这一行。token 序列为 BOS（65504）加上 `tokenizer.encode(text, add_special_tokens=False, split_special_tokens=True)`，长度不超过 320 个 token 的题目进入实验。

chunk 按 token 最后一个字符的位置归属：

- 落在 `Answer:` 及其之前的 token 属于 chunk 0，即题目段。
- 之后按解答中的换行分行，第 $c$ 行的 token 属于 chunk $c$。

记 chunk $c$ 的位置集合为 $P_c$，它的最后一个位置为 $p_c$。chunk $c$ 的计分 token 是从 $P_c$ 中位置预测出的 token，解答第一行的第一个 token 由 $p_0$ 预测。题目段固定用深度 16 执行，所有策略相同，它的成本单独报告，不计入预算归一化。决策对象是 chunk $1,\ldots,n$。

### 3.2 执行语义

执行使用 Huginn 的 `HuginnDynamicCache`，查找策略为 `latest-m4`。层索引的约定如下：

- 前置两层的层索引为 0、1，末端两层为 −1、−2。
- 第 $k$ 轮循环的第 $j$ 层（$j=0,\ldots,3$）的层索引为 $s=2+4k+j$。

位置 $q$ 在层索引 $s\ge2$ 上若没有 KV，规则取

$$
s^\star(q,s)=\max\{\,s'\le s:\ s'\ge2,\ s'\equiv s\pmod 4,\ \text{位置 }q\text{ 在 }s'\text{ 上有 KV}\,\}.
$$

同余条件保证复用的是同一个核心层在更早一轮的 KV。前置层和末端层的 KV 对每个位置都存在。教师强制评价按 chunk 顺序分段预填充，chunk $c$ 的全部位置用深度 $d_c$ 运行。在实数运算中这与逐 token 解码的计算图相同；BF16 下的差异按第 7.2 节的偏差门槛检查。

### 3.3 决策规则与控制开销

第 $c$ 行的深度在位置 $p_{c-1}$ 决定，只使用决策前的历史 $\mathcal H_c$：题目、此前各行的 token、此前各行的执行深度。读出的输入是这个位置的末端表示

$$
z_c=\operatorname{ln_f}\big(\operatorname{coda}(\cdot)\big)_{p_{c-1}},
$$

它在实际历史 $(16,d_1,\ldots,d_{c-1})$ 下算出，用来预测第 $c$ 行的第一个 token，再加上 10 维位置特征 $\phi_c$：9 维行序号 one-hot，序号 9 及以上合为一维，以及上一行长度除以 50。读出为

$$
p(\cdot\mid\mathcal H_c)=\operatorname{softmax}\big(W_0[z_c;\phi_c]+b_0\big),\qquad
W_0\in\mathbb R^{5\times5290}.
$$

部署规则为

$$
d_c(b)=\arg\max_d\big[\log\mu_c(d)-b\,r(d)\big],
$$

$r(d)$ 是第 2.2 节的相对成本，与当前行长度无关。决策规则的两部分都只依赖 $\mathcal H_c$；行的实际长度只用于事后核算成本。一般形式为

$$
d_c=\arg\min_d\Big\{\widehat{\mathbb E}[L_c(d)\mid\mathcal H_c]+\nu\,\widehat{\mathbb E}[f_c(d)\mid\mathcal H_c]\Big\},
$$

忽略注意力项随位置的变化时，$\widehat{\mathbb E}[f_c(d)\mid\mathcal H_c]$ 近似为预期行长、每位置深度 16 成本与 $r(d)$ 三者之积；再假设每 token NLL 与行长在给定 $\mathcal H_c$ 时条件独立，第一项近似为预期行长与每 token 预测 NLL 之积。两项共有的预期行长对所有 $d$ 相同，除去后不改变 $\arg\min$，于是得到上面的部署规则。

每次决策的额外计算为 $2\times5290\times5=52{,}900$ FLOPs，深度 8 下单个位置约 $3.0\times10^{10}$ FLOPs，是读出的约 $5.7\times10^5$ 倍。

### 3.4 成本账本、预算与预算对齐

位置 $t$ 在深度 $d$ 下的 FLOPs 按逐 token 解码的形状计：

$$
F(t,d)=F_{\rm stack}(1,t+1,d)+F_{\rm head}(1),
$$

定义同 v2 的成本账本 `experiments/shared_depth_v2/cost.py`。chunk $c$ 在深度 $d$ 下的成本为 $f_c(d)=\sum_{t\in P_c}F(t,d)$。评价集上一个策略的相对成本为

$$
B(\pi)=\frac{\sum_i\sum_{c\ge1}f_{i,c}(d^\pi_{i,c})}{\sum_i\sum_{c\ge1}f_{i,c}(16)}.
$$

主预算 $B=0.5$，0.6 作为次要预算报告。

预算对齐用文档层面的混合实现。设某策略族在校准集上扫描得到的两个参数 $b_1,b_2$ 满足 $B(\pi_{b_1})\ge B\ge B(\pi_{b_2})$，取

$$
w=\frac{B-B(\pi_{b_2})}{B(\pi_{b_1})-B(\pi_{b_2})},
$$

每篇文档以概率 $w$ 执行 $\pi_{b_1}$、以概率 $1-w$ 执行 $\pi_{b_2}$，抽样由文档编号的哈希确定。这样校准集上的期望成本恰为 $B$，期望 NLL 是两者的线性组合。评价时对两条策略都真实执行，直接计算期望。静态参照与位置日程按同样方式对齐。

## 4. 控制器、训练信号与实验臂

### 4.1 共享参数

LoRA 的位置、秩、缩放、初始化与 v2 计划第 4.1 节相同：两个末端层的四个融合投影，rank 8，alpha 16，共 1,536,000 个参数。生成与控制引用同一组参数对象。读出 $(W_0,b_0)$ 先在预热集上训练，训练行的表示取自各候选深度的固定深度运行，与第 2.3 节的预测器相同；之后在所有训练臂中冻结。零 LoRA 时读出在每个训练 chunk 上的分布保存为固定参考 $\mu_{\rm ref}$。

### 4.2 chunk 成本与 KV 覆盖修正

对文档 $i$、chunk $c$、深度 $d$，训练用的成本为

$$
C_{i,c}(d)=\sum_{u\in U_{i,c}}\ell_{\theta}(u;d)+\lambda\,n_{i,c}\,r(d)
+n_{i,c}\big[\kappa_s\,s_c(d)+\kappa_e\,e_c(d)\big].
$$

各项含义：

- $U_{i,c}$ 是计分 token 集合，$n_{i,c}=|U_{i,c}|$。
- $\ell_\theta(u;d)$ 是当前参数下、整段深度 $d$ 教师强制得到的 token NLL，每步重算。
- $r(d)$ 依次为 0.301、0.418、0.534、0.767、1.000。
- $s_c(d)$ 与 $e_c(d)$ 按第 2.5 节定义，历史深度取自当前策略的无梯度采样。
- $\kappa_s,\kappa_e$ 在先导第 7.3 节重新估计后固定。第 0 阶段的估计为 $\kappa_s=0.0157$、$\kappa_e=-0.0032$。

训练标签可以使用实际行长与实际 NLL，因为它们是监督目标，读出本身只看到 $\mathcal H_c$。

训练时读出的输入取自固定深度 $d_{c-1}$ 的整段运行：

$$
\widetilde z_c=Z_\theta(x_{\le p_{c-1}};16,d_{c-1},\ldots,d_{c-1}),
$$

部署时则是实际历史下的

$$
z_c=Z_\theta(x_{\le p_{c-1}};16,d_1,\ldots,d_{c-1}).
$$

两者只在历史深度全部相同时相等，例如历史 $(16,16,4)$ 与 $(4,16,4)$ 有相同的上一行深度与历史最大深度，KV 覆盖却不同。$\widetilde z_c$ 是训练近似；先导按第 7.2 节测量两者造成的决策差异，结论按在线执行报告。

### 4.3 训练目标：局部代理

固定一篇文档，深度轨迹 $\tau=(d_1,\ldots,d_n)$ 的概率为

$$
P_\theta(\tau)=\prod_{c=1}^n\mu_\theta(d_c\mid\mathcal H_c),
$$

轨迹总成本 $L_\theta(\tau)=\sum_c\ell_{\theta,c}(\tau)$，顺序目标为 $J(\theta)=\sum_\tau P_\theta(\tau)L_\theta(\tau)$。对乘积求导：

$$
\begin{aligned}
\nabla_\theta J
&=\sum_\tau\big[P_\theta(\tau)\nabla_\theta L_\theta(\tau)+L_\theta(\tau)\nabla_\theta P_\theta(\tau)\big]\\
&=\mathbb E_\tau\Big[\nabla_\theta L_\theta(\tau)+\sum_cL_\theta(\tau)\nabla_\theta\log\mu_\theta(d_c\mid\mathcal H_c)\Big].
\end{aligned}
$$

对 $r<c$，$\ell_{\theta,r}$ 在第 $c$ 次决策前已确定，

$$
\mathbb E\big[\ell_{\theta,r}\nabla_\theta\log\mu_\theta(d_c\mid\mathcal H_c)\mid\mathcal H_c\big]
=\ell_{\theta,r}\sum_d\nabla_\theta\mu_\theta(d\mid\mathcal H_c)=0,
$$

所以路由项为

$$
\mathbb E_\tau\Big[\sum_c\Big(\sum_{r=c}^n\ell_{\theta,r}\Big)\nabla_\theta\log\mu_\theta(d_c\mid\mathcal H_c)\Big].
$$

第 $c$ 个动作要承担它对当前及以后成本的影响。本协议的 E 与 J 只用当前行成本，即优化局部代理

$$
J_{\rm loc}(\theta)=\mathbb E_{\mathcal H}\Big[\sum_c\sum_d\mu_\theta(d\mid\mathcal H_c)\,C_c(d)\Big],
$$

其中历史从当前策略无梯度采样。它遗漏

$$
\mathbb E_\tau\Big[\sum_c\Big(\sum_{r>c}\ell_{\theta,r}\Big)\nabla_\theta\log\mu_\theta(d_c\mid\mathcal H_c)\Big].
$$

这一项一般不为零。两步反例：$d_1\sim\operatorname{Bernoulli}(q_\theta)$，$q_\theta=\sigma(\theta)$，$\ell_1=0$，$\ell_2=1-d_1$。真实目标 $J=1-q_\theta$，梯度 $-q_\theta(1-q_\theta)$；局部代理的路由梯度为零，因为第一步成本为零，第二步成本在固定历史下不随第二步动作变化。在本系统中，当前行的深度改变后续各行的 $s_c$ 与 $e_c$，第 2.5 节测得每缺一轮约损失 0.0157 nat/token，因此未来成本依赖当前动作。

结论：E 的解析梯度对局部代理 $J_{\rm loc}$ 严格成立，对顺序目标 $J$ 有偏。本协议把 E 与 J 定义为局部代理上的两种梯度估计，所有结论都以在线真实执行的顺序策略来评价，不声称训练梯度对顺序目标无偏。

J 与 E 的条件同均值关系仍成立：固定历史并停止成本向量 $C$ 的梯度，$P\sim\operatorname{Dirichlet}(\alpha_\theta)$，$\mathbb E[P]=\mu_\theta$，

$$
\mathbb E\big[(C^\top P)\nabla_\theta\log p_\theta(P)\big]=\nabla_\theta\mathbb E[C^\top P]=\sum_dC_d\nabla_\theta\mu_{\theta,d}.
$$

这只说明两者在局部代理上同均值，不能补回共同遗漏的未来成本项。顺序目标的未来成本项留给后续协议，可用"当前及以后成本之和"加基线的采样梯度估计。

每个 chunk 的控制分布沿用 v2 的 Dirichlet 平滑，动作数 $K=5$，$\kappa_D=256$、$\varepsilon=0.01$、$\eta=0.001$。辅助项 $\mathcal A_c$ 为 0.1 倍 CE、0.01 倍 Brier 和 0.1 倍对 $\mu_{\rm ref}$ 的 KL，软标签 $s_c=\operatorname{softmax}(-\operatorname{sg}(C_{i,c})/(n_{i,c}\tau))$，$\tau=0.05$。$\lambda$ 的网格与规则同 v3：取 $\{0.25,0.5,1,1.5,2,3\}$，选预热集上未校准平均相对成本最接近 0.5 者。

## 6. 评价

### 6.1 位置日程 R

位置日程族由第 2.3 节的位置预测器定义：岭回归以行序号 one-hot 与上一行长度为输入，预测各深度的每 token NLL，决策为 $\arg\min_d\{\widehat\ell_d+\nu r(d)\}$。R 的产生分两步：

1. **生成候选。** 对候选池中的每个模型，即冻结模型、SCHED-A、FMIX-A 和 E 的静态版本，在正式训练集的查表 NLL 上拟合位置预测器。训练集有 4,111 篇，避免日程在小样本上过拟合。
2. **真实执行选择。** 在正式校准集上，对每个池成员的日程族扫描 $\nu$ 并真实执行，按第 3.4 节对齐到预算，选在线 NLL 最低的池成员与 $\nu$ 对。三个种子的结果先取平均，三个种子共用同一配方。

查表最优与真实执行最优没有等价保证。写 $L_{\rm real}(R)=L_{\rm table}(R)+\Delta_{\rm KV}(R)$，两个同成本日程若 $L_{\rm table}$ 为 1.00 与 1.01、$\Delta_{\rm KV}$ 为 0.10 与 0，查表选出前者，真实执行却是后者更好；此时 E 若为 1.05，会同时优于查表选出的日程、劣于真实最佳日程。所以 R 必须按真实执行选择，主结论限定在这个日程族内。

### 6.2 控制器的预算校准

部署规则 $d_c(b)=\arg\max_d[\log\mu_c(d)-b\,r(d)]$ 的成本在顺序策略下对 $b$ 没有单调性保证。分数固定时，设 $b_2>b_1$，最优动作分别为 $d_2,d_1$，两个最优性不等式相加得 $(b_2-b_1)[r(d_1)-r(d_2)]\ge0$，所以 $r(d_2)\le r(d_1)$。但改变 $b$ 会改变前一步动作，进而改变后一步的表示和分数，这个前提不再成立。

反例：两行长度 1 与 10，$r_L=0.418$、$r_H=0.534$，第一行深浅对数概率比 $\gamma_1=0.116$；第二行在上一行选 $H$ 时为 0、选 $L$ 时为 0.348。$b=0.5$ 时第一行选 $H$，第二行选 $L$，总成本 4.714；$b=1.5$ 时第一行选 $L$，第二行选 $H$，总成本 5.758。$b$ 增大，成本反而增大。

因此校准不用二分法。在正式校准集上真实执行一组 $b$，报告成本与 NLL 随 $b$ 的曲线；取成本跨过预算的相邻两个 $b$，按第 3.4 节混合到预算。若曲线在预算附近不单调，取预算内 NLL 最低的点，并在报告中列出整条曲线。

### 6.3 同成本条件

同成本条件直接比较确认集上的两个策略：

$$
\frac{C_E^{\rm confirm}}{C_R^{\rm confirm}}\in[0.98,\,1.02].
$$

R 的实际成本随确认集的行长分布变化，不能用它在校准集上的成本代替。比值超出上限时，不作同成本结论，只报告质量与成本。

### 6.4 主指标

文档 $i$ 的质量 $\ell_i$ 是决策 chunk 全部计分 token 的平均 NLL，在 BF16 在线真实执行下计算。E 与 R 都按第 3.4 节的混合方式执行，直接计算期望。

### 6.5 次要指标：生成正确率

取确认集前 512 题，greedy 生成，最多 256 个新 token，遇到 EOS 或新起一行的 `Question:` 即停止。题目段用深度 16；模型每输出一个换行符就做一次决策。答案取停止前输出中最后一个数。比较 E 的三个种子、R 的三个种子，以及冻结模型的纯深度 8 和纯深度 16。先导先测冻结模型纯深度 16 的正确率，确认它不在下限附近。

### 6.6 时间

报告每个策略在 A10 上的生成墙钟时间和每 token 时间。`latest-m4` 的缓存查找在 Huginn 参考实现中以 Python 循环完成，计时反映参考实现的开销，本协议不设速度门槛。

## 9. 统计检验

### 9.1 主检验

对确认文档 $i$，先对三个种子分别计算对齐预算后的在线 $\ell_{R,s,i}$ 与 $\ell_{E,s,i}$，再取平均：

$$
g_i=\frac13\sum_{s}\big(\ell_{R,s,i}-\ell_{E,s,i}\big).
$$

检验以文档为单位做配对 bootstrap，10,000 次，单侧，$\alpha=0.05$。主结论要求同时满足四条：

1. 第 6.3 节的同成本条件成立。
2. 主检验显著。
3. 点估计不低于 0.005 nat/token。
4. 三个种子各自的平均效应均为正。零假设下三个种子同向的概率为 1/8。

### 9.2 确认集规模

正式筛选集 745 篇只用于估计 $g_i$ 的标准差 $\hat\sigma$，计划标准差取 $\sigma=1.2\hat\sigma$。规划效应 $\delta=0.01$，最小实用点估计 $\delta_{\min}=0.005$，功效 0.8，单侧 $\alpha=0.05$：

$$
n\ge\max\left\{\left[\frac{(z_{0.95}+z_{0.8})\sigma}{\delta}\right]^2,\ \left[\frac{z_{0.8}\,\sigma}{\delta-\delta_{\min}}\right]^2\right\},\qquad
z_{0.95}=1.644854,\ z_{0.8}=0.841621.
$$

结果上取到 128 的倍数，最少 512，最多 1,310。用第 2.4 节的数据预估：表示策略与位置策略的逐篇差标准差为 0.047，$\sigma=0.057$，两项分别约需 201 篇和 92 篇，取下限 512 篇。512 篇时的可检出效应约为 $2.486\times0.057/\sqrt{512}\approx0.0063$。

### 9.3 次问题与次要指标

- **次问题。** J 与 E 都只取种子 17，报告 $\ell_{E,17,i}-\ell_{J,17,i}$ 的双侧 95% 区间和可检出效应。
- **次要指标。** 生成正确率报告 E 与 R 的配对差及其 bootstrap 区间，作为描述性结果。

## 10. 结果与研究决策

| 结果 | 支持的判断 | 后续工作 |
|---|---|---|
| 主结论成立 | 联合训练的共享末端在位置日程之外读出了与内容相关的深度信号 | 扩大到更长的推理和带候选的任务 |
| E 优于统一深度但不优于 R | 收益来自位置结构，联合训练没有带来额外信号 | 检查文本候选形式的 Jev 读出或更强的控制器 |
| E 不优于问题级策略 | 按行决策相对按题决策没有优势，KV 缺口抵消了更细粒度的收益 | 回到问题级决策，或研究不产生 KV 缺口的执行语义 |
| 在线执行显著差于查表 | KV 复用代价主导结果 | 研究补算历史 KV 或限制深度跃升的执行语义，或按顺序目标训练 |
| 区间较宽或成本不匹配 | 本研究不能完成对应判断 | 报告区间与成本，另立后续协议 |
| 生成正确率与 NLL 结论方向相反 | NLL 不足以代表推理质量 | 以生成正确率为主指标另立协议 |

## 11. 修订与交付

### 11.1 v3.1 相对 v3 的修订

| 修订 | 原因 |
|---|---|
| 决策只用决策前历史；成本项改为与行长无关的每 token 相对成本；实际行长只用于核算 | v3 探针的成本项使用尚未生成的当前行长度，同一前缀会因未来行长产生不同动作 |
| 第 0 阶段改为在线执行，题目段统一深度 16，预算口径与正式方案一致，所有比较按混合方式对齐预算 | v3 的 0.117、0.052、0.0169、0.0150 分别来自不同的可行集合、离线重放、题目段深度差异与行长泄漏 |
| "上界"改称交叉拟合规则的表现，补 $G^\star\ge0$ 的说明 | 静态参照属于可行集合，最优收益不为负 |
| KV 修正由"此前最大深度"改为按历史位置统计的缺失轮数与超出轮数 | 历史 (16, 4) 后接 12 时有 $32m_2$ 个缺失条目，原修正为零；实测该情形每 token 多损失 0.034 nat |
| 删除"训练表示与部署分布一致"的说法，先导测量两者造成的决策差异 | 相同上一行深度与最大深度的历史可有不同 KV 覆盖 |
| E 与 J 定义为局部代理上的梯度，取消对顺序目标的无偏声明 | 当前行深度影响后续成本，只用当前行成本会遗漏未来成本项，两步反例中真实梯度非零而局部梯度为零 |
| 预算校准改为真实执行扫描并混合相邻参数，取消二分法 | 顺序策略下成本对 $b$ 不单调，存在反例 |
| R 改为在训练集上生成候选、在校准集上按真实执行选择，结论限定在日程族内 | 查表最优与真实执行最优没有等价保证；小样本拟合的日程偏弱 |
| 同成本条件改为确认集上 E 与 R 的成本比 | R 在确认集上的实际成本随行长分布变化 |
| 生成评价补停止规则与下限检查 | 删去答案行后模型可能续写新题，"最后一个数"会取错 |
| 问题级从"没有空间"改为免训练对照 | 在线、同成本测量下，问题级比统一深度好约 0.027，与按行策略相差约 0.01 以内 |
