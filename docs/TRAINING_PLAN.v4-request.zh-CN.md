# v4 请求级两动作循环架构训练计划

协议 ID 为 `jev-v4-request2`，状态为训练计划（设计），待用户确认数据与门槛后进入 infra（2026-10-15）。架构以[附图](ARCHITECTURE_REQUEST.v4.dot)为准，即校正版请求级两动作循环架构：整次回答只决策一次，只有一个生成尾，总轮数 $r\in\{1,2\}$。下一段的单向停止是本计划对附图的唯一修改。

同日采纳[分块扩展](CHUNK_ROUTING.v4-request.zh-CN.md)的推荐方案：第二轮的历史缺口按精确补写处理（B0），生成尾按实际送入的出口维护历史（T0），部署先用第一级“单向停止”。启用第二轮的回答可以在块边界停止第二轮，此后取 $r=1$ 到结束；附图的不变量 3 相应改为“轮数只能在块边界从 2 降为 1”。生成训练改用四类轮数日程（第 4.2 节），单向停止相对请求级的额外空间由判据 GL3 检验（第 6.5 节），停止控制器及其主检验 P4 见第 7.6、8.3 节。

本分支中的按行循环文档（`ARCHITECTURE*.v4.zh-CN.md`、一天方案与 `EXPERIMENT_CONFIG.v4-rowloop.json`）描述另一种方案，本计划不修改它们。MoE 维度、LoRA 参数量、每层矩阵乘账本与统计方法沿用其中已经核实的推导；实验依据见[实验汇总](EXPERIMENT_SUMMARY.zh-CN.md)。

本计划回答四个问题：

1. 第二轮循环能否降低负对数似然（Negative Log-Likelihood，NLL）。
2. 按请求选择轮数，在同样的计算预算下是否优于随机分配。
3. 首轮表示读出 H 与只读查询控制器 Q，能在多大程度上预测哪些请求值得第二轮。
4. 在块边界提前停止第二轮，能否在请求级决策之外进一步改善同成本 NLL。

## 1. 架构要点与训练对象

基座为 Qwen3-30B-A3B-Instruct-2507（版本 `0d7cf239`）：48 层，隐藏维 $H=2048$，每层 128 个前馈专家、每 token 激活 8 个。下表列出各部件及其训练方式：

| 部件 | 范围或输入 | 训练方式 | 可训练参数 |
|---|---|---|---:|
| 共享前缀 $S$ | 第 0–31 层 | 冻结 | 0 |
| 首轮 $F^1$ | 第 32–43 层 | 生成 LoRA，阶段 1 训练 | 210,960,384 |
| 第二轮 $F^2$ | 第 32–43 层 | 与 $F^1$ 共用权重和 LoRA，KV 独立 | 0（共用） |
| 混合向量 $g$ | $\mathbb R^{2048}$ | 阶段 1 训练，初值为 0 | 2,048 |
| 生成尾 $T$ | 第 44–47 层 | 生成 LoRA，阶段 1 训练 | 70,320,128 |
| 最终归一化与词表头 | 原模型 | 冻结 | 0 |
| H | 提示词末位 $h^1_P$ 与已知状态 $z$ | 生成器冻结后训练 | 591,617 |
| 公共成本模型 | 提示词末位读 $z$，块边界读 $z_{d,c}$ | 两个岭回归 | 5、7 |
| Q | 第 43 层首轮提示词 KV、$h^1_P$、$z$ | 生成器冻结后训练 | 约 4.21M |
| 门控 | H 的预测、成本预测与查询价值 | 回归查询带来的预测变化 | 约 0.13M |
| 停止控制器 H$_{\rm stop}$ | 块边界的 $h^1$ 与边界状态 $z_{d,c}$ | 生成器冻结后训练 | 592,129 |

LoRA 取秩 16、缩放 32，$A$ 随机初始化、$B=0$，覆盖注意力的 Q、K、V、输出投影和每个专家的 gate、up、down 投影。每层 LoRA 参数为 17,580,032 个（[数学验证](ARCHITECTURE_MATH.v4.zh-CN.md)第 7.2 节），生成侧共 $16\times17{,}580{,}032+2048=281{,}282{,}560$ 个。

记位置 $i$ 的输入为 $x_i$，执行顺序为

$$
\begin{aligned}
u_i&=S(x_{\le i}),\\
h_i^1&=F_{\theta+\Delta}\big(u_i;\,C^1_{<i}\big),\\
v_i^2&=u_i+\tanh(g)\odot\big(h_i^1-u_i\big),\\
h_i^2&=F_{\theta+\Delta}\big(v_i^2;\,C^2_{<i}\big),\\
p_i&=\operatorname{softmax}\!\Big[W_{\rm vocab}N_{\rm f}\big(T_{\phi}(h_i^{(r_i)};\,C^T_{<i})\big)\Big].
\end{aligned}
$$

其中 $C^1$、$C^2$、$C^T$ 分别是首轮、第二轮与生成尾的 KV 缓存，$\theta$ 为冻结基座权重，$\Delta$ 为第 32–43 层共用的 LoRA 增量，$\phi$ 为生成尾的 LoRA，$r_i$ 为位置 $i$ 的轮数。轮数在提示词末位选定；取 2 时可以在块边界降为 1，此后保持 1 到回答结束（第 7.6 节）。$F^2$ 覆盖从第一个位置到最后一个 $r_i=2$ 的位置（分块扩展推论 3）。

附图列出 5 条执行不变量，训练按以下方式落实：

1. 第二轮在提示词上也完整预填充：凡是有块取 $r=2$ 的训练样本，$F^2$ 都覆盖整段提示词，成本账本单列这部分费用。
2. $F^1$、$F^2$ 共享权重而不共享 KV：自动微分把两轮对共用 LoRA 的梯度相加，两轮的缓存分开存放。
3. 轮数只能在块边界从 2 降为 1（采纳的分块扩展修改了这一条）：部署时第二轮覆盖提示词与停止点之前的位置，没有历史补写，单尾也不需要追赶。训练日程中的开启类样本按精确补写执行（第 4.2 节），只用于让生成尾见过 $h^1$ 历史后接 $h^2$ 的情形。
4. H 与 Q 只读生成表示：控制器在生成器冻结后训练，读取的表示加停止梯度；验收项 E5 检查开启 Q 不改变生成分布。
5. 附图取代此前与正文冲突的自动附图：本计划只依据附图。

## 2. 实验依据与设计约束

### 2.1 先训练生成器，再训练控制器

v3.2 追加实验在只差控制损失的两臂上测得，控制损失使固定日程下的生成 NLL 升高 0.0016 [0.0005, 0.0028]；v3.3 在三个种子上复现为 $h_C=+0.00168$ [0.00134, 0.00203]。本计划沿用两阶段训练：先训练并冻结生成器，H 与 Q 读取的表示加停止梯度，控制器的梯度在构造上不进入生成参数。v3.3 的这一结论限于从 $\theta_S$ 出发的 93 次更新，冻结方案本身不依赖损害的大小。

### 2.2 请求级的可分配空间

请求级决策在已有实验中有三组证据，方向并不一致：

1. v2.1 在通用文本上每请求决策一次。预算 1 处，事后最优只比纯深度 16 好 0.0019；预算 0.35 处，事后上界为 0.0425，计入控制开销的分半上界为 0.0163。空间大小取决于预算点。
2. v3.1 第 0 阶段在 GSM8K 上，冻结模型的问题级策略相对静态混合改善 0.0436 [0.0348, 0.0520]，但它的成本为 0.5102，超出预算 2%，不能直接与同成本策略比较。
3. loopjev 的 Huginn 逐题深度探针（ARC-Challenge validation，299 题）中，事后最优分配相对固定 32 步节省 40.43%（区间 35.26%–45.44%），其中 14.92 个百分点来自 51 道正确性不单调的题；只按“该深度及更深都答对”的稳定口径分配，节省降为 27.99%。四个免训练读出在二折交叉验证下回收率全部为 0，与题目无关的随机数阴性对照在样本内回收了 24.34%。

这三组结果给本计划三条约束。第一，事后上界会被单一样本的噪声抬高，本计划在对偶上界之外再报告分半上界（第 6.3 节）。第二，免训练读出没有识别出难度信号，H 与 Q 必须训练，并与只读已知状态的 R 和读噪声特征的阴性对照 N 比较。第三，可分配空间随预算点变化，主预算在校准集上按上界选定（第 6.2 节）。

### 2.3 训练时的轮数分布

v3.1 在先导校准集（223 篇，单种子，无区间）上，按冻结位置日程训练的 SCHED-A 对齐预算后 NLL 为 0.8778，对五个深度均匀训练的 FMIX-A 为 0.8927，前者好 0.0149。训练分布接近部署分布更有利。本计划的部署比例取决于预算，候选预算的中点 $B=1.125$ 约有一半请求取 $r=2$，生成训练因此让一半位置取 $r=2$。四类日程下（第 4.2 节），块等长且切换点均匀时，停止类与开启类各有一半回答位置取 $r=2$，回答位置取 $r=2$ 的比例为 $\tfrac13+\tfrac16\times\tfrac12+\tfrac16\times\tfrac12=\tfrac12$；提示词位置随第一块，取 $r=2$ 的比例为 $\tfrac13+\tfrac16=\tfrac12$。

### 2.4 统计方法

评价沿用 v3.3 的严格同成本插值与文档配对自助法。v3.3 实验 A 的自助标准差 0.00105 折合逐篇差标准差 $0.00105\times\sqrt{2397}=0.0514$；v3.2 阶段一的规划值为 0.067。本计划按 0.067 规划样本量，在校准集上重估后再报告功效。v3.3 的检出只达到单侧口径，双侧区间含零，本计划对每个比较同时报告单侧下界与双侧区间。

### 2.5 块级粒度

块级粒度的证据有限，详见[分块扩展](CHUNK_ROUTING.v4-request.zh-CN.md)第 1 节。v3.1 第 0 阶段中，按行分配深度相对静态混合改善 0.0342 [0.0276, 0.0408]，问题级策略的同成本数字没有回执；GSM8K 解答平均只有 3.58 行（v3.2 读出训练集 4,111 篇共 14,703 行），块数少；Huginn 上未经训练的 KV 缺口每缺一轮约损失 0.013 nat/token。本计划因此只部署不产生缺口的单向停止，并在训练停止控制器之前用 GL3 测量它相对请求级的额外空间。

## 4. 阶段 1：生成训练

### 4.1 两条生成臂

$G_{\rm two}$ 是本架构的生成器：每条训练请求按哈希分到四类轮数日程之一（第 4.2 节）。$G_{\rm one}$ 是单轮对照：结构、数据、数据顺序、初始化种子、优化器与训练量都与 $G_{\rm two}$ 相同，所有请求都取 $r=1$，没有混合向量 $g$。

两臂只差训练时的轮数分配，所以 $G_{\rm two}$ 取 $r=1$ 时与 $G_{\rm one}$ 的 NLL 差，衡量的是“三分之二的请求在全部或部分位置经第二轮训练”对单轮质量的影响。$r=1$ 路径在本架构中就是普通的单轮 LoRA 模型，这一比较不受首轮是否启用 LoRA 的干扰；按行循环方案里 $G_{\rm loop}(r=1)$ 与 $G_{\rm plain}$ 的差异在这里不存在。

### 4.2 数据、轮数分配与打包

生成训练沿用一天方案的配额：每臂 $2\times10^8$ 个非填充输入 token，通用文本与数学解答各 $10^8$。数学样本以题目为提示词、以完整解答（含最终答案）为监督目标，只对解答 token 计损失；通用文本整篇作为一次请求，全部 token 参与监督。数据集名称与版本由用户确认（第 12 节）。

回答按块划分：数学解答每行一块，超过 64 token 的行在 64 token 处切开；通用文本按句切分，超过 32 token 的句子在 32 token 处切开。记请求 $d$ 的回答有 $K_d$ 块，第 $c$ 块起点为 $b_c$。

请求 $d$ 的轮数日程由哈希决定。令

$$
\eta_d=\operatorname{int}_{\rm BE}\big[\operatorname{SHA256}(\text{UTF-8}(\texttt{jev-v4-request2-r})\,\|\,\texttt{0x00}\,\|\,\text{UTF-8}(\text{请求标识}))\big],
$$

$\operatorname{int}_{\rm BE}$ 把 32 字节摘要读作大端整数，写法与 v3.1 的分桶规则相同。按 $\eta_d\bmod6$ 分配日程：

| $\eta_d\bmod6$ | 日程 | 比例 | 各块轮数 |
|---|---|---:|---|
| 0、1 | 全程 $r=1$ | 1/3 | 全部为 1 |
| 2、3 | 全程 $r=2$ | 1/3 | 全部为 2 |
| 4 | 停止 | 1/6 | 第 $1,\ldots,s_d-1$ 块为 2，其余为 1 |
| 5 | 开启 | 1/6 | 第 $1,\ldots,s_d-1$ 块为 1，其余为 2 |

切换点 $s_d$ 在内部块边界 $\{2,\ldots,K_d\}$ 上均匀抽取：用盐 `jev-v4-request2-s` 按同样写法得到整数，对 $K_d-1$ 取模后加 2。$K_d=1$ 时没有内部边界，停止类按全程 $r=2$、开启类按全程 $r=1$ 处理。提示词位置按第一块的轮数送入生成尾。哈希与数据顺序无关，各类日程在每个数据来源内的比例相同。

训练按精确补写语义执行（分块扩展的 B0＋T0）：凡是有块取 $r=2$ 的样本，$F^2$ 覆盖到最后一个取 $r=2$ 的位置为止。全程 $r=2$ 与开启类覆盖全篇，开启类前缀上的第二轮只供后缀的第二轮注意力读取；停止类覆盖提示词与停止点之前的块。生成尾在每个位置读取该位置实际选择的出口。开启类只出现在训练中，作用是让生成尾见过“$h^1$ 历史接 $h^2$ 当前”的情形，第二级“单次切换”需要这种情形；第一级部署只用到停止。

打包分两个流。流一为全程 $r=1$ 的请求，不执行 $F^2$。流二为其余三类，执行器把每篇请求需要第二轮的前缀另行打包给 $F^2$，按文档隔离注意力。每个全局批次 32 条序列，11 条来自流一、21 条来自流二，比例约为 1:2，与日程比例一致。

### 4.3 目标与优化

$G_{\rm two}$ 最小化批次内监督 token 的平均 NLL：

$$
\mathcal L_{\rm gen}(\Delta,\phi,g)
=\frac{1}{\sum_{d\in\mathcal B}|A_d|}
\sum_{d\in\mathcal B}\sum_{t\in A_d}
-\log p_{\Delta,\phi,g}\big(x_{d,t}\mid x_{d,<t};\,\mathbf r_d\big),
$$

其中 $\mathcal B$ 为批次中的请求，$A_d$ 为请求 $d$ 的监督 token 集合，$\mathbf r_d=(r_{d,i})_i$ 为请求 $d$ 按日程确定的逐位置轮数。$x_{d,t}$ 的预测由位置 $t-1$ 的输出给出，只依赖 $i\le t-1$ 的 $r_{d,i}$。$G_{\rm one}$ 的目标相同，只是全部 $r_{d,i}=1$，没有参数 $g$。

两臂的优化设置与一天方案一致：AdamW，学习率在前 5% 更新内从零升到 $10^{-4}$，再余弦降到 $10^{-5}$；LoRA 权重衰减 0.01，$g$ 的权重衰减为 0；梯度范数裁剪阈值 1；BF16 激活与 FP32 主参数；序列长度 4096；全局批量 131,072 token；激活重算；种子 17。每臂 $2\times10^8/131{,}072=1525.9$，取 1,526 次更新。

### 4.4 零初始化等价与 $g$ 的梯度

**命题 1。** 若 $g=0$，则对任意 LoRA 参数，$r=2$ 与 $r=1$ 在每个位置给出相同的预测分布。若同时所有 LoRA 增量为零，两者都等于原模型。

**证明。** $\tanh(0)=0$，所以 $v_i^2=u_i$ 对所有位置成立。$F^2$ 与 $F^1$ 使用同一组权重 $\theta+\Delta$，第一层的输入在所有位置上相同。对层号归纳：设第 $l$ 层（$32\le l\le43$）在所有位置 $j\le i$ 上，第二轮输入等于首轮输入。第 $l$ 层的 K、V 是该层输入经同一组投影得到的，所以第二轮缓存 $C^{2,l}_{<i}$ 与首轮缓存 $C^{1,l}_{<i}$ 逐项相同。当前位置的查询、注意力权重、注意力输出与 MoE 输出也都相同，所以第 $l+1$ 层的输入在所有 $j\le i$ 上相等。归纳到第 43 层得 $h_i^2=h_i^1$。生成尾收到相同的出口序列，预测分布相同。若所有 LoRA 增量为零，第 32–47 层都回到原权重，两条路径都等于原模型。证毕。

这一论证对逐块任意的轮数序列同样成立：$g=0$ 时凡是执行第二轮的位置都有 $h_i^2=h_i^1$，生成尾收到的出口序列与轮数无关，四类日程在训练开始时彼此等价。

$g$ 的梯度由链式法则得到：

$$
\frac{\partial\mathcal L}{\partial g}
=\sum_i\frac{\partial\mathcal L}{\partial v_i^2}\odot\operatorname{sech}^2(g)\odot\big(h_i^1-u_i\big),
$$

$g=0$ 时 $\operatorname{sech}^2(0)=1$。只要首轮出口与前缀出口不同，$g$ 从第一步起就有非零梯度。

$g=0$ 时，$v^2$ 不依赖 $h^1$（$\partial v^2/\partial h^1=\operatorname{diag}(\tanh g)=0$），$r=2$ 样本的损失只经 $F^2$ 依赖共用 LoRA，而 $F^2$ 的计算与 $r=1$ 时的 $F^1$ 完全相同。所以训练开始时，同一请求无论分到哪个流，给共用 LoRA 的梯度都相同。两条路径的差异随 $g$ 离开零而出现。

### 4.5 训练量与吞吐准入

每 token 训练 FLOPs 按数学验证第 7.1 节的每层矩阵乘账本计算。第 $i$ 个位置每层前向为 $113{,}770{,}496+16{,}384\,i$，序列长 4096 时平均为

$$
113{,}770{,}496+16{,}384\times2048.5=147{,}333{,}120 .
$$

冻结路径只做前向；可训练路径按前向、重算与反向计 3 倍；LoRA 每层前向为 2,719,744（注意力 557,056 加 8 个激活专家 2,162,688），按前向、重算、激活梯度与权重梯度计 4 倍；词表头前向 622,329,856，计 3 倍。由此：

| 样本类型 | 冻结层 | 可训练层 | 每 token GFLOPs |
|---|---:|---:|---:|
| 全程 $r=1$（$G_{\rm one}$ 全部，$G_{\rm two}$ 的 1/3） | 32 | 16（$F^1$ 12、$T$ 4） | 13.83 |
| 全程 $r=2$ 与开启类（$G_{\rm two}$ 的 1/2） | 32 | 28（$F^1$ 12、$F^2$ 12、$T$ 4） | 19.26 |
| 停止类（$G_{\rm two}$ 的 1/6） | 32 | 16，另有比例 $f$ 的位置执行 $F^2$ | $13.83+5.43f$ |
| $G_{\rm two}$ 平均（取 $f=0.7$） | | | 17.18 |

以全程 $r=1$ 为例：$32\times147{,}333{,}120+3\times16\times147{,}333{,}120+3\times622{,}329{,}856+16\times4\times2{,}719{,}744=13{,}827{,}702{,}784$。停止类中执行 $F^2$ 的位置，每个多出 $12\times3\times147{,}333{,}120+12\times4\times2{,}719{,}744=5{,}434{,}540{,}032$ FLOPs；比例 $f$ 是提示词与停止点之前的块占全部位置的比例，取决于数据，这里按 0.7 估计。四类加权平均为 $\tfrac13(13.83+19.26)+\tfrac16(17.63+19.26)=17.18$ GF。

两臂各 $2\times10^8$ token 的准入式沿用一天方案：

$$
\frac{2\times10^8}{v_{\rm two}}+\frac{2\times10^8}{v_{\rm one}}\le0.8\times10\times3600=28{,}800\ \text{s},
$$

$v$ 为 8 卡合计的实测输入 token/s。若 $v_{\rm one}=16{,}000$，则须 $v_{\rm two}\ge12{,}270$。按 FLOPs 比例 $17.18/13.83=1.242$ 估计，$v_{\rm two}\approx12{,}879$，两臂共 $12{,}500+15{,}529=28{,}029$ 秒，约 7.79 小时，满足准入。此时每卡约 $12{,}879\times17.18\times10^9/8\approx27.7$ TFLOP/s，为 H200 SXM BF16 稠密峰值 989.5 TFLOP/s 的 2.8%。吞吐能否达标取决于 MoE 路由与小批量内核的效率，以验收项 E11 的实测为准。

## 5. 阶段 2：同请求双动作标签

### 5.1 标签定义

生成器 $G_{\rm two}$ 冻结后，对每个请求 $d$（提示词长 $P_d$，参考答案 $A_d$ 有 $n_d$ 个 token）分别以 $r=1$ 与 $r=2$ 教师强制运行一次，记录

$$
\ell_d(r)=\frac{1}{n_d}\sum_{t\in A_d}-\log p^{(r)}\big(x_{d,t}\mid x_{d,<t}\big),
\qquad
\Delta\ell_d=\ell_d(2)-\ell_d(1).
$$

$\Delta\ell_d<0$ 表示第二轮使答案的平均 NLL 下降。成本记为每个答案 token 的完整账本成本 $c_d(r)=C_d(r)/n_d$，$C_d(r)$ 含提示词与答案全部位置上的 $S$、$F^1$、$T$、词表头、LoRA，$r=2$ 时再加 $F^2$ 与混合。两种轮数的成本差为

$$
\Delta c_d=c_d(2)-c_d(1)=\frac{C_{F^2+{\rm mix}}(P_d+n_d)}{n_d},
$$

即第二轮在提示词与答案全部位置上的费用，按答案 token 数归一。

标签按答案 token 数归一，是为了与评价口径一致。评价把每篇文档的 NLL 与成本都除以该文档的计分 token 数，再在文档间等权平均（数学验证第 12.1 节）。在价格 $\lambda$ 下，策略 $\pi$ 的目标

$$
L(\pi)+\lambda C(\pi)=\frac1D\sum_d\big[\ell_d(\pi_d)+\lambda c_d(\pi_d)\big]
$$

对文档可分，每篇文档单独取最小即可。文档 $d$ 选 $r=2$ 当且仅当 $\Delta\ell_d+\lambda\Delta c_d<0$，这正是附图的选择规则；控制器用预测值 $\Delta\hat\ell_d$ 与 $\hat C_2-\hat C_1$ 代替真实值。

### 5.2 教师强制评价等于查表

**命题 2。** 对任何只读取提示词信息的请求级策略 $\pi$，它在确认集上的教师强制 NLL 等于 $\frac1D\sum_d\ell_d(\pi_d)$，成本等于 $\frac1D\sum_d c_d(\pi_d)$ 加上控制器自身的账本费用。

**证明。** 决策发生在提示词末位，读取的 $h^1_P$、$z$ 与第 43 层首轮 KV 都在 $F^1$ 中算出，与之后选择的 $r$ 无关。请求级策略选定的 $r$ 在整次回答内不变，生成中没有补写或尾追赶（不变量 3）。H 与 Q 只读生成表示，不改变生成分布（不变量 4）。所以策略在请求 $d$ 上的教师强制输出与标签运行中 $r=\pi_d$ 的那一次逐位相同，NLL 与生成成本分别是 $\ell_d(\pi_d)$ 与 $c_d(\pi_d)$。证毕。

由此，所有策略族的教师强制校准与确认评价都只需查标签表，不再占用 GPU。命题依赖不变量 3、4，由验收项 E2–E6 检查。按行循环方案中动作会改变后续历史，必须在线执行，这里没有这一限制。

### 5.3 特征与缓存

控制器在提示词末位读取三类信息：

1. 已知状态 $z_d\in\mathbb R^4$：$\log(1+P_d)$、$\log(1+\text{提示词行数})$，以及“数学”“通用”两维来源独热编码。
2. 首轮表示 $h^1_{d,P}\in\mathbb R^{2048}$，加停止梯度。
3. 第 43 层首轮提示词 KV：每个位置 4 个 KV 头、头维 128，K 与 V 各 512 维，BF16 下每个位置 2,048 字节。

标签运行同时保存这三类信息，供 S4 训练使用。

### 5.4 数据角色与规模

评价沿用一天方案的 GSM8K 默认分桶，盐改为 `jev-v4-request2`：按 SHA256(UTF-8(`jev-v4-request2`) ‖ 0x00 ‖ UTF-8(题目原文)) 的 32 字节摘要作大端整数 mod 100，桶 0–44 为拟合，45–59 为校准，60–99 为确认，确认集约 2,989 篇。GSM8K 测试集已在 v3.3 作过确认集，只作自由生成的复用基准。

H 与 Q 是请求级模型，每个请求只提供一行样本。拟合请求不少于 20,000 个：GSM8K 拟合桶约 3,363 个，其余取自数学训练语料中预留、不参与生成训练的请求。这一规模与 v3.3 的 H 拟合行数（41,839）同一量级。所有评价请求都对生成训练数据做 13-gram 去污染。

标签运行的计算量很小。两次运行共用 $S$ 与 $F^1$，每 token 前向约为 64 层（$S$ 32、$F^1$ 12、$F^2$ 12、$T$ 两次各 4）加两次词表头；按 GSM8K 的短上下文约 8.7 GFLOPs。约 24,000 个请求、每个约 300 token 时，合计约 $7.2\times10^6\times8.7\times10^9\approx6.3\times10^{16}$ FLOPs，按 8 卡合计 $2.5\times10^{14}$ FLOP/s 约 4 分钟。

### 5.5 停止点标签

单向停止策略的选项是停止点 $s\in\{1,\ldots,K_d+1\}$：第 $1,\ldots,s-1$ 块取 $r=2$，其余取 $r=1$。$s=1$ 与 $s=K_d+1$ 分别是请求级的 $r=1$ 与 $r=2$，取自两次全程运行。第 $c$ 块覆盖位置 $[b_c,b_{c+1})$，块的轮数作用于这些位置；位置 $t-1$ 的输出给出 $x_t$ 的预测。

对每个内部停止点 $s\in\{2,\ldots,K_d\}$，以全程 $r=2$ 运行在位置 $b_s$ 之前的生成尾缓存为历史、以 $h^1$ 为输入，对位置 $b_s$ 及之后重跑一次生成尾与词表头，得到停止点为 $s$ 时的预测分布 $p^{[s]}$。$t\le b_s$ 时，$x_t$ 由 $b_s$ 之前的位置预测，这些位置取 $r=2$，生成尾的历史全部来自 $h^2$，预测与全程 $r=2$ 运行相同。所以

$$
\ell_d(s)=\frac1{n_d}\Big[\sum_{t\in A_d,\,t\le b_s}-\log p^{(2)}\big(x_{d,t}\mid x_{d,<t}\big)+\sum_{t\in A_d,\,t>b_s}-\log p^{[s]}\big(x_{d,t}\mid x_{d,<t}\big)\Big].
$$

成本 $c_d(s)$ 中，第二轮只覆盖提示词与前 $s-1$ 块。

由分块扩展的命题 1，取 $r=2$ 的位置上 $h^2$ 与全程 $r=2$ 运行相同，$h^1$ 与动作无关；由它的推论 1，预测只经生成尾的输入序列依赖动作，而重跑使用的正是停止点为 $s$ 时的输入序列。所以 $\ell_d(s)$ 就是停止策略的教师强制 NLL，命题 2 对单向停止策略同样成立：任何单向停止策略的教师强制评价都是在 $(d,s)$ 表上查表。这一等价由验收项 C2 检查。

各块等长时，尾部后缀运行的总长度为

$$
\sum_{s=2}^{K}\big(K-s+1\big)\frac nK=\frac nK\cdot\frac{K(K-1)}2=\frac{n(K-1)}2
$$

个答案 token。GSM8K 平均 $K=3.58$，提示词 100、回答 150 个 token 时，后缀运行约为两次全程运行计算量的 10%，标签运行合计仍在 5 分钟以内。每个拟合请求提供 $K_d-1$ 行停止样本，20,000 个拟合请求约 51,600 行。标签运行同时保存每个内部边界的首轮出口 $h^1_{d,b_c}$ 与边界状态 $z_{d,c}$（第 7.6 节），$h^1$ 在 BF16 下每个边界占 4 KiB。

## 6. 阶段 3：门槛 GL1、GL2 与 GL3

### 6.1 GL1：第二轮的平均效应

在校准文档上计算 $\Delta_{\rm loop}=-\frac{1}{D_{\rm cal}}\sum_d\Delta\ell_d$，即全部请求取 $r=2$ 相对全部取 $r=1$ 的 NLL 改善。GL1 要求 $\Delta_{\rm loop}\ge0.005$，且文档自助法单侧 95% 下界大于零。两者使用同一个检查点，只差轮数，是单因素比较。

### 6.2 GL2：两动作的对偶上界

记 $C(r)=\frac1D\sum_dc_d(r)$，以全部 $r=1$ 的成本为单位 1。随机分配策略以概率 $w$ 让每个请求整次取 $r=2$，其期望成本与期望 NLL 都是两个端点的凸组合；在预算 $B$ 处

$$
L_{\rm mix}(B)=L(1)+w(B)\big[L(2)-L(1)\big],
\qquad
w(B)=\frac{B-C(1)}{C(2)-C(1)},
$$

这与严格同成本插值在两个均匀端点之间的取值相同。

任何控制器在标签表上的同成本 NLL 都有下界。令 $x_d\in[0,1]$ 为请求 $d$ 取 $r=2$ 的概率，问题写成线性规划：

$$
\min_{x\in[0,1]^D}\ \frac1D\sum_d\big[\ell_d(1)+x_d\Delta\ell_d\big]
\quad\text{s.t.}\quad
\frac1D\sum_d\big[c_d(1)+x_d\Delta c_d\big]\le B .
$$

**命题 3。** 上述线性规划的最优值等于 $\sup_{\lambda\ge0}[O(\lambda)-\lambda B]$，其中 $O(\lambda)=\frac1D\sum_d\min\{\ell_d(1)+\lambda c_d(1),\ \ell_d(2)+\lambda c_d(2)\}$。最优解按单位成本收益 $\rho_d=-\Delta\ell_d/\Delta c_d$ 从大到小依次令 $x_d=1$，直到预算用完，最后一个请求取分数。

**证明。** 对约束引入乘子 $\lambda\ge0$，拉格朗日对偶函数为

$$
\min_{x\in[0,1]^D}\frac1D\sum_d\big[\ell_d(1)+\lambda c_d(1)+x_d(\Delta\ell_d+\lambda\Delta c_d)\big]-\lambda B .
$$

方括号对每个 $x_d$ 是线性的，最小值在 $x_d=\mathbf 1[\Delta\ell_d+\lambda\Delta c_d<0]$ 处取到，等于 $\min\{\ell_d(1)+\lambda c_d(1),\ell_d(2)+\lambda c_d(2)\}$，所以对偶函数就是 $O(\lambda)-\lambda B$。线性规划的可行域非空（$x=0$ 时成本为 $C(1)=1\le B$），强对偶成立，原问题最优值等于 $\sup_\lambda[O(\lambda)-\lambda B]$。所有 $\Delta c_d>0$ 时，这是分数背包问题，按 $\rho_d$ 从大到小装入是它的最优解。证毕。

整数解（每个请求只能取一个 $r$）与分数解至多差一个请求的贡献 $\max_d|\Delta\ell_d|/D$，确认集有数千篇时可以忽略。定义可分配空间

$$
\Gamma(B)=L_{\rm mix}(B)-\sup_{\lambda\ge0}\big[O(\lambda)-\lambda B\big].
$$

例：三个请求等权，$\Delta c_d$ 都是 0.25，$\Delta\ell_d$ 依次为 $-0.06$、$-0.02$、$+0.01$，$C(1)=1$，$C(2)=1.25$。取 $B=1+0.25/3$，恰好够一个请求取 $r=2$。随机分配时 $w=1/3$，$L_{\rm mix}=L(1)+\frac13\times\frac{-0.07}{3}=L(1)-0.00778$。下界把第一个请求设为 $r=2$，得 $L(1)-0.02$。所以 $\Gamma=0.02-0.00778=0.01222$。

候选预算为 1.0625、1.125、1.1875。按层调用数，全部取 $r=2$ 的相对成本在提示词位置为 $60/48=1.25$，在答案位置因词表头稀释约为 1.225；三个候选都在两个端点之间，大约对应 25%、50%、75% 的请求取 $r=2$。主预算取 $\Gamma(B)$ 最大的候选，并列取较小预算；超出两个端点实际成本范围的候选，在读取确认集前剔除并记录。GL2 要求所选预算处 $\Gamma(B)\ge0.005$。

### 6.3 分半上界（诊断）

$\Gamma(B)$ 用每个请求的实际标签选择轮数，单个参考答案的噪声会使它偏向乐观；loopjev 中有 14.92 个百分点的事后节省来自这类噪声。分半上界把每个答案按 token 顺序分成前后两半，用前半的 $\Delta\ell^{(a)}_d$ 按命题 3 的规则选择，在后半的 $\Delta\ell^{(b)}_d$ 上评价。

若请求的真实效应为 $\mu_d$，两半的偏差 $\varepsilon^{(a)}_d$、$\varepsilon^{(b)}_d$ 在给定 $\mu_d$ 时相互独立且均值为零，那么选择只依赖前半，$\mathbb E[\varepsilon^{(b)}_d\mid\text{选择}]=0$，后半上的评价值不含“用同一噪声选择再评价”的偏差。它仍然用了答案的前半信息，所以是一个乐观程度较低的参照，只作诊断，不作门槛。

### 6.4 门槛的后果

| GL1 | GL2 | 处理 |
|---|---|---|
| 通过 | 通过 | 控制器比较按第 8.3 节作确认性检验 |
| 通过 | 未通过 | 控制器照常训练与评价，全部比较只报告估计与区间 |
| 未通过 | 通过 | 继续，并注明第二轮的平均效应未达门槛、可分配空间来自请求间差异 |
| 未通过 | 未通过 | 不作控制器比较，只报告生成器对照与第 6 节的各个上界 |

### 6.5 GL3：单向停止相对请求级的额外空间

在校准文档的 $(d,s)$ 表上，按分块扩展第 6 节计算两类策略的对偶下界：

$$
\mathrm{LB}_{\mathcal P}(B)=\sup_{\lambda\ge0}\Big[\frac1D\sum_d\min_{o\in\mathcal O_d(\mathcal P)}\big(\ell_d(o)+\lambda c_d(o)\big)-\lambda B\Big].
$$

请求级的选项集合为 $\{1,K_d+1\}$，单向停止的为 $\{1,\ldots,K_d+1\}$。证明与命题 3 相同：拉格朗日松弛后，每个请求在自己的选项中取最小，下界对任何满足预算的规则都成立。单向停止包含请求级，所以

$$
\Delta_{\rm stop}(B)=\mathrm{LB}_{\rm req}(B)-\mathrm{LB}_{\rm stop}(B)\ge0 .
$$

GL3 要求主预算处 $\Delta_{\rm stop}(B)\ge0.005$。未通过时，即使按事后标签选择停止点，单向停止也最多只比请求级好 0.005。

GL3 同时报告分半版本。第 6.3 节的前后分半不适用于停止点：停止点都落在后半时，各选项在前半的 NLL 相同，前半无法区分它们。分半版本因此按答案位置的奇偶分组：在偶数组上求对偶下界的最优解（每个请求取 $\ell^{\rm even}_d(o)+\lambda c_d(o)$ 最小的选项，$\lambda$ 使预算恰好用尽），把选出的选项在奇数组上评价；请求级与单向停止都这样计算，再取两者之差。奇偶两组来自同一些块，块级的参考答案噪声在两组间共享，这一版本去掉的只是逐 token 噪声带来的选择偏差。

GL3 只决定 P4 的地位，不改变 GL1、GL2 的后果：

1. GL3 通过且第 6.4 节判为确认性检验时，P4 与 P1–P3 一起进入 Holm 族（第 8.3 节）。
2. GL3 未通过，或第 6.4 节判为只报告估计时，停止控制器照常训练（代价很小），P4 只报告估计与区间。
3. GL1 与 GL2 都未通过时不作控制器比较，P4 也不例外。

GL3 的结果与每块第二轮收益沿回答的分布（第 8.5 节）一起，作为是否推进第二、三级的依据。

## 7. 阶段 4：成本模型与控制器

### 7.1 公共成本模型

两种轮数的成本差 $\Delta c_d$ 在提示词长度与答案长度已知时可以精确计算，决策时只有答案长度 $n_d$ 未知。成本模型用岭回归预测 $\widehat{\mathbb E}[1/n_d\mid z_d]$，再把它代入账本，得到 $\hat C_1$、$\hat C_2$ 与 $\hat C_2-\hat C_1$。模型只读 $z_d$，供 R、H、Q 共用，比较各控制器时成本预测相同。评价一律使用实际账本。块边界的成本预测见第 7.6 节。

### 7.2 R、H 与阴性对照 N

三者的目标都是 $\Delta\ell_d$，样本权重都是文档等权，交叉验证折都按文档分组：

1. R：在 $z_d$ 上做岭回归（4 维加截距），岭系数网格 $\{10^{-6},\ldots,10^{1}\}$，选中边缘时向外扩展两个十倍点一次，并列取较小者。R 对应 v3.3 中只读位置与执行状态的基线。
2. H：多层感知机，结构为 $2052\to256\to256\to1$，GELU 激活，输入 $[h^1_{d,P};z_d]$ 按拟合折统计量标准化。以加权均方误差训练，AdamW 学习率 $10^{-3}$，权重衰减 0.01，每批 256 个请求，至多 100 个 epoch；从拟合请求中按文档哈希留出 10% 作验证，连续 5 个 epoch 不改善即停止，种子 17。
3. N：与 H 结构和训练完全相同，只是把 $h^1_{d,P}$ 换成按请求标识播种的 2048 维标准正态噪声。N 衡量模型容量与过拟合本身带来的“收益”；loopjev 的随机阴性对照在样本内回收了 24.34%。

### 7.3 只读查询控制器 Q

Q 的查询为 512 维，恰好等于第 43 层 4 个 KV 头乘以头维 128。初始查询由 $[h^1_{d,P};z_d]$ 线性映射得到：$q^0=W_{\rm in}\operatorname{std}([h^1_{d,P};z_d])$。对第 $k=1,2$ 层，把 $W^k_Q q^{k-1}$ 按头切成 4 段，每段与对应 KV 头的提示词键做点积注意力：

$$
a^k_j=\operatorname{softmax}\!\Big(\frac{K_{43,j}\,(W^k_Qq^{k-1})_j}{\sqrt{128}}\Big)^{\!\top}V_{43,j},
\qquad j=1,\ldots,4,
$$

$$
\tilde q^k=q^{k-1}+W^k_O[a^k_1;\ldots;a^k_4],\qquad
q^k=\tilde q^k+\operatorname{MLP}^k\big(\operatorname{LN}(\tilde q^k)\big),
$$

其中 MLP 为 $512\to1024\to512$。键与值按缓存原样读取（含 $k$ 归一化与旋转位置编码），查询不加位置编码。输出以 H 为起点学习残差：

$$
\Delta\hat\ell_Q=\Delta\hat\ell_H+w_{\rm out}^\top\operatorname{LN}(q^2)+b_{\rm out}.
$$

参数量逐项为：输入映射 $2052\times512+512=1{,}051{,}136$；每层 $W_Q$、$W_O$（各 $512\times512+512$）、MLP（$512\times1024+1024+1024\times512+512$）与一个层归一化合计 1,576,448，两层 3,152,896；输出前的层归一化 1,024 与输出 513。总计 4,205,569，约 4.21M。

Q 只读取已有 KV，不写任何生成缓存，也不增加 token。每次查询的计算量约为

$$
C_Q(P)\approx8.4\times10^6+4096\,P\ \text{FLOPs},
$$

其中 $4096P$ 是两层、四个头在 $P$ 个提示词位置上的点积与加权求和。Q 以与 H 相同的目标和权重训练，H 冻结（取同一折的交叉拟合预测），AdamW 学习率 $3\times10^{-4}$，权重衰减 0.01，每批 128 个请求，至多 50 个 epoch，早停规则同 H。

### 7.4 门控：查询的期望改善

把一次决策的代价写成 $\delta=\Delta\ell+\lambda\Delta c$，$\delta<0$ 时应取 $r=2$。设决策前的信息为 $\mathcal F$（H 可见的信息），查询 Q 后的信息为 $\mathcal G\supset\mathcal F$。记 $m=\mathbb E[\delta\mid\mathcal F]$，$M=\mathbb E[\delta\mid\mathcal G]$，由全期望公式 $\mathbb E[M\mid\mathcal F]=m$。

以“全部取 $r=1$”为参照，按信息 $\mathcal F$ 决策的期望代价增量为 $\min(0,m)$，查询后为 $\mathbb E[\min(0,M)\mid\mathcal F]$。查询带来的期望改善为

$$
I=\min(0,m)-\mathbb E\big[\min(0,M)\mid\mathcal F\big]\ \ge\ 0,
$$

不等号来自 $\min(0,\cdot)$ 的凹性与 Jensen 不等式。设 $M\mid\mathcal F\sim\mathcal N(m,s^2)$。截断正态的一阶矩给出

$$
\mathbb E\big[\min(0,M)\big]=\int_{-\infty}^{0}x\,\frac1s\varphi\!\Big(\frac{x-m}{s}\Big)\,dx
=m\,\Phi\!\Big(-\frac ms\Big)-s\,\varphi\!\Big(\frac ms\Big).
$$

$m\ge0$ 时，$I=s\varphi(m/s)-m\Phi(-m/s)$。$m<0$ 时，

$$
I=m-m\Phi(-m/s)+s\varphi(m/s)=m\Phi(m/s)+s\varphi(m/s)=s\varphi(|m|/s)-|m|\Phi(-|m|/s).
$$

两种情形合并为

$$
I=s\,\psi\!\Big(\frac{|m|}{s}\Big),\qquad \psi(t)=\varphi(t)-t\,\Phi(-t).
$$

$\psi$ 在 $t\ge0$ 上单调下降，$\psi(0)=\varphi(0)=0.3989$。决策越接近边界（$|m|$ 越小），查询越有价值，最大改善为 $0.3989\,s$。

门控实现附图的判断“预计查询改善 > λ × 查询成本”：

$$
\text{查询 Q}\iff s_d\,\psi\!\Big(\frac{|m_d|}{s_d}\Big)>\lambda\,c_{Q,d},
\qquad
m_d=\Delta\hat\ell_{H,d}+\lambda(\hat C_2-\hat C_1)_d,
$$

其中 $c_{Q,d}=C_Q(P_d)\,\widehat{\mathbb E}[1/n_d\mid z_d]$ 是按答案 token 归一的查询成本。$s_d^2=\operatorname{Var}(M\mid\mathcal F)$ 等于查询带来的预测变化的方差，用交叉拟合的 $(\Delta\hat\ell_Q-\Delta\hat\ell_H)^2$ 作目标，以与 H 输入相同、隐藏宽度 64 的多层感知机回归，输出经 softplus 保证非负（约 0.13M 参数）。高斯假设在校准集上检验：比较预测改善 $I$ 与实际改善的分箱均值。

按 FLOPs 账本，Q 的费用可以忽略。GSM8K 类请求取 $P=100$、$n=150$ 时，$C_Q\approx8.8\times10^6$ FLOPs，而整次请求在 $r=1$ 下约 $1.48\times10^{12}$ FLOPs，比值约 $6\times10^{-6}$。门控因此几乎总会查询，门控族与“总是查询”族近乎重合，主检验 P3 实际比较 H 与 Q。门控只有在成本计入首 token 延迟、或 Q 的规模显著增大时才起作用；成本口径列为待确认事项。

### 7.5 交叉拟合

拟合请求按文档分成 5 折。H、Q、N 与门控的方差模型都用折外预测：第 $k$ 折的 $\Delta\hat\ell_H$ 与 $\Delta\hat\ell_Q$ 由不含该折的模型给出，$s^2$ 的回归只使用折外预测。最终模型在全部拟合请求上重新训练，校准集与确认集不参与任何拟合。

### 7.6 停止控制器

停止决策只在第二轮仍在运行时做出，此时之前全部块都取 $r=2$，历史唯一，标签不需要行为策略。决策规则采用分块扩展第 5.1 节的一步前瞻：在边界 $b_c$（$2\le c\le K_d$）处，比较“现在停止”与“再执行一块第二轮后停止”。现在停止使 NLL 增加

$$
y_{d,c}=\ell_d(c)-\ell_d(c+1),
$$

同时节省第 $c$ 块上的第二轮费用

$$
c_d(c+1)-c_d(c)=\frac{U_{d,c}}{n_d},
$$

$U_{d,c}$ 为第 $c$ 块各位置上第二轮与混合的账本成本之和。$y_{d,c}$ 包含停止对之后各块的影响：停止改变生成尾的历史，后续块的预测随之改变。

边界处第 $c$ 块的长度与回答总长 $n_d$ 都未知。公共成本模型为此增加一个岭回归，以边界状态 $z_{d,c}$ 预测第 $c$ 块占回答的比例 $(b_{c+1}-b_c)/n_d$（6 维加截距，共 7 个参数），节省的估计值为这一比例乘以每个位置第二轮与混合的平均账本成本。三个停止控制器共用这一估计，评价一律使用实际账本。

三个停止控制器以 $y_{d,c}$ 为目标，与请求级的 R、H、N 一一对应：

1. R$_{\rm stop}$：在 6 维边界状态 $z_{d,c}$ 上做岭回归。$z_{d,c}$ 由 $\log(1+P_d)$、两维来源独热编码、块序号 $c$、$\log(1+m_{d,c})$ 与 $\log(1+\text{上一块长度})$ 组成，$m_{d,c}=b_c-P_d$ 是第 $c$ 块之前的回答 token 数。
2. H$_{\rm stop}$：结构为 $2054\to256\to256\to1$ 的多层感知机，输入为边界位置的首轮出口 $h^1_{d,b_c}$ 与 $z_{d,c}$，参数 592,129 个。$S$ 与 $F^1$ 的计算与动作无关，位置 $b_c$ 的首轮出口在决策前已经算出，决策只决定 $F^2$ 是否在该位置执行。
3. N$_{\rm stop}$：与 H$_{\rm stop}$ 相同，只是把 $h^1_{d,b_c}$ 换成按请求标识与块序号播种的 2048 维标准正态噪声。

样本权重按文档等权，每篇请求的 $K_d-1$ 行平分该文档的权重；岭系数网格、网络训练设置、交叉拟合与早停规则同第 7.2、7.5 节。

部署时，提示词末位仍由请求级控制器决定是否启用第二轮；启用后，在第一个满足

$$
\hat y_{d,c}<\lambda\,\widehat{\Big(\frac{U_{d,c}}{n_d}\Big)}
$$

的边界停止，没有边界满足时第二轮执行到回答结束。$\lambda$ 与提示词末位的决策共用，一个价格网格描出整条成本曲线。第一级不在块边界调用 Q。

由分块扩展的命题 2，停止问题单调时一步前瞻是最优停止规则。单调性在校准集上用真实标签检验：对价格网格中的每个 $\lambda$，用真实的 $y_{d,c}$ 与 $U_{d,c}/n_d$ 执行一步前瞻，报告它选出的停止点与事后最优停止点 $\arg\min_{2\le s\le K_d+1}\big[\ell_d(s)+\lambda c_d(s)\big]$ 相同的请求比例。

### 8.2 预算与价格网格

预算以“全部 $r=1$、不运行控制器”的文档平均每 token 完整账本为单位。每个策略族在校准集上取 64 个对数等距的价格 $\lambda$，覆盖从全部 $r=1$ 到全部 $r=2$ 的成本范围，读取确认集前锁定。教师强制评价是查表（命题 2），密集网格不增加 GPU 开销，并减小严格同成本插值的端点间距。

### 8.3 主检验与判定

在主预算 $B$ 处，主检验以严格同成本计算，正值表示后者 NLL 更低：

1. P1：$g_{\rm mix,R}=L_{\rm mix}(B)-L_R(B)$，已知状态的分配价值。
2. P2：$g_{RH}=L_R(B)-L_H(B)$，首轮表示的预测价值。
3. P3：$g_{H,HQ}=L_H(B)-L_{HQ}(B)$，只读查询的增益，计入查询成本。
4. P4：$g_{H,{\rm stop}}=L_H(B)-L_{\rm H+H_{stop}}(B)$，块边界停止的增益。两者在提示词末位用同一个 H，只差停止控制器。

主检验族由 GL3 决定（第 6.5 节）：P4 进入时为 P1–P4，族大小 $m=4$；否则为 P1–P3，$m=3$。族内各比较检验 $H_0:g\le0$，按 Holm 法在单侧 0.05 下控制族错误率：p 值从小到大排列，第 $k$ 个在前面都被拒绝时与 $0.05/(m-k+1)$ 比较，否则不拒绝。判定表中的单侧下界取对应的 Holm 水平分位（第一个用 $0.05/m$ 分位，$m=3$ 时为 1.667%，$m=4$ 时为 1.25%），使“有增益”与 Holm 拒绝一致；族外的比较用 5% 分位。判定表沿用[一天方案](EXPERIMENT_PLAN.v4-one-day.zh-CN.md)第 4.2 节的六档，实用门槛 $\delta_{\min}=0.005$ nat/token，夹逼失败时区间不可估。每个比较同时报告单侧下界、双侧 95% 区间与相对改善 $g/L_{\rm mix}(B)$。

文档自助法重采样 10,000 次，种子 20261016，每次重采样重算成本、夹逼端点与插值权重。

### 8.4 样本量

按数学验证第 15 节的公式，取 $\sigma=0.067$、$\delta=0.005$、功效 0.8，第一步 Holm 水平按较严的 $m=4$ 取 $0.05/4=0.0125$（$z=2.2414$）：

$$
n\ge\left(\frac{(2.2414+0.8416)\times0.067}{0.005}\right)^2=(3.0830\times13.4)^2=1706.7,
$$

确认集至少 1,707 篇。$m=3$ 时第一步水平为 $0.05/3$（$z=2.1280$），$n\ge(2.9696\times13.4)^2=1583.5$，至少 1,584 篇。默认确认集约 2,989 篇，两种情形都满足，全部可以查表评价。

若真实效应只有 0.002，2,989 篇下 $m=4$ 时的检出概率为 $\Phi(0.002\sqrt{2989}/0.067-2.2414)=\Phi(-0.609)\approx0.27$，$\sigma=0.051$ 时为 $\Phi(-0.097)\approx0.46$；$m=3$ 时分别为 $\Phi(-0.496)\approx0.31$ 与 $\Phi(0.016)\approx0.51$。确认集按实用门槛 0.005 设计，0.002 量级的效应大概率得到“未检出”或“低于门槛”，这一点在运行前写明。读取确认集前，用校准集重估 $\sigma$ 并报告预测功效。

### 8.5 次要分析

以下比较只报告估计与区间：

1. $G_{\rm two}$ 取 $r=1$ 对 $G_{\rm one}$：单因素对照，衡量三分之二的请求在全部或部分位置经第二轮训练对单轮质量的影响。
2. Q（总是查询）对 HQ：门控的价值。
3. N 对 R：阴性对照。N 显著优于 R 时，说明 H 一类模型的收益含过拟合成分。
4. 对偶上界、分半上界与实际达到值的比较。
5. 自由生成：GSM8K 测试集中 256 题，每题至多 512 token，设置为 $G_{\rm one}$、$G_{\rm two}$ 全部 $r=1$、全部 $r=2$，以及主预算处的 R、H、HQ 与 H＋H$_{\rm stop}$。价格沿用教师强制校准的锁定值，报告逐题正确率差、配对区间、回答长度、截断比例与实际成本。$r$ 会改变回答长度，自由生成的实际成本与教师强制成本不同，两者分开报告。
6. 通用文本：在预留的通用请求上报告 $G_{\rm two}$ 与 $G_{\rm one}$ 的 NLL 以及控制器的分配，作描述，不作检验。
7. 块边界的表示价值：H＋R$_{\rm stop}$ 对 H＋H$_{\rm stop}$，两者只差停止控制器的输入特征。阴性对照：H＋N$_{\rm stop}$ 对 H＋R$_{\rm stop}$。
8. 停止行为：一步前瞻与事后最优停止点的一致比例（第 7.6 节）；停止点在回答中相对位置的分布；单向停止的对偶下界、分半版本与 H＋H$_{\rm stop}$ 实际达到值的差距。
9. 每块的第二轮收益：两次全程运行给出第 $c$ 块在 $r=2$ 与 $r=1$ 下按 token 平均的 NLL 之差，按块在回答中的相对位置分组报告其分布（分块扩展第 6 节）。收益集中在回答后段时，第二级“单次切换”才有价值。

| C2 | 停止点标签：在线执行单向停止（增量解码，在 $b_s$ 处停止第二轮）的 logits 对第 5.5 节的全程 $r=2$ 前缀加尾部后缀重跑 | FP32、16 篇、每篇全部内部停止点：最大绝对误差 $\le10^{-4}$ |
| C3 | 成本计数：32 篇随机停止点的请求与 8 篇开启类训练样本 | $F^2$ 计数等于最后一个 $r=2$ 位置及之前的位置数，开启类的补写在切换时刻计入；与账本逐项相等 |

## 10. 资源与 24 小时安排

$G_{\rm two}$ 训练时每卡显存估算如下：

1. 冻结基座 BF16 权重 56.9 GiB（30,532,122,624 个参数）。
2. 生成侧 281,282,560 个参数的 FP32 主副本、梯度与 AdamW 两个矩，16 字节/参数，约 4.2 GiB。
3. 激活：按层边界重算时，$r=2$ 样本每 token 保存 28 个可训练层的输入与 $u_i$、$h_i^1$，共 30 个 2048 维 BF16 向量，即 122,880 字节；一条 4096 token 的序列约 0.47 GiB，每卡每步 4 条约 1.9 GiB，加重算峰值约 3 GiB。
4. 词表 logits 按 1,024 token 分块计算交叉熵，logits 与梯度约 1.2 GiB。

合计约 65 GiB，低于 H200 每卡 143,771 MiB（约 140.4 GiB）的 85%，即 119.3 GiB。数据并行时每卡放一份完整模型即可，以 E10 的实测为准。

| 时段 | 工作 | 完成条件 |
|---|---|---|
| 0–6 小时 | S0 验收、显存与吞吐短跑 | E1–E11、M1–M5、C1–C3 通过 |
| 6–16 小时 | S1：$G_{\rm two}$ 与 $G_{\rm one}$ 各 $2\times10^8$ token | 两个检查点锁定 |
| 16–17 小时 | S2 双动作与停止点标签、S3 门槛与主预算 | GL1、GL2、GL3 判定，主预算锁定 |
| 17–19 小时 | S4 控制器（含停止控制器）交叉拟合与训练、S5 价格校准 | 全部预测器与价格锁定 |
| 19–21 小时 | S6 确认评价（查表）与自由生成 | 主检验与次要分析完成 |
| 21–24 小时 | 核验、保存与报告 | 检查点、标签表、逐篇指标与阶段记录 |

吞吐不足时依次缩减：自由生成从 256 题减为 128 题；取消通用文本的描述性评价；仍不足时报告预计延长时间。两臂各 $2\times10^8$ token 与确认集规模不缩减，后者只需查表。

中止条件如下：

1. E1–E11、M1–M5 或 C1–C3 失败时停下修复，只许重跑一次，第二次失败即中止并报告。
2. GL1 与 GL2 都未通过时，不作控制器比较。
3. 数值异常时保存状态并中止相应阶段，成功完成的检查不能替代未通过的检查。

## 11. 风险

1. 第二轮的平均效应不足。Qwen3-30B-A3B 没有循环预训练，第 32–43 层再执行一次能否降低 NLL 没有测量；GL1 直接检验这一点。
2. 请求间差异难以预测。loopjev 的四个免训练读出回收率为 0；H、Q 是否优于 R 由 P2、P3 检验，N 衡量模型容量本身的虚假收益。
3. 单个参考答案带来标签噪声，对偶上界偏乐观；分半上界给出乐观程度较低的参照。
4. 训练时一半位置取 $r=2$，只与 $B=1.125$ 附近的部署比例一致；v3.1 的相关证据只有单种子、无区间。
5. 三分之二的请求在全部或部分位置经第二轮训练，对单轮质量的影响由 $G_{\rm two}(r=1)$ 对 $G_{\rm one}$ 的单因素比较测量。
6. 自由生成中 $r$ 会改变回答长度，实际成本与教师强制成本不同。
7. Qwen 指令模型的训练数据是否包含 GSM8K 无法核实；若包含，绝对 NLL 偏低，同一文档上的配对比较仍然有效。
8. 按 FLOPs 计费时门控几乎不起作用，P3 实际比较 H 与 Q。
9. GSM8K 的回答平均只有 3.58 行，单向停止相对请求级的额外空间受块数限制，大小由 GL3 直接测量。
10. 一步前瞻的最优性依赖停止问题的单调性（分块扩展命题 2）。某一块的第二轮收益很小、后面的块收益又变大时，一步前瞻会过早停止；第 7.6 节在校准集上测量它与事后最优停止点的一致比例。
11. 部署用到的“$h^2$ 历史接 $h^1$”只出现在停止类中，占 $G_{\rm two}$ 训练请求的 1/6。生成尾若没有学好这种历史，停止后的 NLL 会升高；停止点标签直接测量停止后的 NLL，这一损失体现为 GL3 的空间变小，不进入 P1–P3。

## 12. 待用户确认的事项

1. 训练数据：通用文本 $10^8$ 与数学解答 $10^8$ token 的数据集名称、版本与许可，以及通用文本整篇监督的格式。
2. 评价与拟合数据：GSM8K 默认分桶，以及补足 20,000 个拟合请求的数学语料来源。
3. 实用门槛：沿用 0.005 nat/token，或改为相对门槛。
4. Q 的成本口径：只计 FLOPs（门控几乎总是查询），或把首 token 延迟计入成本。
5. 是否保留单轮对照 $G_{\rm one}$（另需约 3.5 小时训练）。
6. 8×H200 节点的使用窗口，以及运行是否允许超过 24 小时。
7. 本方案与按行循环方案的关系：以本方案为执行依据，还是两者并行。
8. 块的定义：数学解答按行（超过 64 token 的行在 64 token 处切开），通用文本按句（超过 32 token 的句子在 32 token 处切开），见第 4.2 节。
