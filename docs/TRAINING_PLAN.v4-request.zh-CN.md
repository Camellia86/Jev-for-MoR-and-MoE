# v4 请求级两动作循环架构训练计划

协议 ID 为 `jev-v4-request2`，状态为训练计划（设计），待用户确认数据与门槛后开始实现执行器与分析代码，并按第 9 节验收（2026-10-15）。架构以[附图](ARCHITECTURE_REQUEST.v4.dot)为准，即校正版请求级两动作循环架构：整次回答只决策一次，只有一个生成尾，总轮数 $r\in\{1,2\}$。本计划对附图结构只有一处修改，即下一段的单向停止；含这一修改的完整架构见[单向停止架构图](ARCHITECTURE_REQUEST.v4-stop.dot)。

本计划采用[分块扩展](CHUNK_ROUTING.v4-request.zh-CN.md)的推荐方案，设定如下：

1. 第二轮的历史缺口按精确补写处理（B0），生成尾按实际送入的出口维护历史（T0）。
2. 部署只用第一级“单向停止”：启用第二轮的回答可以在块边界停止第二轮，此后取 $r=1$ 到结束。附图的不变量 3 相应改为“轮数只能在块边界从 2 降为 1”。
3. 生成训练使用四类轮数日程（第 4.2 节）。
4. 单向停止相对请求级的事后额外空间由 GL3 测量（第 6.5 节），作为是否推进第二、三级的依据；停止控制器及其主检验 P4 见第 7.6、8.3 节。

按行循环方案（`ARCHITECTURE*.v4.zh-CN.md`、一天方案与 `EXPERIMENT_CONFIG.v4-rowloop.json`）是与本计划并列的另一种方案。混合专家（Mixture of Experts，MoE）维度、低秩适配（Low-Rank Adaptation，LoRA）参数量、每层矩阵乘账本与统计方法沿用其中已经核实的推导；实验依据见[实验汇总](EXPERIMENT_SUMMARY.zh-CN.md)。

本计划回答四个问题：

1. 第二轮循环能否降低负对数似然（Negative Log-Likelihood，NLL）。
2. 按请求选择轮数，在同样的计算预算下是否优于随机分配。
3. 首轮表示读出 H 与只读查询控制器 Q，能在多大程度上预测哪些请求值得第二轮。
4. 在块边界提前停止第二轮，能否在请求级决策之外进一步改善同成本 NLL。

## 1. 架构要点与训练对象

基座为 Qwen3-30B-A3B-Instruct-2507（版本 `0d7cf239`）：48 层，隐藏维 2048，每层 128 个前馈专家、每 token 激活 8 个。下表列出各部件及其训练方式：

| 部件 | 范围或输入 | 训练方式 | 可训练参数 |
|---|---|---|---:|
| 共享前缀 $S$ | 第 0–31 层 | 冻结 | 0 |
| 首轮 $F^1$ | 第 32–43 层 | 生成 LoRA，阶段 1 训练 | 210,960,384 |
| 第二轮 $F^2$ | 第 32–43 层 | 与 $F^1$ 共用权重和 LoRA，键值（Key-Value，KV）缓存独立 | 0（共用） |
| 混合向量 $g$ | $\mathbb R^{2048}$ | 阶段 1 训练，初值为 0 | 2,048 |
| 生成尾 $T$ | 第 44–47 层 | 生成 LoRA，阶段 1 训练 | 70,320,128 |
| 最终归一化与词表头 | 原模型 | 冻结 | 0 |
| H | 提示词末位 $h^1_P$ 与已知状态 $z$ | 生成器冻结后训练 | 591,617 |
| 对照 Z、N、R | Z 只读 $z$；N 读噪声与 $z$；R 为 $z$ 上的岭回归 | 生成器冻结后训练，只用于比较 | 67,329；591,617；5 |
| 公共成本模型 | 提示词末位读 $z$，块边界读 $z_{d,c}$；账本系数由 $P_d$、$b_c$ 精确计算 | 三个岭回归：$\Delta c$、$1/n$、$U/n$（第 7.1、7.6 节） | 10、5、14 |
| Q | 第 43 层首轮提示词 KV、$h^1_P$、$z$ | 生成器冻结后训练 | 约 4.21M |
| 门控 | $h^1_P$、$z$、H 的预测、成本预测与价格 $\lambda$ | 生成器冻结后训练，回归查询的真实收益 $\Delta^{\rm Q}(\lambda)$（第 7.4 节） | 135,873 |
| 停止控制器 H$_{\rm stop}$ | 块边界的 $h^1$ 与边界状态 $z_{d,c}$ | 生成器冻结后训练 | 592,129 |
| 停止侧对照 Z$_{\rm stop}$、N$_{\rm stop}$、R$_{\rm stop}$ | Z$_{\rm stop}$ 只读 $z_{d,c}$；N$_{\rm stop}$ 读噪声与 $z_{d,c}$；R$_{\rm stop}$ 为 $z_{d,c}$ 上的岭回归 | 生成器冻结后训练，只用于比较 | 67,841；592,129；7 |

LoRA 取秩 16、缩放 32，$A$ 随机初始化、$B=0$，覆盖注意力的 Q、K、V、输出投影和每个专家的 gate、up、down 投影。每层 LoRA 参数为 17,580,032 个（[数学验证](ARCHITECTURE_MATH.v4.zh-CN.md)第 7.2 节），生成侧共 $16\times17{,}580{,}032+2048=281{,}282{,}560$ 个。

记位置 $i$ 的输入为 $x_i$，执行顺序为

$$
\begin{aligned}
u_i&=S(x_{\le i}),\\
h_i^1&=F_{\theta+\Delta}\big(u_i;\,C^1_{<i}\big),\\
v_i^2&=u_i+\tanh(g)\odot\big(h_i^1-u_i\big),\\
h_i^2&=F_{\theta+\Delta}\big(v_i^2;\,C^2_{<i}\big),\\
p_i&=\operatorname{softmax}\!\Big[W_{\rm vocab}N_{\rm f}\big(T_{\phi}(h_i^{(r_i)};\,C^T_{<i})\big)\Big].
\end{aligned}
$$

其中 $C^1$、$C^2$、$C^T$ 分别是首轮、第二轮与生成尾的 KV 缓存，$\theta$ 为冻结基座权重，$\Delta$ 为第 32–43 层共用的 LoRA 增量，$\phi$ 为生成尾的 LoRA，$r_i$ 为位置 $i$ 的轮数。轮数在提示词末位选定；取 2 时可以在块边界降为 1，此后保持 1 到回答结束（第 7.6 节）。$F^2$ 覆盖从第一个位置到最后一个 $r_i=2$ 的位置（分块扩展推论 3）。

附图列出 5 条执行不变量，训练按以下方式落实：

1. 第二轮在提示词上也完整预填充：凡是有块取 $r=2$ 的训练样本，$F^2$ 都覆盖整段提示词，成本账本单列这部分费用。
2. $F^1$、$F^2$ 共享权重而不共享 KV：自动微分把两轮对共用 LoRA 的梯度相加，两轮的缓存分开存放。
3. 轮数只能在块边界从 2 降为 1（附图原文为“生成中不切换深度，因此无历史补写或尾追赶”，单向停止改动了这一条）：部署时第二轮覆盖提示词与停止点之前的位置，没有历史补写，单尾也不需要追赶。训练日程中的开启类样本按精确补写执行（第 4.2 节），只用于让生成尾见过 $h^1$ 历史后接 $h^2$ 的情形。
4. H、Q、门控与停止控制器只读生成表示：控制器在生成器冻结后训练，读取的表示加停止梯度；验收项 E5 检查开启 Q 不改变生成分布。
5. 附图取代此前与正文冲突的自动附图：本计划以附图为准，唯一的结构修改是文首所述的单向停止（即上面第 3 条），修改后的完整架构见[单向停止架构图](ARCHITECTURE_REQUEST.v4-stop.dot)。

## 2. 实验依据与设计约束

### 2.1 先训练生成器，再训练控制器

v3.2 追加实验在只差控制损失的两臂上测得，控制损失使固定日程下的生成 NLL 升高 0.0016 [0.0005, 0.0028]；v3.3 在三个种子上复现为 +0.00168 [0.00134, 0.00203]。两组数字来自同一设定：以 Huginn-0125 上 v3.1 先导中 SCHED-A 的 LoRA 检查点（种子 17）为起点，在 GSM8K 上继续训练 93 次更新；结论的适用范围限于这一模型、起点与训练量。本计划沿用两阶段训练：先训练并冻结生成器，H 与 Q 读取的表示加停止梯度，控制器的梯度在构造上不进入生成参数，所以无论这一损害在本计划的设定下有多大，冻结方案都能避免它。

### 2.2 请求级的可分配空间

请求级决策在已有实验中有三组证据，方向并不一致：

1. v2.1 在通用文本上每请求决策一次。预算 1 处，事后最优只比纯深度 16 好 0.0019；预算 0.35 处，事后上界为 0.0425，计入控制开销的跨半选择评价为 0.0163（v2.1 报告称为分半上界，用前 64 个目标 token 选择深度、后 64 个评价）。空间大小取决于预算点。
2. v3.1 第 0 阶段在 GSM8K 上，冻结模型的问题级策略相对静态混合改善 0.0436 [0.0348, 0.0520]，但它的成本为 0.5102，超出预算 2%，不能直接与同成本策略比较。
3. loopjev 的 Huginn 逐题深度探针（ARC-Challenge validation，299 题）中，事后最优分配相对固定 32 步节省 40.43%（区间 35.26%–45.44%），其中 14.92 个百分点来自 51 道正确性不单调的题；只按“该深度及更深都答对”的稳定口径分配，节省降为 27.99%。四个免训练读出在二折交叉验证下回收率全部为 0，与题目无关的随机数阴性对照在样本内回收了 24.34%。

这三组结果给本计划三条约束：

1. 事后上界会被单一样本的噪声抬高。本计划在对偶上界之外再报告跨半选择评价（第 6.3 节）：用答案的一半选择、另一半评价，只作诊断。
2. 免训练读出没有识别出难度信号，H 与 Q 必须训练。H 的对照是结构与训练流程相同、只读已知状态的 Z；阴性对照 N 把 H 读取的首轮表示换成噪声。loopjev 的 24.34% 是样本内的回收；本计划的控制器一律在拟合请求之外评价，读噪声特征的 N 在期望上不优于只读已知状态的最优规则（第 7.2 节）。
3. 可分配空间随预算点变化，主预算在校准集上按上界选定（第 6.2 节）。

### 2.3 训练时的轮数分布

v3.1 在先导校准集（223 篇，单种子，无区间）上，按冻结位置日程训练的 SCHED-A 对齐预算后 NLL 为 0.8778，对五个深度均匀训练的 FMIX-A 为 0.8927，前者好 0.0149。训练分布接近部署分布更有利。本计划的部署比例取决于预算，候选预算的中点 $B=1.125$ 约有一半请求取 $r=2$，生成训练因此让一半位置取 $r=2$。四类日程下（第 4.2 节），块等长且切换点均匀时，停止类与开启类各有一半回答位置取 $r=2$，回答位置取 $r=2$ 的比例为 $\tfrac13+\tfrac16\times\tfrac12+\tfrac16\times\tfrac12=\tfrac12$；提示词位置随第一块，取 $r=2$ 的比例为 $\tfrac13+\tfrac16=\tfrac12$。

### 2.4 统计方法

评价沿用 v3.3 的严格同成本插值与文档配对自助法。v3.3 实验 A 的自助标准差 0.00105 折合逐篇差标准差 $0.00105\times\sqrt{2397}=0.0514$；v3.2 阶段一的规划值为 0.067。本计划按 0.067 规划样本量，在校准集上重估后再报告功效。v3.3 的检出只达到单侧口径，双侧区间含零。本计划把检出与区间分开规定：确认族内的检出由 Holm 调整 p 值决定，是否达到实用门槛由 Bonferroni 同时界判断，每个比较另报告边际双侧 95% 区间（第 8.3 节）。

### 2.5 块级粒度

块级粒度的证据有限，详见[分块扩展](CHUNK_ROUTING.v4-request.zh-CN.md)第 1 节：

1. v3.1 第 0 阶段中，按行分配深度相对静态混合改善 0.0342 [0.0276, 0.0408]。问题级策略的同成本比较只出现在 [v3.1 计划](EXPERIMENT_PLAN.v3.1.zh-CN.md)第 2.4 节的诊断表中，结果文件里没有这组数字。
2. GSM8K 解答平均只有 3.58 行（v3.2 读出训练集 4,111 篇共 14,703 行），块数少。
3. Huginn 上未经训练的 KV 缺口每缺一轮约损失 0.013 nat/token。

本计划因此只部署不产生缺口的单向停止，并在训练停止控制器之前用 GL3 测量它相对请求级的事后额外空间。

## 4. 阶段 1：生成训练

### 4.1 两条生成臂

$G_{\rm two}$ 是本架构的生成器：每条训练请求按哈希分到四类轮数日程之一（第 4.2 节）。$G_{\rm one}$ 是单轮对照：结构、数据、数据顺序、初始化种子、优化器与训练量都与 $G_{\rm two}$ 相同，所有请求都取 $r=1$，没有混合向量 $g$。

两臂只差训练时的轮数分配，所以 $G_{\rm two}$ 取 $r=1$ 时与 $G_{\rm one}$ 的 NLL 差，衡量的是“三分之二的请求在全部或部分位置经第二轮训练”对单轮质量的影响。$r=1$ 路径在本架构中就是普通的单轮 LoRA 模型，两臂在 $r=1$ 下的计算图与 LoRA 配置逐项相同。

### 4.2 数据、轮数分配与打包

生成训练沿用一天方案的配额：每臂 $2\times10^8$ 个非填充输入 token，通用文本与数学解答各 $10^8$。数学样本以题目为提示词、以完整解答（含最终答案）为监督目标，只对解答 token 计损失；通用文本整篇作为一次请求，全部 token 参与监督。数据集名称与版本由用户确认（第 12 节）。

回答按块划分：数学解答每行一块，超过 64 token 的行在 64 token 处切开；通用文本按句切分，超过 32 token 的句子在 32 token 处切开。记请求 $d$ 的提示词占位置 $1,\ldots,P_d$，回答 token 为 $x_{d,P_d+1},\ldots,x_{d,P_d+n_d}$，共 $K_d$ 块。位置 $i$ 输入 $x_{d,i}$，输出给出 $x_{d,i+1}$ 的预测；模型执行位置 $1,\ldots,P_d+n_d-1$，最后一个回答 token 不再输入。边界按预测位置定义：$b_1=P_d$，$b_{K_d+1}=P_d+n_d$；第 $c$ 块有 $n_{d,c}=b_{c+1}-b_c$ 个 token，$\sum_cn_{d,c}=n_d$，这些 token $x_{d,b_c+1},\ldots,x_{d,b_{c+1}}$ 由位置 $[b_c,b_{c+1})$ 预测，块的轮数作用于这些位置。$c\ge2$ 时，边界位置的输入 $x_{d,b_c}$ 是第 $c-1$ 块的最后一个 token（数学解答中是行末换行符，或长行切开处的第 64 个 token），边界只由 $x_{d,\le b_c}$ 判定。

执行顺序决定每个量的时刻。提示词各位置依次执行 $S$ 与 $F^1$，位置 $j$ 上的 $u_j$、$h^1_j$ 与首轮 KV 属于时刻 $j$；提示词末位读取 $h^1_{P_d}$ 做请求级决策，再按所选轮数对提示词执行 $F^2$（$r=2$ 时）与生成尾预填充，这一决策以及提示词各位置的 $h^2_j$、生成尾缓存与 logits 都属于时刻 $P_d$。回答位置 $i$（$P_d<i\le P_d+n_d-1$）依次执行 $S$、$F^1$、边界处的停止决策、$F^2$（第二轮仍在运行时）、生成尾与词表头，这些量都属于时刻 $i$。时刻 $i$ 的量只依赖 $x_{\le i}$。

边界 $b_c$ 的轮数决策在时刻 $b_c$ 做出：$x_{b_c}$ 已经输入，$h^1_{b_c}$ 已经算出，决策决定位置 $b_c$ 是否执行 $F^2$，影响 $x_{b_c+1}$ 及之后的预测。提示词末位的请求级决策是 $c=1$ 的情形，它同时决定提示词预填充送入生成尾的出口。第 $c$ 块之前的回答 token 数为 $m_{d,c}=b_c-P_d$，第 $c$ 块长 $n_{d,c}$。例：提示词 100 个 token，回答三行依次 40、50、60 个 token，则 $b_1=100$、$b_2=140$、$b_3=190$、$b_4=250$，$m_{d,2}=40$、$m_{d,3}=90$；边界 $b_2$ 的决策在输入第一行末的换行符 $x_{140}$ 之后做出，影响第二行首个 token $x_{141}$ 起的预测。

请求 $d$ 的轮数日程由哈希决定。令

$$
\eta_d=\operatorname{int}_{\rm BE}\big[\operatorname{SHA256}(\text{UTF-8}(\texttt{jev-v4-request2-r})\,\|\,\texttt{0x00}\,\|\,\text{UTF-8}(\text{请求标识}))\big],
$$

$\operatorname{int}_{\rm BE}$ 把 32 字节摘要读作大端整数，写法与 v3.1 的分桶规则相同。按 $\eta_d\bmod6$ 分配日程：

| $\eta_d\bmod6$ | 日程 | 比例 | 各块轮数 |
|---|---|---:|---|
| 0、1 | 全程 $r=1$ | 1/3 | 全部为 1 |
| 2、3 | 全程 $r=2$ | 1/3 | 全部为 2 |
| 4 | 停止 | 1/6 | 第 $1,\ldots,s_d-1$ 块为 2，其余为 1 |
| 5 | 开启 | 1/6 | 第 $1,\ldots,s_d-1$ 块为 1，其余为 2 |

切换点 $s_d$ 在内部块边界 $\{2,\ldots,K_d\}$ 上均匀抽取：用盐 `jev-v4-request2-s` 按同样写法得到整数，对 $K_d-1$ 取模后加 2。$K_d=1$ 时没有内部边界，停止类按全程 $r=2$、开启类按全程 $r=1$ 处理。提示词位置按第一块的轮数送入生成尾。哈希与数据顺序无关，各类日程在每个数据来源内的比例相同。

训练按精确补写语义执行（分块扩展的 B0＋T0）：凡是有块取 $r=2$ 的样本，$F^2$ 覆盖到最后一个取 $r=2$ 的位置为止。全程 $r=2$ 与开启类覆盖全篇，开启类前缀上的第二轮只供后缀的第二轮注意力读取；停止类覆盖提示词与停止点之前的块。生成尾在每个位置读取该位置实际选择的出口。开启类只出现在训练中，作用是让生成尾见过“$h^1$ 历史接 $h^2$ 当前”的情形，第二级“单次切换”需要这种情形；第一级部署只用到停止。

打包分两个流。流一为全程 $r=1$ 的请求，不执行 $F^2$。流二为其余三类，执行器把每篇请求需要第二轮的前缀另行打包给 $F^2$，按文档隔离注意力。每个全局批次 32 条序列，流一按 11、11、10 条循环轮取，其余来自流二；每三个批次共 32 条来自流一、64 条来自流二，比例恰为 1:2，与日程比例一致。哈希分出的两流 token 数只在期望上为 1:2，训练末尾某一流先用尽时，余下批次全部取自另一流。

### 4.3 目标与优化

$G_{\rm two}$ 最小化批次内监督 token 的平均 NLL：

$$
\mathcal L_{\rm gen}(\Delta,\phi,g)
=\frac{1}{\sum_{d\in\mathcal B}|A_d|}
\sum_{d\in\mathcal B}\sum_{t\in A_d}
-\log p_{\Delta,\phi,g}\big(x_{d,t}\mid x_{d,<t};\,\mathbf r_d\big),
$$

其中 $\mathcal B$ 为批次中的请求，$A_d$ 为请求 $d$ 的监督 token 集合，$\mathbf r_d=(r_{d,i})_i$ 为请求 $d$ 按日程确定的逐位置轮数。$x_{d,t}$ 的预测由位置 $t-1$ 的输出给出，只依赖 $i\le t-1$ 的 $r_{d,i}$。$G_{\rm one}$ 的目标相同，只是全部 $r_{d,i}=1$，没有参数 $g$。

两臂的优化设置与一天方案一致：AdamW，学习率在前 5% 更新内从零升到 $10^{-4}$，再余弦降到 $10^{-5}$；LoRA 权重衰减 0.01，$g$ 的权重衰减为 0；梯度范数裁剪阈值 1；BF16 激活与 FP32 主参数；序列长度 4096；全局批量 131,072 token；激活重算；种子 17。每臂 $2\times10^8/131{,}072=1525.9$，取 1,526 次更新。

### 4.4 零初始化等价与 $g$ 的梯度

**命题 1。** 若 $g=0$，则对任意 LoRA 参数，$r=2$ 与 $r=1$ 在每个位置给出相同的预测分布。若同时所有 LoRA 增量为零，两者都等于原模型。

**证明。** $\tanh(0)=0$，所以 $v_i^2=u_i$ 对所有位置成立。$F^2$ 与 $F^1$ 使用同一组权重 $\theta+\Delta$，第一层的输入在所有位置上相同。对层号归纳：设第 $l$ 层（$32\le l\le43$）在所有位置 $j\le i$ 上，第二轮输入等于首轮输入。第 $l$ 层的 K、V 是该层输入经同一组投影得到的，所以第二轮缓存 $C^{2,l}_{<i}$ 与首轮缓存 $C^{1,l}_{<i}$ 逐项相同。当前位置的查询、注意力权重、注意力输出与 MoE 输出也都相同，所以第 $l+1$ 层的输入在所有 $j\le i$ 上相等。归纳到第 43 层得 $h_i^2=h_i^1$。生成尾收到相同的出口序列，预测分布相同。若所有 LoRA 增量为零，第 32–47 层都回到原权重，两条路径都等于原模型。证毕。

这一论证对逐块任意的轮数序列同样成立：$g=0$ 时凡是执行第二轮的位置都有 $h_i^2=h_i^1$，生成尾收到的出口序列与轮数无关，四类日程在训练开始时彼此等价。

$g$ 的梯度由链式法则得到：

$$
\frac{\partial\mathcal L}{\partial g}
=\sum_i\frac{\partial\mathcal L}{\partial v_i^2}\odot\operatorname{sech}^2(g)\odot\big(h_i^1-u_i\big),
$$

求和遍及执行 $F^2$ 的位置，含开启类中只供注意力读取的前缀；$\partial\mathcal L/\partial v_i^2$ 包含经第二轮 KV 传到之后位置的梯度。$g=0$ 时 $\operatorname{sech}^2(0)=1$，梯度化为 $\sum_i\partial\mathcal L/\partial v_i^2\odot(h_i^1-u_i)$。零初始化因此保留了 $g$ 的一阶学习通路：首轮出口与前缀出口不同时，梯度经这条通路到达 $g$。批次梯度是否非零还取决于伴随量：$\partial\mathcal L/\partial v_i^2$ 为零、它与 $h_i^1-u_i$ 的逐分量乘积为零，或者不同位置、不同请求的贡献相互抵消，都会使和式为零。

下面的例子中首轮残差非零，批次梯度为零。取标量 $u=-1$ 与共享映射 $F(v)=v+1$，则 $h^1=F(u)=0$，$h^1-u=1$，$v^2=-1+\tanh g$，$h^2=F(v^2)=\tanh g$。输出 logits 为 $(h^2,0)$，批次含两个相同输入，目标分别为第一类与第二类。记 $t=\tanh g$，两个样本的交叉熵分别为 $\log(1+e^t)-t$ 与 $\log(1+e^t)$，平均为

$$
\mathcal L(g)=\log(1+e^t)-\frac t2=\log\big(e^{t/2}+e^{-t/2}\big)=\log2+\log\cosh\frac t2 .
$$

对 $g$ 求导，

$$
\mathcal L'(g)=\frac12\tanh\Big(\frac{\tanh g}{2}\Big)\operatorname{sech}^2g,\qquad\mathcal L'(0)=0 .
$$

两个样本在 $g=0$ 处的梯度分别为 $-\tfrac12$ 与 $+\tfrac12$，相互抵消。$g$ 是否获得非零更新由实际批次梯度决定，验收项 E9 用有限差分检查这条通路上的梯度。

$g=0$ 时，$v^2$ 不依赖 $h^1$（$\partial v^2/\partial h^1=\operatorname{diag}(\tanh g)=0$），$r=2$ 样本的损失只经 $F^2$ 依赖共用 LoRA，而 $F^2$ 的计算与 $r=1$ 时的 $F^1$ 完全相同。所以训练开始时，同一请求无论分到哪个流，给共用 LoRA 的梯度都相同。两条路径的差异随 $g$ 离开零而出现。

### 4.5 训练量与吞吐准入

每 token 训练 FLOPs 按数学验证第 7.1 节的每层矩阵乘账本计算。第 $i$ 个位置每层前向为 $c_{\rm proj}+c_{\rm att}(i)$：$c_{\rm proj}=113{,}770{,}496$ 是 Q、K、V、输出投影与 8 个激活专家及路由投影，$c_{\rm att}(i)=16{,}384\,i$ 是查询键乘与注意力值乘，位置 $i$ 可见 $i$ 个键。账本把每条训练序列的 4096 个位置按一篇文档计，注意力项平均为 $\bar c_{\rm att}=16{,}384\times2048.5=33{,}562{,}624$，每层前向平均为

$$
113{,}770{,}496+16{,}384\times2048.5=147{,}333{,}120 .
$$

打包时按文档隔离注意力，文档短于 4096 时每个位置可见的键更少，所以这一口径给出注意力项的上界；它也等于在整条 4096 位置序列上做因果注意力、不跳过跨文档掩码块的内核的实际计算量。LoRA 每层前向为 $c_{\rm LoRA}=2{,}719{,}744$（注意力 557,056 加 8 个激活专家 2,162,688），词表头前向为 $c_{\rm voc}=622{,}329{,}856$。

训练倍数按每个矩阵乘需要的梯度确定。冻结的第 0–31 层只做前向，可训练层按层边界重算：

1. 投影与专家的权重冻结，只需输入梯度。$Y=XW$ 的反向为 $\nabla_X\mathcal L=\nabla_Y\mathcal L\,W^\top$，一份矩阵乘，连同前向与重算计 3 倍。
2. 注意力的 $S=QK^\top$ 与 $O=AV$ 两个输入都需要梯度：$\nabla_Q\mathcal L=\nabla_S\mathcal L\,K$，$\nabla_K\mathcal L=(\nabla_S\mathcal L)^\top Q$，$\nabla_A\mathcal L=\nabla_O\mathcal L\,V^\top$，$\nabla_V\mathcal L=A^\top\nabla_O\mathcal L$。反向是两份同规模矩阵乘，连同前向与重算计 4 倍。
3. LoRA 按前向、重算、激活梯度与权重梯度计 4 倍。
4. 词表头的权重冻结，按前向、分块交叉熵的重算与输入梯度计 3 倍。

单轮与完整双轮的每 token 训练 FLOPs 为

$$
\begin{aligned}
\Omega_1&=32\big(c_{\rm proj}+\bar c_{\rm att}\big)+16\big(3c_{\rm proj}+4\bar c_{\rm att}+4c_{\rm LoRA}\big)+3c_{\rm voc},\\
\Omega_2&=\Omega_1+12\big(3c_{\rm proj}+4\bar c_{\rm att}+4c_{\rm LoRA}\big).
\end{aligned}
$$

停止类的第二轮只执行每篇文档的前缀，即提示词与停止点之前的块；记前缀长为 $\tau_d$，即分块扩展推论 3 中最后一个 $r=2$ 位置。投影、专家与 LoRA 项与 $\tau_d$ 成正比；注意力项是前缀上的三角和

$$
\sum_{i=1}^{\tau_d}c_{\rm att}(i)=16{,}384\cdot\frac{\tau_d(\tau_d+1)}{2},
$$

随 $\tau_d$ 的平方增长。按同一口径取文档长 4096，并按全部位置归一，停止类相对单轮的增量为

$$
\begin{aligned}
\Omega_{\rm stop}-\Omega_1
&=12\Big[\big(3c_{\rm proj}+4c_{\rm LoRA}\big)f+4\times16{,}384\times\frac{\mathbb E[\tau_d(\tau_d+1)]}{2\times4096}\Big]\\
&=4{,}226{,}285{,}568\,f+96\big(\mathbb E[\tau_d^2]+\mathbb E[\tau_d]\big)\\
&=4{,}226{,}678{,}784\,f+1{,}610{,}612{,}736\,f_2,
\end{aligned}
$$

其中 $f=\mathbb E[\tau_d]/4096$ 是第二轮覆盖的位置比例，$f_2=\mathbb E[\tau_d^2]/4096^2$ 是它的二阶矩，期望对停止类文档取。$f_2$ 的范围由两个不等式确定。Jensen 不等式给出 $\mathbb E[\tau_d^2]\ge(\mathbb E[\tau_d])^2$，即 $f_2\ge f^2$，各文档覆盖比例相同时取等号。$\tau_d\le4096$ 给出 $\tau_d^2\le4096\,\tau_d$，即 $f_2\le f$，覆盖比例只取 0 或 1 时取等号。$f_2=f$ 时增量为 $f(\Omega_2-\Omega_1)$，即每个执行 $F^2$ 的位置都按完整序列的平均位置计注意力；$F^2$ 前缀另行打包成 4096 位置序列、内核不跳过跨文档掩码块时，实际计算量就是这个值。由此：

| 样本类型 | 冻结层 | 可训练层 | 每 token GFLOPs |
|---|---:|---:|---:|
| 全程 $r=1$（$G_{\rm one}$ 全部，$G_{\rm two}$ 的 1/3） | 32 | 16（$F^1$ 12、$T$ 4） | 14.36 |
| 全程 $r=2$ 与开启类（$G_{\rm two}$ 的 1/2） | 32 | 28（$F^1$ 12、$F^2$ 12、$T$ 4） | 20.20 |
| 停止类（$G_{\rm two}$ 的 1/6） | 32 | 16，另有每篇文档的前 $\tau_d$ 个位置执行 $F^2$ | $14.36+4.23f+1.61f_2$ |
| $G_{\rm two}$ 平均（取 $f=0.7$、$f_2=0.49$） | | | 17.91 |

逐项代入：$c_{\rm proj}+\bar c_{\rm att}=147{,}333{,}120$，$3c_{\rm proj}+4\bar c_{\rm att}+4c_{\rm LoRA}=341{,}311{,}488+134{,}250{,}496+10{,}878{,}976=486{,}440{,}960$。所以 $\Omega_1=32\times147{,}333{,}120+16\times486{,}440{,}960+3\times622{,}329{,}856=4{,}714{,}659{,}840+7{,}783{,}055{,}360+1{,}866{,}989{,}568=14{,}364{,}704{,}768$。完整第二轮的增量为 $12\times486{,}440{,}960=5{,}837{,}291{,}520$，$\Omega_2=20{,}201{,}996{,}288$。

$f=0.7$ 按 GSM8K 的形状估计：提示词 100、回答 150 个 token，停止点在内部边界上均匀抽取且各块等长时，第二轮平均覆盖提示词与一半回答，$f=(100+75)/250=0.7$。通用文本整篇监督，提示词部分可以忽略，同样的抽取给出 $f\approx0.5$。两类数据各占 $10^8$ token，混合后 $f\approx0.6$，此时停止类增量至多为 $0.6\times5.837=3.502$ GF（取 $f_2=f$）。

取 $f=0.7$、$f_2=f^2=0.49$，停止类增量为 $4{,}226{,}678{,}784\times0.7+1{,}610{,}612{,}736\times0.49=2{,}958{,}675{,}148.8+789{,}200{,}240.64=3{,}747{,}875{,}389.44$，高于混合数据按 $f\approx0.6$ 估计的上限 3.502 GF，所以这组取值对混合数据偏保守。此时 $\Omega_{\rm stop}=18{,}112{,}580{,}157$，四类加权平均为

$$
\bar\Omega=\tfrac13(\Omega_1+\Omega_2)+\tfrac16(\Omega_{\rm stop}+\Omega_2)
=\tfrac13\times34.567+\tfrac16\times38.315=17.908\ \text{GF}.
$$

$f=0.7$ 而 $f_2$ 取上限 0.7 时，停止类为 18.451 GF，平均为 17.964 GF。只用全程 $r=1$ 与全程 $r=2$ 两类日程时，平均为 $(\Omega_1+\Omega_2)/2=17.283$ GF；四类日程比它高 3.6%，$f_2$ 取上限时高 3.9%。

账本只计矩阵乘的最小需求。FlashAttention 类内核在反向中再算一次 $QK^\top$，注意力项实际为 4.5 倍，每个可训练层每 token 多 16,781,312 FLOPs，全程 $r=1$ 合计多约 0.27 GF；这类实现相关的重算，以及归一化、softmax 等非矩阵乘算子，由验收项 E11 的实测吞吐体现。

两臂各 $2\times10^8$ token 的准入式沿用一天方案：

$$
\frac{2\times10^8}{v_{\rm two}}+\frac{2\times10^8}{v_{\rm one}}\le0.8\times10\times3600=28{,}800\ \text{s},
$$

$v$ 为 8 卡合计的实测输入 token/s。若 $v_{\rm one}=16{,}000$，$G_{\rm one}$ 需 12,500 秒，则须 $v_{\rm two}\ge2\times10^8/(28{,}800-12{,}500)=12{,}270$。按 FLOPs 比例 $\bar\Omega/\Omega_1=17.908/14.365=1.2467$ 估计，$v_{\rm two}\approx12{,}834$，两臂共 $12{,}500+15{,}583=28{,}083$ 秒，约 7.80 小时，满足准入。$f_2$ 取上限 0.7 时比例为 1.2506，$v_{\rm two}\approx12{,}794$，两臂共 28,132 秒，约 7.81 小时，同样满足。此时每卡约 $12{,}834\times17.908\times10^9/8\approx28.7$ TFLOP/s，为 H200 SXM BF16 稠密峰值 989.5 TFLOP/s 的 2.9%。吞吐能否达标取决于 MoE 路由与小批量内核的效率，以验收项 E11 的实测为准。

## 5. 阶段 2：同请求双动作标签

### 5.1 标签定义

生成器 $G_{\rm two}$ 冻结后，对每个请求 $d$（提示词长 $P_d$，参考答案 $A_d$ 有 $n_d$ 个 token）分别以 $r=1$ 与 $r=2$ 教师强制运行一次，记录

$$
\ell_d(r)=\frac{1}{n_d}\sum_{t\in A_d}-\log p^{(r)}\big(x_{d,t}\mid x_{d,<t}\big),
\qquad
\Delta\ell_d=\ell_d(2)-\ell_d(1).
$$

$\Delta\ell_d<0$ 表示第二轮使答案的平均 NLL 下降。成本记为每个答案 token 的完整账本成本 $c_d(r)=C_d(r)/n_d$。按第 4.2 节的位置约定，模型执行位置 $1,\ldots,P_d+n_d-1$；$C_d(r)$ 含这些位置上的 $S$、$F^1$、$T$ 与 LoRA，以及 $n_d$ 个预测位置 $P_d,\ldots,P_d+n_d-1$ 上的词表头，$r=2$ 时再加这些位置上的 $F^2$ 与混合。两种轮数的成本差为

$$
\Delta c_d=c_d(2)-c_d(1)=\frac{C_{F^2+{\rm mix}}(P_d+n_d-1)}{n_d},
$$

即第二轮在提示词与答案全部执行位置上的费用，按答案 token 数归一；$C_{F^2+{\rm mix}}(N)$ 记第二轮与混合在位置 $1,\ldots,N$ 上的账本成本之和，闭式见第 7.1 节。

标签按答案 token 数归一，是为了与评价口径一致。评价把每篇文档的 NLL 与成本都除以该文档的计分 token 数，再在文档间等权平均（数学验证第 12.1 节）。在价格 $\lambda$ 下，策略 $\pi$ 的目标

$$
L(\pi)+\lambda C(\pi)=\frac1D\sum_d\big[\ell_d(\pi_d)+\lambda c_d(\pi_d)\big]
$$

对文档可分，每篇文档单独取最小即可。文档 $d$ 选 $r=2$ 当且仅当 $\Delta\ell_d+\lambda\Delta c_d<0$，这正是附图的选择规则；控制器用预测值 $\Delta\hat\ell_d$ 与 $\widehat{\Delta c}_d$（第 7.1 节）代替真实值。

### 5.2 教师强制评价等于查表

**命题 2。** 对任何只读取提示词信息的请求级策略 $\pi$，它在确认集上的教师强制 NLL 等于 $\frac1D\sum_d\ell_d(\pi_d)$，成本等于 $\frac1D\sum_d c_d(\pi_d)$ 加上控制器自身的账本费用。

**证明。** 决策发生在提示词末位，读取的 $h^1_P$、$z$ 与第 43 层首轮 KV 都在 $F^1$ 中算出，与之后选择的 $r$ 无关。请求级策略选定的 $r$ 在整次回答内不变，生成中没有补写或尾追赶（不变量 3）。H 与 Q 只读生成表示，不改变生成分布（不变量 4）。所以策略在请求 $d$ 上的教师强制输出与标签运行中 $r=\pi_d$ 的那一次逐位相同，NLL 与生成成本分别是 $\ell_d(\pi_d)$ 与 $c_d(\pi_d)$。证毕。

由此，所有策略族的教师强制校准与确认评价都只需查标签表，不再占用 GPU。命题依赖不变量 3、4，由验收项 E2–E6 检查。按行循环方案中动作会改变后续历史，必须在线执行，这里没有这一限制。

### 5.3 特征与缓存

控制器在提示词末位读取三类信息：

1. 已知状态 $z_d\in\mathbb R^4$：$\log(1+P_d)$、$\log(1+\text{提示词行数})$，以及“数学”“通用”两维来源独热编码。
2. 首轮表示 $h^1_{d,P}\in\mathbb R^{2048}$，加停止梯度。
3. 第 43 层首轮提示词 KV：每个位置 4 个 KV 头、头维 128，K 与 V 各 512 维，BF16 下每个位置 2,048 字节。

标签运行同时保存这三类信息，供 S4 训练使用。

### 5.4 数据角色与规模

评价沿用一天方案的 GSM8K 默认分桶，盐改为 `jev-v4-request2`：按 SHA256(UTF-8(`jev-v4-request2`) ‖ 0x00 ‖ UTF-8(题目原文)) 的 32 字节摘要作大端整数 mod 100，桶 0–44 为拟合，45–59 为校准，60–99 为确认，确认集约 2,989 篇。GSM8K 测试集已在 v3.3 作过确认集，只作自由生成的复用基准。

H 与 Q 是请求级模型，每个请求只提供一行样本。拟合请求不少于 20,000 个：GSM8K 拟合桶约 3,363 个，其余取自数学训练语料中预留、不参与生成训练的请求。这一规模与 v3.3 的 H 拟合行数（41,839）同一量级。所有评价请求都对生成训练数据做 13-gram 去污染。拟合请求再对校准与确认请求做 13-gram 去重：与任一评价请求共享 13-gram 的拟合请求剔除，剔除后仍不少于 20,000 个。提示词在拟合与评价之间重复时，H 与 Q 能凭几乎相同的输入记住拟合标签，抬高 P2、P3 的样本外结果；N 的噪声与提示词内容无关，第 7.2 节的阴性对照察觉不到这一通道。

标签运行的计算量很小。两次运行共用 $S$ 与 $F^1$，每 token 前向约为 64 层（$S$ 32、$F^1$ 12、$F^2$ 12、$T$ 两次各 4）加两次词表头；按 GSM8K 的短上下文约 8.7 GFLOPs。约 24,000 个请求、每个约 300 token 时，合计约 $7.2\times10^6\times8.7\times10^9\approx6.3\times10^{16}$ FLOPs，按第 4.5 节估计的 8 卡合计约 $2.3\times10^{14}$ FLOP/s，约 4.6 分钟。

### 5.5 停止点标签

单向停止策略的选项是停止点 $s\in\{1,\ldots,K_d+1\}$：第 $1,\ldots,s-1$ 块取 $r=2$，其余取 $r=1$。$s=1$ 与 $s=K_d+1$ 分别是请求级的 $r=1$ 与 $r=2$，取自两次全程运行。第 5.1 节的 $\ell_d(r)$、$c_d(r)$ 以轮数为自变量；停止点为 $s$ 时按答案 token 归一的 NLL 与成本记为 $\ell^{[s]}_d$、$c^{[s]}_d$，上标与预测分布 $p^{[s]}$ 一致。两种记号在端点处相等：$\ell^{[1]}_d=\ell_d(1)$，$\ell^{[K_d+1]}_d=\ell_d(2)$，$c^{[1]}_d=c_d(1)$，$c^{[K_d+1]}_d=c_d(2)$。按第 4.2 节的约定，第 $c$ 块的 token $x_{b_c+1},\ldots,x_{b_{c+1}}$ 由位置 $[b_c,b_{c+1})$ 预测，块的轮数作用于这些位置；位置 $t-1$ 的输出给出 $x_t$ 的预测，所以 $t\le b_s$ 的回答 token 恰好是前 $s-1$ 块的 token。

对每个内部停止点 $s\in\{2,\ldots,K_d\}$，以全程 $r=2$ 运行在位置 $b_s$ 之前的生成尾缓存为历史、以 $h^1$ 为输入，对位置 $b_s$ 及之后重跑一次生成尾与词表头，得到停止点为 $s$ 时的预测分布 $p^{[s]}$。$t\le b_s$ 时，$x_t$ 由 $b_s$ 之前的位置预测，这些位置取 $r=2$，生成尾的历史全部来自 $h^2$，预测与全程 $r=2$ 运行相同。所以

$$
\ell^{[s]}_d=\frac1{n_d}\Big[\sum_{t\in A_d,\,t\le b_s}-\log p^{(2)}\big(x_{d,t}\mid x_{d,<t}\big)+\sum_{t\in A_d,\,t>b_s}-\log p^{[s]}\big(x_{d,t}\mid x_{d,<t}\big)\Big].
$$

成本 $c^{[s]}_d$ 中，$s=1$ 时不执行第二轮，提示词以 $h^1$ 预填充；$s\ge2$ 时第二轮覆盖位置 $1,\ldots,b_s-1$，即提示词与前 $s-1$ 块，所以 $c^{[s]}_d-c^{[1]}_d=C_{F^2+{\rm mix}}(b_s-1)/n_d$；$s=K_d+1$ 时 $b_s-1=P_d+n_d-1$，与第 5.1 节请求级 $r=2$ 的覆盖范围相同。

由分块扩展的命题 1，取 $r=2$ 的位置上 $h^2$ 与全程 $r=2$ 运行相同，$h^1$ 与动作无关；由它的推论 1，预测只经生成尾的输入序列依赖动作，而重跑使用的正是停止点为 $s$ 时的输入序列。所以 $\ell^{[s]}_d$ 就是停止策略的教师强制 NLL，命题 2 对单向停止策略同样成立：任何单向停止策略的教师强制评价都是在 $(d,s)$ 表上查表。这一等价由验收项 C2 检查。

各块等长时，尾部后缀运行的总长度为

$$
\sum_{s=2}^{K}\big(K-s+1\big)\frac nK=\frac nK\cdot\frac{K(K-1)}2=\frac{n(K-1)}2
$$

个答案 token。GSM8K 平均 $K=3.58$，提示词 100、回答 150 个 token 时，后缀运行约为两次全程运行计算量的 10%，标签运行合计约 5 分钟。每个拟合请求提供 $K_d-1$ 行停止样本，20,000 个拟合请求约 51,600 行。标签运行同时保存每个内部边界的首轮出口 $h^1_{d,b_c}$ 与边界状态 $z_{d,c}$（第 7.6 节），$h^1$ 在 BF16 下每个边界占 4 KiB。

## 6. 阶段 3：门槛 GL1、GL2 与 GL3

### 6.1 GL1：第二轮的平均效应

在校准文档上计算 $\Delta_{\rm loop}=-\frac{1}{D_{\rm cal}}\sum_d\Delta\ell_d$，即全部请求取 $r=2$ 相对全部取 $r=1$ 的 NLL 改善。GL1 要求 $\Delta_{\rm loop}\ge0.005$，且文档自助法单侧 95% 下界大于零；下界取第 8.3 节的位次分位 $q^-(0.05)$，大于零等价于自助 p 值小于 0.05。两者使用同一个检查点，只差轮数，是单因素比较。GL1 是只用校准文档的放行判据，与第 8.3 节的确认族分开计算；确认文档与校准文档不相交，确认族的族错误率在 GL1 的任一结果下都不超过 0.05。

### 6.2 GL2：两动作的对偶上界

记 $C(r)=\frac1D\sum_dc_d(r)$，以全部 $r=1$ 的成本为单位 1。随机分配策略（记为 U-mix）以概率 $w$ 让每个请求整次取 $r=2$，其期望成本与期望 NLL 都是两个端点的凸组合；在预算 $B$ 处

$$
L_{\rm mix}(B)=L(1)+w(B)\big[L(2)-L(1)\big],
\qquad
w(B)=\frac{B-C(1)}{C(2)-C(1)},
$$

这与严格同成本插值在两个均匀端点之间的取值相同。

任何控制器在标签表上的同成本 NLL 都有下界。令 $x_d\in[0,1]$ 为请求 $d$ 取 $r=2$ 的概率，问题写成线性规划：

$$
\min_{x\in[0,1]^D}\ \frac1D\sum_d\big[\ell_d(1)+x_d\Delta\ell_d\big]
\quad\text{s.t.}\quad
\frac1D\sum_d\big[c_d(1)+x_d\Delta c_d\big]\le B .
$$

**命题 3。** 设 $B\ge C(1)$，记 $\beta=B-C(1)$。第二轮在每个位置都有正的账本费用，所以每个请求的 $\Delta c_d>0$（第 5.1 节），单位成本收益 $\rho_d=-\Delta\ell_d/\Delta c_d$ 有定义，且 $\rho_d>0$ 当且仅当 $\Delta\ell_d<0$。令 $O(\lambda)=\frac1D\sum_d\min\{\ell_d(1)+\lambda c_d(1),\ \ell_d(2)+\lambda c_d(2)\}$，并令

$$
W(t)=\frac1D\sum_{d:\,\rho_d>t}\Delta c_d,\qquad
\lambda^\ast=\min\{t\ge0:\ W(t)\le\beta\},\qquad
B^\circ=C(1)+\frac1D\sum_{d:\,\Delta\ell_d<0}\Delta c_d .
$$

$W(t)$ 是令全部 $\rho_d>t$ 的请求取 $r=2$ 所需的额外成本，$B^\circ$ 是令全部 $\Delta\ell_d<0$ 的请求取 $r=2$ 时的成本。则：

1. 线性规划的最优值（记为 $\mathrm{LB}(B)$）等于 $\sup_{\lambda\ge0}[O(\lambda)-\lambda B]$，上确界在 $\lambda^\ast$ 处取到。
2. 可行解 $x$ 是最优解，当且仅当 $\rho_d>\lambda^\ast$ 的请求取 $x_d=1$，$\rho_d<\lambda^\ast$ 的请求取 $x_d=0$，并且 $\lambda^\ast>0$ 时成本恰为 $B$；$\rho_d=\lambda^\ast$ 的请求取 $[0,1]$ 中满足这些条件的任意值。
3. $B<B^\circ$ 时预算约束活跃，$\lambda^\ast>0$：最优解按 $\rho_d$ 从大到小令 $x_d=1$，装到成本恰为 $B$ 为止，临界价格 $\lambda^\ast$ 上的并列请求取分数。$B\ge B^\circ$ 时预算约束不活跃，$\lambda^\ast=0$：最优解令全部 $\Delta\ell_d<0$ 的请求取 $r=2$、全部 $\Delta\ell_d>0$ 的请求取 $r=1$，最优值为 $\frac1D\sum_d\min\{\ell_d(1),\ell_d(2)\}$，预算可以剩余。两种情形下，$\Delta\ell_d>0$ 的请求在任何最优解中都取 $r=1$。

**证明。** 对约束引入乘子 $\lambda\ge0$，拉格朗日对偶函数为

$$
\min_{x\in[0,1]^D}\frac1D\sum_d\big[\ell_d(1)+\lambda c_d(1)+x_d(\Delta\ell_d+\lambda\Delta c_d)\big]-\lambda B .
$$

方括号对每个 $x_d$ 是线性的，系数为 $\Delta\ell_d+\lambda\Delta c_d=\Delta c_d(\lambda-\rho_d)$。$\rho_d>\lambda$ 时系数为负，最小值在 $x_d=1$ 处取到；$\rho_d<\lambda$ 时系数为正，最小值在 $x_d=0$ 处取到；$\rho_d=\lambda$ 时系数为零，$[0,1]$ 中任意值都取到最小值。三种情形的最小值都等于 $\min\{\ell_d(1)+\lambda c_d(1),\ \ell_d(2)+\lambda c_d(2)\}$，所以对偶函数就是 $O(\lambda)-\lambda B$。

记线性规划的目标为 $L(x)=\frac1D\sum_d[\ell_d(1)+x_d\Delta\ell_d]$，约束左端为 $C(x)=\frac1D\sum_d[c_d(1)+x_d\Delta c_d]$。对任意可行 $x$ 与任意 $\lambda\ge0$，由 $C(x)\le B$ 得弱对偶不等式

$$
L(x)\ \ge\ L(x)+\lambda\big(C(x)-B\big)
=\frac1D\sum_d\big[\ell_d(1)+\lambda c_d(1)+x_d\Delta c_d(\lambda-\rho_d)\big]-\lambda B
\ \ge\ O(\lambda)-\lambda B .
$$

第一个不等号在 $\lambda=0$ 或 $C(x)=B$ 时取等，第二个不等号在每个 $x_d$ 都使方括号取最小时取等。

下面构造使两个不等号同时取等的可行解 $x^\ast$。$W(t)$ 随 $t$ 不增且右连续，$t\ge\max\{0,\max_d\rho_d\}$ 时 $W(t)=0\le\beta$，所以 $\lambda^\ast$ 存在。

1. $\lambda^\ast=0$ 时，令 $x^\ast_d=\mathbf 1[\rho_d>0]$。成本为 $C(1)+W(0)\le B$，每个 $x^\ast_d$ 使 $\lambda=0$ 处的方括号取最小。
2. $\lambda^\ast>0$ 时，由最小性，$0\le t<\lambda^\ast$ 有 $W(t)>\beta$，而 $W(\lambda^\ast)\le\beta$，所以 $W$ 在 $\lambda^\ast$ 处跳跃，$\lambda^\ast$ 等于某些请求的 $\rho_d$。记并列集合 $\mathcal T=\{d:\rho_d=\lambda^\ast\}$，其额外成本为 $C_{\mathcal T}=\frac1D\sum_{d\in\mathcal T}\Delta c_d$。在 $\lambda^\ast$ 左侧足够近处 $W(t)=W(\lambda^\ast)+C_{\mathcal T}>\beta$，所以 $0\le\beta-W(\lambda^\ast)<C_{\mathcal T}$。令 $\rho_d>\lambda^\ast$ 时 $x^\ast_d=1$，$\rho_d<\lambda^\ast$ 时 $x^\ast_d=0$，$d\in\mathcal T$ 时 $x^\ast_d=\nu=(\beta-W(\lambda^\ast))/C_{\mathcal T}\in[0,1)$。成本为 $C(1)+W(\lambda^\ast)+\nu\,C_{\mathcal T}=C(1)+\beta=B$，每个 $x^\ast_d$ 使 $\lambda^\ast$ 处的方括号取最小。

两种情形下 $x^\ast$ 可行，且 $L(x^\ast)=O(\lambda^\ast)-\lambda^\ast B$。由弱对偶不等式，任意可行 $x$ 有 $L(x)\ge O(\lambda^\ast)-\lambda^\ast B=L(x^\ast)$，所以 $x^\ast$ 最优；任意 $\lambda\ge0$ 有 $O(\lambda)-\lambda B\le L(x^\ast)=O(\lambda^\ast)-\lambda^\ast B$，所以上确界在 $\lambda^\ast$ 处取到并等于最优值。第 1 条得证。

对任意可行 $x$，把弱对偶不等式在 $\lambda^\ast$ 处的两个差相加，得

$$
L(x)-L(x^\ast)
=\frac1D\sum_d\Big[x_d\Delta c_d(\lambda^\ast-\rho_d)-\min_{y\in[0,1]}y\,\Delta c_d(\lambda^\ast-\rho_d)\Big]
+\lambda^\ast\big(B-C(x)\big).
$$

右端两项都非负。$x$ 最优当且仅当左端为零，也就是两项同时为零。第一项为零要求每个 $x_d$ 使方括号取最小，即 $\rho_d>\lambda^\ast$ 时 $x_d=1$、$\rho_d<\lambda^\ast$ 时 $x_d=0$；第二项为零要求 $\lambda^\ast>0$ 时 $C(x)=B$。第 2 条得证。

由 $\rho_d>0\iff\Delta\ell_d<0$ 得 $W(0)=B^\circ-C(1)$，所以 $\lambda^\ast=0$ 当且仅当 $W(0)\le\beta$，即 $B\ge B^\circ$。$\lambda^\ast>0$ 时，$\Delta\ell_d\ge0$ 的请求有 $\rho_d\le0<\lambda^\ast$，由第 2 条取 $x_d=0$；构造中的 $x^\ast$ 就是按 $\rho_d$ 从大到小装到成本为 $B$ 的解。$\lambda^\ast=0$ 时，第 2 条要求 $\Delta\ell_d<0$ 的请求取 $x_d=1$、$\Delta\ell_d>0$ 的请求取 $x_d=0$，$\Delta\ell_d=0$ 的请求不改变目标，最优值为 $O(0)=\frac1D\sum_d\min\{\ell_d(1),\ell_d(2)\}$。第 3 条得证。证毕。

#### 等式约束版本

把预算约束改为 $C(x)=B$（要求 $C(1)\le B\le C(2)$），最优值记为 $\mathrm{LB}^{=}(B)$。等式的可行集包含于不等式的可行集，所以 $\mathrm{LB}^{=}(B)\ge\mathrm{LB}(B)$。等式约束下 $\lambda(C(x)-B)=0$ 对任意实数 $\lambda$ 成立，弱对偶不等式对 $\lambda\in\mathbb R$ 都成立。$B<C(2)$ 时把 $\lambda^\ast$ 的定义改为 $\min\{t\in\mathbb R:W(t)\le\beta\}$，对所有 $t<\lambda^\ast$ 有 $W(t)>\beta$，上面第 2 种情形的构造给出成本恰为 $B$ 的 $x^\ast$，且 $L(x^\ast)=O(\lambda^\ast)-\lambda^\ast B$；$B=C(2)$ 时唯一可行解是全部 $x_d=1$，$\lambda\le\min_d\rho_d$ 时 $O(\lambda)-\lambda B=L(2)$。所以 $\mathrm{LB}^{=}(B)=\sup_{\lambda\in\mathbb R}[O(\lambda)-\lambda B]$，最优解按 $\rho_d$ 从大到小装入全部请求，包括 $\rho_d\le0$ 的请求，装到成本恰为 $B$ 为止。记 $\bar B=C(1)+\frac1D\sum_{d:\,\Delta\ell_d\le0}\Delta c_d\ge B^\circ$，两个版本的关系为：

1. $B\le\bar B$ 时 $\mathrm{LB}^{=}(B)=\mathrm{LB}(B)$。$B<B^\circ$ 时命题 3 的最优解成本恰为 $B$；$B^\circ\le B\le\bar B$ 时，在命题 3 的最优解上给 $\Delta\ell_d=0$ 的请求补足成本 $B-B^\circ$，目标不变。两种情形下不等式问题都有成本恰为 $B$ 的最优解。
2. $B>\bar B$ 时 $\mathrm{LB}^{=}(B)>\mathrm{LB}(B)$。成本为 $B$ 的解必须在 $\Delta\ell_d>0$ 的请求上花费至少 $B-\bar B>0$ 的额外成本，而此时 $\lambda^\ast=0$，命题 3 第 2 条要求这些请求取 $x_d=0$，所以等式可行解都不是不等式问题的最优解。

GL2 使用不等式版本。严格同成本插值是文档级随机化（数学验证第 12.2 节）：在相邻两个确定性策略之间按文档独立抽取，请求 $d$ 取 $r=2$ 的概率 $x_d\in[0,1]$，期望总成本恰为 $B$。总成本含控制器费用，生成部分 $C(x)$ 等于 $B$ 减去控制器费用；Q 与 HQ 的查询费用为正，生成部分严格小于 $B$。所以每个请求级策略族在预算 $B$ 处的插值策略都满足不等式约束，只有不计控制器费用的策略才满足等式约束。不等式版本是对全部族都成立的下界；它不高于等式版本，按它计算的 $\Gamma(B)$ 不低于等式版本的值，作为 GL2 的必要条件更宽松。

#### 整数解

每个请求只取一个 $r$ 的确定性规则对应 $x\in\{0,1\}^D$，其最优值记为 $\mathrm{LB}^{\rm int}(B)$。$\lambda^\ast=0$ 时构造解 $x^\ast$ 已是整数解，两者相等。$\lambda^\ast>0$ 时，把并列集合 $\mathcal T$ 中的请求按任意顺序逐个装满，由第 2 条得到至多一个分量取分数的最优解；记该分量为请求 $k$，取值 $\nu_k$。把 $x_k$ 改为 0 得到成本更低的整数可行解，目标增加 $\nu_k|\Delta\ell_k|/D$，而 $\rho_k=\lambda^\ast$ 给出 $|\Delta\ell_k|=\lambda^\ast\Delta c_k$。所以

$$
\mathrm{LB}(B)\ \le\ \mathrm{LB}^{\rm int}(B)\ \le\ \mathrm{LB}(B)+\frac{\nu_k\lambda^\ast\Delta c_k}{D}\ \le\ \mathrm{LB}(B)+\frac{\max_d|\Delta\ell_d|}{D}.
$$

这个差由临界请求的 $|\Delta\ell_k|$ 决定。交叉熵没有统一上界，只凭 $D$ 不能断定差小于实用门槛：校准集约 1,121 篇时，$|\Delta\ell_k|=0.1$ 给出的上界为 $8.9\times10^{-5}$，而上界 $|\Delta\ell_k|/D$ 在 $|\Delta\ell_k|>5.61$ 时超过 0.005。校准集上报告 $\nu_k\lambda^\ast\Delta c_k/D$ 的实际值。$\Gamma(B)$ 用分数解定义，不依赖这一差：严格同成本插值本身是文档级随机化，分数解的最优值正是全部插值值的下界。

#### 多选项的对偶最优选择

第 6.5 节的单向停止每个请求有 $K_d+1$ 个选项 $o$，各有成本 $c^{[o]}_d$ 与 NLL $\ell^{[o]}_d$。把 $x_d$ 换成请求 $d$ 在选项上的概率向量后，弱对偶不等式与第 2 条的论证逐字成立，对偶函数为 $O_{\mathcal P}(\lambda)-\lambda B$，$O_{\mathcal P}(\lambda)=\frac1D\sum_d\min_o[\ell^{[o]}_d+\lambda c^{[o]}_d]$。$O_{\mathcal P}$ 是有限个仿射函数下包络的平均，$O_{\mathcal P}(\lambda)-\lambda B$ 是凹的分段线性函数，它在 $\lambda\ge0$ 上最小的最大值点 $\lambda^\ast$ 为 0 或某个断点 $(\ell^{[o]}_d-\ell^{[o']}_d)/(c^{[o']}_d-c^{[o]}_d)$，逐个求值即可精确得到。在 $\lambda^\ast$ 处，每个请求在使 $\ell^{[o]}_d+\lambda^\ast c^{[o]}_d$ 最小的选项中取成本最低的 $o_d^-$ 与成本最高的 $o_d^+$，两者的文档平均成本记为 $C^-$、$C^+$。$O_{\mathcal P}$ 在 $\lambda^\ast$ 处的右导数为 $C^-$、左导数为 $C^+$，$\lambda^\ast$ 是最小的最大值点，所以 $C^-\le B$，且 $\lambda^\ast>0$ 时 $C^+>B$。选择规则为：

1. $\lambda^\ast=0$ 时，每个请求取 $o_d^-$，预算可以剩余。
2. $\lambda^\ast>0$ 时，每个请求独立地以概率 $\nu=(B-C^-)/(C^+-C^-)$ 取 $o_d^+$，否则取 $o_d^-$，期望成本恰为 $B$。只有 $o_d^-\ne o_d^+$ 的并列请求受随机化影响，标签表上的评价按概率取期望，不需要实际抽样。

这一规则下每个请求的选项分布都使 $\lambda^\ast$ 处的拉格朗日项取最小，$\lambda^\ast>0$ 时期望成本等于 $B$，由第 2 条的论证达到第 6.5 节的 $\mathrm{LB}_{\mathcal P}(B)$。两个选项时它就是构造解 $x^\ast$：$o_d^-\ne o_d^+$ 的请求恰为并列集合 $\mathcal T$，$\nu$ 相同。第 6.3 节的跨半选择评价与第 6.5 节的跨半版本都使用这一规则。

#### 可分配空间

定义可分配空间

$$
\Gamma(B)=L_{\rm mix}(B)-\sup_{\lambda\ge0}\big[O(\lambda)-\lambda B\big].
$$

U-mix 对应 $x_d=w(B)$ 的可行解，所以 $\Gamma(B)\ge0$；任何请求级策略族在预算 $B$ 处的严格同成本值都不低于 $\mathrm{LB}(B)$，相对 U-mix 的改善不超过 $\Gamma(B)$。

例：三个请求等权，$\Delta c_d$ 都是 0.25，$\Delta\ell_d$ 依次为 $-0.06$、$-0.02$、$+0.01$，$C(1)=1$，$C(2)=1.25$。取 $B=1+0.25/3$，恰好够一个请求取 $r=2$。随机分配时 $w=1/3$，$L_{\rm mix}=L(1)+\frac13\times\frac{-0.07}{3}=L(1)-0.00778$。下界把第一个请求设为 $r=2$，得 $L(1)-0.02$。所以 $\Gamma=0.02-0.00778=0.01222$。这里 $B<B^\circ=1.16667$，预算约束活跃，$\lambda^\ast=\rho_2=0.08$，并列请求 2 取 $\nu=0$。

同一组请求取 $B=1.1875$ 时，$\beta=0.1875$，$B^\circ=1+0.5/3=1.16667\le B$，预算约束不活跃，$\lambda^\ast=0$。下界令前两个请求取 $r=2$、第三个取 $r=1$，成本为 1.16667，剩余预算 0.02083，得 $L(1)-0.08/3=L(1)-0.02667$。随机分配时 $w=0.75$，$L_{\rm mix}=L(1)-0.75\times0.07/3=L(1)-0.0175$，所以 $\Gamma=0.02667-0.0175=0.00917$。若要求用尽预算，第三个请求须取 $x_3=0.02083/(0.25/3)=0.25$，NLL 增加 $0.25\times0.01/3=0.00083$，得到等式约束版本的下界 $L(1)-0.02583$ 与可分配空间 0.00833（此例 $\bar B=B^\circ<B$）。

候选预算为 1.0625、1.125、1.1875，相关规定如下：

1. 候选位置：按层调用数，全部取 $r=2$ 的相对成本在提示词位置为 $60/48=1.25$，在答案位置因词表头稀释约为 1.225；计入 LoRA 与混合后，按第 7.1 节账本的主要项分别约为 1.254 与 1.229（第 8.2 节）。提示词 100、回答 150 个 token 的请求全部取 $r=2$ 时相对成本约为 1.238，三个候选都在两个端点之间，大约对应 26%、53%、79% 的请求取 $r=2$。
2. 主预算：取 $\Gamma(B)$ 最大的候选，并列取较小预算；超出两个端点实际成本范围的候选，在读取确认集前剔除并记录。每个策略族都含强制全程 $r=1$ 与强制全程 $r=2$ 两个端点（第 8.2 节），两个端点之间的候选对所有族都可夹逼。
3. 约束活跃性报告：校准集同时报告 $B^\circ$ 与 $\bar B$。候选 $B\ge B^\circ$ 时，事后最优不再用尽预算，$\mathrm{LB}(B)$ 不再随 $B$ 下降。
4. 门槛：GL2 要求所选预算处 $\Gamma(B)\ge0.005$。

### 6.3 跨半选择评价（诊断）

$\Gamma(B)$ 用每个请求的实际标签选择轮数，单个参考答案的噪声会使它偏向乐观；loopjev 中有 14.92 个百分点的事后节省来自这类噪声。跨半选择评价把选择与评价分到答案的不同 token 上。每个答案按 token 顺序分成两半：前半为前 $\lfloor n_d/2\rfloor$ 个答案 token，后半为其余 token。记两半各自按 token 平均的 NLL 差为 $\Delta\ell^{(a)}_d$、$\Delta\ell^{(b)}_d$。用 $\Delta\ell^{(a)}$ 代替 $\Delta\ell$、成本仍取实际账本，按命题 3 的规则得到分数解 $x^{(a)}$，再在后半上计算它相对随机分配的改善：

$$
\Gamma^{\times}(B)=\frac1D\sum_d\big[w(B)-x^{(a)}_d\big]\,\Delta\ell^{(b)}_d .
$$

同时报告后半上的对偶上界 $\Gamma^{(b)}(B)$，即第 6.2 节的 $\Gamma(B)$ 改用后半标签计算的值，选择与评价都用 $\Delta\ell^{(b)}$。两者都只用后半 token，口径相同。$x^{(a)}$ 是后半问题的可行解，所以 $\Gamma^{(b)}(B)\ge\Gamma^{\times}(B)$ 恒成立。两者之差包含两部分：同一噪声既用于选择又用于评价带来的乐观部分，以及按带噪前半标签选择造成的损失；下文第二个例子中后半没有噪声，$\Gamma^{(b)}=0.005$，差 0.00375 全部来自后者。两者与按整段答案计算的 $\Gamma(B)$ 口径不同。

记 $\Delta\ell^{(b)}_d=\mu^{(b)}_d+\varepsilon^{(b)}_d$，$\mu^{(b)}_d$ 为请求 $d$ 后半的真实效应。$x^{(a)}$ 读取全部请求的前半标签与实际成本，$w(B)$ 读取实际成本，成本又由答案长度决定。评价无偏所需的条件因此要覆盖选择读取的全部信息：

$$
\mathbb E\big[\varepsilon^{(b)}_d\mid\boldsymbol\mu^{(b)},\boldsymbol{\Delta\ell}^{(a)},\boldsymbol c\big]=0,\qquad d=1,\ldots,D,
$$

粗体为全部请求的向量。$x^{(a)}_d$ 与 $w(B)$ 都是 $(\boldsymbol{\Delta\ell}^{(a)},\boldsymbol c)$ 的函数，由全期望公式

$$
\mathbb E\big[x^{(a)}_d\varepsilon^{(b)}_d\mid\boldsymbol\mu^{(b)}\big]
=\mathbb E\Big[x^{(a)}_d\,\mathbb E\big[\varepsilon^{(b)}_d\mid\boldsymbol\mu^{(b)},\boldsymbol{\Delta\ell}^{(a)},\boldsymbol c\big]\ \Big|\ \boldsymbol\mu^{(b)}\Big]=0,
$$

$w(B)\varepsilon^{(b)}_d$ 同理。所以 $\Gamma^{\times}(B)$ 与前半选出的分配在后半上的真实改善 $\frac1D\sum_d\big[w(B)-x^{(a)}_d\big]\mu^{(b)}_d$ 之差，在给定 $\boldsymbol\mu^{(b)}$ 时条件期望为零。

“两半误差在给定 $\mu_d$ 时相互独立且均值为零”弱于这一条件：成本可以把后半误差带进选择。例：单篇请求，真实效应为零，两半误差独立地等概率取 $\pm0.01$，预算余量为 0.05；后半误差为 $-0.01$ 时 $\Delta c=0.1$，为 $+0.01$ 时 $\Delta c=0.2$。前半标签为负时分配 $x=0.05/\Delta c$，否则 $x=0$。四种误差组合等概率，只有前半误差为负的两种分配第二轮，

$$
\mathbb E\big[x\,\varepsilon^{(b)}\big]
=\frac14\big[0.5\times(-0.01)+0.25\times0.01\big]
=-0.000625\neq0 .
$$

$\Gamma^{\times}(B)$ 评价的是由带噪的前半标签选出的那一个分配，可部署策略的改善可以高于它：读提示词的控制器可以选得更准。例：两篇请求的真实 $\Delta\ell$ 为 $-0.01$、$+0.01$，$\Delta c$ 都是 0.25，$C(1)=1$，$B=1.125$，$w(B)=0.5$，提示词完全揭示请求类型。可部署策略把第二轮给第一篇，相对随机分配改善

$$
\frac12\big[(0.5-1)\times(-0.01)+(0.5-0)\times0.01\big]=0.005 .
$$

设后半误差为零，前半误差对两篇独立地等概率取 $\pm0.02$。前半误差为 $(+0.02,+0.02)$、$(+0.02,-0.02)$、$(-0.02,+0.02)$、$(-0.02,-0.02)$ 时，前半标签分别为 $(0.01,0.03)$、$(0.01,-0.01)$、$(-0.03,0.03)$、$(-0.03,-0.01)$，命题 3 的规则依次不分配、选第二篇、选第一篇、选第一篇，$\Gamma^{\times}$ 依次为 $0$、$-0.005$、$0.005$、$0.005$。期望为 0.00125，低于可部署策略的 0.005。$\Gamma^{\times}$ 因此只作诊断，不作门槛。

### 6.5 GL3：单向停止相对请求级的额外空间

在校准文档的 $(d,s)$ 表上，按分块扩展第 6 节计算两类策略的对偶下界：

$$
\mathrm{LB}_{\mathcal P}(B)=\sup_{\lambda\ge0}\Big[\frac1D\sum_d\min_{o\in\mathcal O_d(\mathcal P)}\big(\ell^{[o]}_d+\lambda c^{[o]}_d\big)-\lambda B\Big].
$$

请求级的选项集合为 $\{1,K_d+1\}$，单向停止的为 $\{1,\ldots,K_d+1\}$。证明与命题 3 相同：拉格朗日松弛后，每个请求在自己的选项中取最小，下界对任何期望成本不超过 $B$ 的规则都成立，包括文档级随机混合；达到下界的选择由第 6.2 节的多选项对偶最优选择给出。单向停止包含请求级，所以

$$
\Delta_{\rm stop}(B)=\mathrm{LB}_{\rm req}(B)-\mathrm{LB}_{\rm stop}(B)\ge0 .
$$

GL3 要求主预算处 $\Delta_{\rm stop}(B)\ge0.005$。$\Delta_{\rm stop}$ 是同一张标签表上两个事后最优值之差：未通过时，按事后标签选择停止点的最优单向停止策略，比按事后标签选择轮数的最优请求级策略至多好 0.005。

P4 比较的是两个实际控制器 H 与 H＋H$_{\rm stop}$（第 8.3 节），$\Delta_{\rm stop}$ 只是它的一个分量。记两个实际策略距各自事后最优值的差为

$$
e_H(B)=L_H(B)-\mathrm{LB}_{\rm req}(B),
\qquad
e_S(B)=L_{\rm H+H_{stop}}(B)-\mathrm{LB}_{\rm stop}(B).
$$

严格同成本插值给出平均成本恰为 $B$ 的文档级随机策略。H 的插值策略是请求级线性规划的可行解，H＋H$_{\rm stop}$ 的插值策略是单向停止线性规划的可行解，所以 $e_H(B)\ge0$，$e_S(B)\ge0$。代入 P4 的定义：

$$
\begin{aligned}
g_{H,{\rm stop}}(B)
&=L_H(B)-L_{\rm H+H_{stop}}(B)\\
&=\big[\mathrm{LB}_{\rm req}(B)+e_H(B)\big]-\big[\mathrm{LB}_{\rm stop}(B)+e_S(B)\big]\\
&=\Delta_{\rm stop}(B)+e_H(B)-e_S(B).
\end{aligned}
$$

$e_H-e_S$ 是两个实际策略距各自事后最优值的差之差，符号不定。停止控制器在块边界停掉 H 误开的第二轮，并把省下的成本经价格重新分给其他请求时，这一项增大（下面的例子中为 0.009）。停止控制器在应当继续的块边界停止，或在应当停止的块边界继续时，$e_S$ 增大，这一项减小。H 已达到请求级事后最优（$e_H=0$）时，只要 $e_S>0$，这一项就为负。这一项不受 $\Delta_{\rm stop}$ 约束，GL3 未通过时 P4 仍然可以超过实用门槛。

例：两篇文档等权，每篇回答两块，预算 $B=1.125$。三个选项的成本与 NLL $(c,\ell)$ 如下：

| 文档 | 全程 $r=1$（$s=1$） | 第 2 块起停止（$s=2$） | 全程 $r=2$（$s=3$） |
|---|---|---|---|
| 1 | $(1,\ 1)$ | $(1.025,\ 0.999)$ | $(1.25,\ 0.990)$ |
| 2 | $(1,\ 1)$ | $(1.025,\ 1.001)$ | $(1.25,\ 1.010)$ |

文档 1 两端点连线的斜率为 $(0.990-1)/0.25=-0.04$，在 $c=1.025$ 处取 $1-0.04\times0.025=0.999$；文档 2 的斜率为 $+0.04$，在同一处取 1.001。两个停止点都落在各自两端点的连线上，加入它们不改变随机化最优值。预算只够一篇整次取 $r=2$，事后最优把它给文档 1：

$$
\mathrm{LB}_{\rm req}(B)=\mathrm{LB}_{\rm stop}(B)=\frac{0.990+1}{2}=0.995,
\qquad
\Delta_{\rm stop}(B)=0 .
$$

设 H 对两篇预测的 $\Delta\hat\ell$ 依次为 $-0.01$、$-0.02$，成本预测等于真实值 0.25。H 在 $0.04\le\lambda<0.08$ 时只对文档 2 启用第二轮，平均成本恰为 1.125，

$$
L_H(B)=\frac{1+1.010}{2}=1.005 .
$$

停止控制器取真实的 $y_{d,2}=\ell^{[2]}_d-\ell^{[3]}_d$ 与真实节省 $c^{[3]}_d-c^{[2]}_d=0.225$。文档 2 的 $y_{2,2}=1.001-1.010=-0.009$，对任何 $\lambda\ge0$ 都满足 $y_{2,2}<0.225\lambda$，启用后总在第 2 块起点停止；文档 1 的 $y_{1,2}=0.999-0.990=0.009$，只在 $\lambda>0.04$ 时停止。于是 H＋H$_{\rm stop}$ 在 $0.04\le\lambda<0.08$ 时只启用文档 2 并停止，平均成本与 NLL 为 $(1.0125,\ 1.0005)$；在 $0\le\lambda<0.04$ 时两篇都启用，文档 1 执行到底，文档 2 停止，为 $(1.1375,\ 0.9955)$。严格同成本插值中高成本点的权重为 $(1.125-1.0125)/(1.1375-1.0125)=0.9$，于是

$$
L_{\rm H+H_{stop}}(B)=0.1\times1.0005+0.9\times0.9955=0.996,
$$

$$
g_{H,{\rm stop}}(B)=1.005-0.996=0.009 .
$$

三项分别为 $\Delta_{\rm stop}=0$、$e_H=1.005-0.995=0.010$、$e_S=0.996-0.995=0.001$，$0+0.010-0.001=0.009$。GL3 为零，P4 超过实用门槛 0.005。

GL3 同时报告跨半版本，作诊断。第 6.3 节的前后分半不适用于停止点：停止点都落在后半时，各选项在前半的 NLL 相同，前半无法区分它们。跨半版本因此按答案内 token 序号的奇偶分组，记 $\ell^{{\rm even},[o]}_d$、$\ell^{{\rm odd},[o]}_d$ 为选项 $o$ 下偶数组、奇数组答案 token 的平均 NLL，分两步计算：

1. 选择。以 $\ell^{{\rm even},[o]}_d$ 代替 $\ell^{[o]}_d$，按第 6.2 节的多选项对偶最优选择求最小最优价格 $\lambda^\ast$，每个请求取 $\ell^{{\rm even},[o]}_d+\lambda^\ast c^{[o]}_d$ 最小的选项；$\lambda^\ast>0$ 时并列选项按文档随机化，使期望成本恰为 $B$，$\lambda^\ast=0$ 时预算可以剩余。
2. 评价。把选出的选项在奇数组上评价，随机化的请求按两个选项的概率加权。

请求级与单向停止都这样计算，两者之差为跨半版本的 $\Delta_{\rm stop}$。

记 $\ell^{{\rm odd},[o]}_d=\mu^{{\rm odd},[o]}_d+\varepsilon^{{\rm odd},[o]}_d$。按第 6.3 节的推导，评价值在下式对全部 $d$ 与 $o$ 成立时不含选择偏差：

$$
\mathbb E\big[\varepsilon^{{\rm odd},[o]}_d\mid\boldsymbol\mu^{\rm odd},\boldsymbol\ell^{\rm even},\boldsymbol c\big]=0 .
$$

奇偶两组来自同一些块，相邻 token 共享上下文，块级的参考答案噪声在两组间共享，这一条件不成立：两组噪声正相关时，偶数组选中的选项在奇数组上的噪声也偏低，跨半版本仍偏乐观。它去掉的只是逐 token 独立噪声带来的选择偏差。

P4 与 P1–P3 固定组成确认族，族大小 $m=4$（第 8.3 节），不随 GL3 的结果改变。P4 的地位随 GL1、GL2 的后果而定：

1. 第 6.4 节判为确认性检验时，P4 与 P1–P3 一起进入确认族。
2. 第 6.4 节判为只报告估计时，P4 与其余比较一样只报告估计与区间。
3. GL1 与 GL2 都未通过时不作控制器比较，P4 也不例外。

前两种情形下停止控制器都照常训练（代价很小）。

由 $e_S(B)\ge0$，同一组文档上有 $g_{H,{\rm stop}}(B)\le L_H(B)-\mathrm{LB}_{\rm stop}(B)=e_H(B)+\Delta_{\rm stop}(B)$。另一种安排是以校准集上的这一上界达到 0.005 作为 P4 进入确认族的门槛：它要在 S5 锁定 H 的价格网格之后、读取确认集之前计算，族的选择只用校准数据，Holm 法的族错误率控制仍然成立。本计划采用固定的族，依据有三点：

1. 功效损失小。Holm 法拒绝每个满足 $p\le0.05/m$ 的比较，所以每个比较的检出概率不低于它在 $0.05/m$ 水平单独检验的检出概率。确认集 2,989 篇、$\sigma=0.067$、真实效应 0.005 时，$0.005\sqrt{2989}/0.067=4.080$；$m=4$ 下这一概率为 $\Phi(4.080-2.2414)=\Phi(1.839)=0.967$，$m=3$ 下为 $\Phi(4.080-2.1280)=\Phi(1.952)=0.975$，相差 0.0075。第 8.4 节的最低篇数 1,707 本来就按 $m=4$ 计算。
2. 这一门槛只在 H 已接近请求级事后最优时排除 P4。门槛排除 P4 当且仅当 $e_H(B)<0.005-\Delta_{\rm stop}(B)$。由 $\Gamma(B)=L_{\rm mix}(B)-\mathrm{LB}_{\rm req}(B)$ 得 $e_H(B)=\Gamma(B)-\big[L_{\rm mix}(B)-L_H(B)\big]$，所以排除等价于 H 相对随机分配的改善超过 $\Gamma(B)+\Delta_{\rm stop}(B)-0.005$。排除时只能推出校准集上的 P4 估计小于 0.005；校准集约 1,121 篇，按 $\sigma=0.067$ 这一估计的标准误约 $0.067/\sqrt{1121}=0.0020$，确认集上的真实效应仍可以达到实用门槛。
3. 固定的族更容易解释。P1–P3 的检验水平与停止控制器在校准集上的表现无关，P4 的地位在读取任何数据之前确定。

GL3 的结果与每块第二轮收益沿回答的分布（第 8.5 节）一起，作为是否推进第二、三级的依据。

## 7. 阶段 4：成本模型与控制器

### 7.1 公共成本模型

按数学验证第 7.1 节的每层矩阵乘账本（记号见第 4.5 节），第二轮与混合在位置 $i$ 上的推理成本对位置是仿射的：

$$
k(i)=k_0+k_1i,\qquad
k_0=12\big(c_{\rm proj}+c_{\rm LoRA}\big)+3\times2048=1{,}397{,}889{,}024,\qquad
k_1=12\times16{,}384=196{,}608 .
$$

$k_0$ 含 12 层的投影与专家矩阵乘、LoRA 前向，以及混合的 $3\times2048=6{,}144$ 次运算（数学验证第 7 节）；$k_1i$ 是 12 层在 $i$ 个键上的查询键乘与注意力值乘。账本若再计入归一化、softmax 等逐位置或逐键的运算，$k_0$、$k_1$ 随之改变，$k$ 仍对 $i$ 仿射，以下推导不变。

请求级 $r=2$ 的第二轮覆盖位置 $1,\ldots,N$，$N=P_d+n_d-1$（第 5.1 节）。等差求和给出 $\sum_{i=1}^{N}(k_0+k_1i)=k_0N+\frac{k_1}2N(N+1)$，其中

$$
N(N+1)=(P_d+n_d-1)(P_d+n_d)=P_d(P_d-1)+(2P_d-1)\,n_d+n_d^2 .
$$

除以 $n_d$，按 $n_d$ 的幂次整理：

$$
\begin{aligned}
\Delta c_d
&=k_0+\frac{k_0(P_d-1)}{n_d}+\frac{k_1}2\Big[\frac{P_d(P_d-1)}{n_d}+(2P_d-1)+n_d\Big]\\
&=\alpha_0(P_d)+\alpha_1\,n_d+\alpha_{-1}(P_d)\,\frac1{n_d},
\end{aligned}
$$

$$
\alpha_0(P)=k\Big(P-\frac12\Big)=k_0+k_1\Big(P-\frac12\Big),\qquad
\alpha_1=\frac{k_1}2=98{,}304,\qquad
\alpha_{-1}(P)=(P-1)\Big(k_0+\frac{k_1P}2\Big).
$$

例如 $P_d=100$、$n_d=150$ 时，$\alpha_0=1{,}417{,}451{,}520$，$\alpha_1n_d=14{,}745{,}600$，$\alpha_{-1}/n_d=929{,}094{,}819.84$，合计 $\Delta c_d=2{,}361{,}291{,}939.84$ FLOPs/答案 token，与逐位置求和 $354{,}193{,}790{,}976/150$ 相同。

决策时 $P_d$ 已知（$z_d$ 含 $\log(1+P_d)$），只有 $n_d$ 未知。取条件期望：

$$
\mathbb E[\Delta c_d\mid z_d]=\alpha_0(P_d)+\alpha_1\,\mathbb E[n_d\mid z_d]+\alpha_{-1}(P_d)\,\mathbb E[1/n_d\mid z_d].
$$

两个条件矩都要估计，$\mathbb E[n\mid z]$ 也不能由 $1/\mathbb E[1/n\mid z]$ 代替。例：$n\equiv100$ 与 $\Pr(n=50)=\frac13$、$\Pr(n=200)=\frac23$ 的 $\mathbb E[1/n]$ 都是 $0.01$，$\mathbb E[n]$ 分别为 100 与 150；$P=100$ 时两者的 $\mathbb E[\Delta c]$ 相差 $\alpha_1\times50=4{,}915{,}200$ FLOPs/答案 token，为前者 $2{,}820{,}924{,}149.76$ 的 0.17%。$\alpha_1n_d$ 一项在 $P_d=100$、$n_d=150$ 时占 $\Delta c_d$ 的 0.62%，在 $P_d=500$、$n_d=2000$ 时占 9.6%。

成本模型把两个条件矩取为 $\tilde z_d$ 的线性函数代入上式，系数以账本的 $\Delta c_d$ 为目标联合拟合。$\tilde z_d$ 是 $z_d$ 按拟合折统计量标准化后加截距的 5 维向量。岭回归的特征为 $[\tilde z_d;\alpha_{-1}(P_d)\tilde z_d]$，共 10 个参数，目标为 $\Delta c_d-\alpha_0(P_d)$，预测为

$$
\widehat{\Delta c}_d=\alpha_0(P_d)+\max\Big\{0,\ \hat\zeta^\top\big[\tilde z_d;\alpha_{-1}(P_d)\tilde z_d\big]\Big\}.
$$

若 $\mathbb E[n\mid z]=\zeta_1^\top\tilde z$ 且 $\mathbb E[1/n\mid z]=\zeta_{-1}^\top\tilde z$，回归目标的条件均值为 $(\alpha_1\zeta_1)^\top\tilde z+\zeta_{-1}^\top\big(\alpha_{-1}(P)\tilde z\big)$，落在特征的线性组合之内，模型正确设定。

两种更简单的做法各有缺陷：

1. 两个矩分别拟合再代入。$1/n$ 的回归按未经放大的误差选择系数，而这一误差要乘以 $\alpha_{-1}(P_d)$ 才进入 $\widehat{\Delta c}_d$；$\alpha_{-1}(100)=139{,}364{,}222{,}976$，且 $\alpha_{-1}(P_d)$ 约与 $P_d$ 成正比，提示词越长，误差放大越多。
2. 在 $\tilde z_d$ 上直接回归 $\Delta c_d$。$\alpha_0(P_d)$、$\alpha_{-1}(P_d)$ 对 $P_d$ 近似线性，对 $z_d$ 中的 $\log(1+P_d)$ 呈指数型，线性函数表示不了这一依赖。

截断的依据是目标 $\alpha_1n_d+\alpha_{-1}(P_d)/n_d$ 恒为正，其条件均值 $\mu\ge0$。对任意预测值 $\hat t$：$\hat t\ge0$ 时 $\max\{0,\hat t\}=\hat t$，误差不变；$\hat t<0$ 时 $|0-\mu|=\mu\le\mu-\hat t=|\hat t-\mu|$。所以截断不增大平方误差，并保证 $\widehat{\Delta c}_d\ge\alpha_0(P_d)>0$。

查询成本 $c_{Q,d}=C_Q(P_d)/n_d$（第 7.3 节）需要 $\mathbb E[1/n_d\mid z_d]$。第二个岭回归以 $1/n_d$ 为目标、$\tilde z_d$ 为特征，共 5 个参数，预测 $\hat\mu_{-1}(z_d)=\max\{0,\hat\zeta_{-1}^\top\tilde z_d\}$。$C_Q(P_d)$ 在决策时已知，$\hat c_{Q,d}=C_Q(P_d)\,\hat\mu_{-1}(z_d)$。

两个回归每个拟合请求一行、权重相同，即文档等权。标准化、截距不加惩罚与正规方程沿用数学验证第 9.3 节；岭系数网格与选择规则同第 7.2 节的 R，按文档分组的五折验证以各自目标的均方误差选择。模型只读 $z_d$，供全部请求级控制器（R、Z、H、N、Q）与门控共用，比较各控制器时成本预测相同。评价一律使用实际账本。块边界的成本模型见第 7.6 节。

全部回归器的输入按同一通则处理：公共成本模型、R、Z、H、N、Q、门控与停止控制器的输入都按拟合折上的均值与标准差标准化，拟合折上方差为零的维度标准化后恒取 0。

### 7.2 H、只读状态基线 Z、阴性对照 N 与线性基线 R

四者的目标都是 $\Delta\ell_d$，样本权重都是文档等权，交叉验证折都按文档分组。H、Z、N 由同一份训练代码按输入列生成，除输入列与第一层的输入维数外，结构与训练设置逐项相同：

1. H：多层感知机，结构为 $2052\to256\to256\to1$，GELU 激活，输入 $[h^1_{d,P};z_d]$。以加权均方误差训练，AdamW 学习率 $10^{-3}$，权重衰减 0.01，每批 256 个请求，至多 100 个 epoch；从拟合请求中按文档哈希留出 10% 作验证，连续 5 个 epoch 不改善即停止，种子 17。参数为 $2052\times256+256+256\times256+256+256+1=591{,}617$ 个。
2. Z：与 H 相同，输入只有 $z_d$，结构为 $4\to256\to256\to1$，参数为 $(4\times256+256)+(256\times256+256)+(256+1)=1{,}280+65{,}792+257=67{,}329$ 个。Z 与 H 只差输入是否含 $h^1_{d,P}$，是 P2 的对照（第 8.3 节）。
3. N：与 H 相同，只是把 $h^1_{d,P}$ 换成按请求标识播种的 2048 维标准正态噪声，参数同为 591,617 个。N 与 Z 只差 2048 维噪声输入，它的对照对象是 Z。
4. R：在 $z_d$ 上做岭回归（4 维加截距，5 个参数），岭系数网格 $\{10^{-6},\ldots,10^{1}\}$，选中边缘时向外扩展两个十倍点一次，并列取较小者。R 对应 v3.3 中只读位置与执行状态的基线。v3.3 的 H 与 R 都是岭回归，两者只差输入；本计划的 H 是多层感知机，与 R 同时差输入和函数类，所以 R 只作描述性线性基线（第 8.5 节第 3 项）。

输入标准化按第 7.1 节的通则。本计划的拟合、校准与确认请求都来自数学数据，来源独热编码在这些请求上为常数，Z 实际读取 $\log(1+P_d)$ 与 $\log(1+\text{提示词行数})$ 两个变量。

Z 与 R 输入相同、函数类不同，非线性读出在总体分布上可以严格优于线性读出。设 $z$ 中一个中心化的标量 $x$ 等概率取 $-1$、$0$、$1$，$\Delta\ell=-(1+x^2)$，$\Delta c=1$，成本模型给出精确值，预算至多允许三分之二的请求取 $r=2$。记 $p(x)$ 为取 $r=2$ 的概率，相对全部取 $r=1$ 的 NLL 改善为 $\frac13\big[2p(-1)+p(0)+2p(1)\big]$，预算约束为 $p(-1)+p(0)+p(1)\le2$。线性读出的预测是 $x$ 的线性函数，每个价格下取 $r=2$ 的请求是 $x$ 的一个上水平集或下水平集；严格同成本插值混合两个相邻价格的嵌套集合，所以 $p(x)$ 对 $x$ 单调。以非增情形为例（非减情形对称），预算用尽时 $p(-1)+p(0)+p(1)=2$，

$$
\frac13\big[2p(-1)+p(0)+2p(1)\big]
=\frac13\Big[2\big(p(-1)+p(0)+p(1)\big)-p(0)\Big]
=\frac13\big[4-p(0)\big].
$$

由 $p(-1)\le1$ 得 $p(0)+p(1)\ge1$，再由 $p(0)\ge p(1)$ 得 $p(0)\ge\frac12$，所以改善至多为 $\frac13\big(4-\frac12\big)=\frac76$，在 $p=(1,\frac12,\frac12)$ 处取到。预算只用去 $S_p=p(-1)+p(0)+p(1)<2$ 时，同样的推导给出 $p(0)\ge\max\big(0,\frac{S_p-1}2\big)$，改善至多为 $\frac13\big[2S_p-\max\big(0,\frac{S_p-1}2\big)\big]<\frac76$。非线性读出可以学到 $x^2$，取 $p=(1,0,1)$，改善为 $\frac13(2+0+2)=\frac43$。两者相差至少 $\frac43-\frac76=\frac16$。这一差距在总体分布上存在，来源是函数类。所以 H 相对 R 的改善混合了首轮表示与非线性读出两个因素，首轮表示的价值由 H 对 Z 测量。

N 的作用由下面的性质确定。评价请求不参与拟合，N 的参数只由拟合请求决定；评价请求的噪声 $\xi$ 由请求标识播种，与 $(z,\Delta\ell,\Delta c)$ 独立。固定价格 $\lambda$，记 $\delta_\lambda=\Delta\ell+\lambda\Delta c$。N 的动作 $a\in\{0,1\}$ 是 $(z,\xi)$ 的函数，令

$$
p(z)=\Pr(a=1\mid z),\qquad
\bar\delta_\lambda(z)=\mathbb E[\delta_\lambda\mid z],\qquad
a^*(z)=\mathbf 1[\bar\delta_\lambda(z)<0].
$$

$a^*$ 是只读 $z$ 的最优规则，它相对全部取 $r=1$ 的期望代价增量为 $\mathbb E[\min(0,\bar\delta_\lambda(z))]$。给定 $z$ 时 $a$ 只随 $\xi$ 变化，与 $\delta_\lambda$ 独立，所以

$$
\mathbb E[a\,\delta_\lambda]
=\mathbb E\big[\mathbb E[a\mid z]\,\mathbb E[\delta_\lambda\mid z]\big]
=\mathbb E\big[p(z)\,\bar\delta_\lambda(z)\big].
$$

$\bar\delta_\lambda(z)<0$ 时 $a^*(z)=1$，$p\,\bar\delta_\lambda-\min(0,\bar\delta_\lambda)=p\,\bar\delta_\lambda-\bar\delta_\lambda=(1-p)\lvert \bar\delta_\lambda\rvert$；$\bar\delta_\lambda(z)\ge0$ 时 $a^*(z)=0$，$p\,\bar\delta_\lambda-\min(0,\bar\delta_\lambda)=p\lvert \bar\delta_\lambda\rvert$。两种情形都等于 $\lvert \bar\delta_\lambda(z)\rvert\cdot\lvert p(z)-a^*(z)\rvert$，所以

$$
\mathbb E[a\,\delta_\lambda]-\mathbb E\big[\min(0,\bar\delta_\lambda(z))\big]
=\mathbb E\Big[\lvert \bar\delta_\lambda(z)\rvert\cdot\lvert p(z)-a^*(z)\rvert\Big]\ \ge0 .
$$

例：$z$ 等概率取两个值，$\bar\delta_\lambda$ 分别为 $-0.03$ 与 $+0.01$，噪声使两个值上各有 20% 的请求偏离 $a^*$，N 的期望代价比 $a^*$ 高 $\frac12\times0.03\times0.2+\frac12\times0.01\times0.2=0.004$。

同一独立性给出同成本口径下的结论。N 的期望 NLL 与期望成本都只经 $p(z)$ 依赖动作，与“以概率 $p(z)$ 取 $r=2$”的只读 $z$ 随机规则相同；严格同成本插值混合两个价格的规则，结果仍是只读 $z$ 的随机规则。所以在任一预算 $B$ 处，N 的期望 NLL 不低于只读 $z$ 的最优随机规则所能达到的值 $L^*_z(B)$。

过拟合噪声特征的效果正是让 $p(z)$ 偏离 $a^*(z)$。拟合请求上，模型见过每个噪声向量及其标签，可以靠记忆降低训练误差，loopjev 的阴性对照在样本内回收 24.34% 即属此类；评价请求的噪声是新抽取的，记忆只留下上式右端的损失。

Z 也是只读 $z$ 的规则，期望 NLL 同样不低于 $L^*_z(B)$。N 在样本外明显优于 Z（双侧 95% 区间位于零以上）时，除抽样误差外只有两种来源：

1. 独立性不成立，评价流程让噪声携带了标签信息，例如拟合请求与评价请求共用请求标识、折划分错位或标签表行序错位。
2. Z 离 $L^*_z(B)$ 比 N 更远，即同一训练流程在 4 维输入上没有学到 N 在 2052 维输入上学到的 $z$ 的作用；这时 P2 会把 Z 的不足记为首轮表示的价值。

两种来源都使 P2 不能按首轮表示的价值解读。读取确认集前，先在校准集上计算 $g_{ZN}=L_Z(B)-L_N(B)$；其双侧 95% 区间位于零以上时，核对请求标识、折划分与标签表的对应关系，检查 H、Z、N 的验证损失曲线，修正对三者同时生效，重新锁定预测器与价格后再读取确认集。提示词在拟合与评价之间重复的通道由第 5.4 节的去重处理。

### 7.3 只读查询控制器 Q

Q 的查询为 512 维，恰好等于第 43 层 4 个 KV 头乘以头维 128。初始查询由 $[h^1_{d,P};z_d]$ 线性映射得到：$q^0=W_{\rm in}\operatorname{std}([h^1_{d,P};z_d])$。对第 $k=1,2$ 层，把 $W^k_Q q^{k-1}$ 按头切成 4 段，每段与对应 KV 头的提示词键做点积注意力：

$$
a^k_j=\operatorname{softmax}\!\Big(\frac{K_{43,j}\,(W^k_Qq^{k-1})_j}{\sqrt{128}}\Big)^{\!\top}V_{43,j},
\qquad j=1,\ldots,4,
$$

$$
\tilde q^k=q^{k-1}+W^k_O[a^k_1;\ldots;a^k_4],\qquad
q^k=\tilde q^k+\operatorname{MLP}^k\big(\operatorname{LN}(\tilde q^k)\big),
$$

其中 MLP 为 $512\to1024\to512$。键与值按缓存原样读取，其中键已经过 Qwen3 的逐头键归一化与旋转位置编码（Rotary Position Embedding，RoPE）；查询不加位置编码。输出以 H 为起点学习残差：

$$
\Delta\hat\ell_Q=\Delta\hat\ell_H+w_{\rm out}^\top\operatorname{LN}(q^2)+b_{\rm out}.
$$

参数量逐项为：输入映射 $2052\times512+512=1{,}051{,}136$；每层 $W_Q$、$W_O$（各 $512\times512+512$）、MLP（$512\times1024+1024+1024\times512+512$）与一个层归一化合计 1,576,448，两层 3,152,896；输出前的层归一化 1,024 与输出 513。总计 4,205,569，约 4.21M。

Q 只读取已有 KV，不写任何生成缓存，也不增加 token。每次查询的计算量约为

$$
C_Q(P)\approx8.4\times10^6+4096\,P\ \text{FLOPs},
$$

其中 $4096P$ 是两层、四个头在 $P$ 个提示词位置上的点积与加权求和。Q 以与 H 相同的目标和权重训练，残差的基 $\Delta\hat\ell_H$ 冻结：训练请求上取第 7.5 节嵌套交叉拟合给出的折外预测，部署时取最终的 H。AdamW 学习率 $3\times10^{-4}$，权重衰减 0.01，每批 128 个请求，至多 50 个 epoch，早停规则同 H。

### 7.4 门控：查询的真实收益

把一次决策的代价写成 $\delta=\Delta\ell+\lambda\Delta c$，$\delta<0$ 时应取 $r=2$。设决策前的信息为 $\mathcal F$（H 可见的信息），查询 Q 后的信息为 $\mathcal G\supset\mathcal F$。记 $\bar\delta_{\mathcal F}=\mathbb E[\delta\mid\mathcal F]$，$\bar\delta_{\mathcal G}=\mathbb E[\delta\mid\mathcal G]$，由全期望公式 $\mathbb E[\bar\delta_{\mathcal G}\mid\mathcal F]=\bar\delta_{\mathcal F}$。

以“全部取 $r=1$”为参照，按信息 $\mathcal F$ 决策的期望代价增量为 $\min(0,\bar\delta_{\mathcal F})$，查询后为 $\mathbb E[\min(0,\bar\delta_{\mathcal G})\mid\mathcal F]$。查询带来的期望改善为

$$
I=\min(0,\bar\delta_{\mathcal F})-\mathbb E\big[\min(0,\bar\delta_{\mathcal G})\mid\mathcal F\big]\ \ge\ 0,
$$

不等号来自 $\min(0,\cdot)$ 的凹性与 Jensen 不等式。记 $\varsigma^2=\operatorname{Var}(\bar\delta_{\mathcal G}\mid\mathcal F)$。$\varsigma=0$ 时 $\bar\delta_{\mathcal G}=\bar\delta_{\mathcal F}$ 几乎必然成立，查询不改变决策，$I=\min(0,\bar\delta_{\mathcal F})-\min(0,\bar\delta_{\mathcal F})=0$。$\varsigma>0$ 时设 $\bar\delta_{\mathcal G}\mid\mathcal F\sim\mathcal N(\bar\delta_{\mathcal F},\varsigma^2)$，截断正态的一阶矩给出

$$
\mathbb E\big[\min(0,\bar\delta_{\mathcal G})\big]=\int_{-\infty}^{0}x\,\frac1\varsigma\varphi\!\Big(\frac{x-\bar\delta_{\mathcal F}}{\varsigma}\Big)\,dx
=\bar\delta_{\mathcal F}\,\Phi\!\Big(-\frac{\bar\delta_{\mathcal F}}{\varsigma}\Big)-\varsigma\,\varphi\!\Big(\frac{\bar\delta_{\mathcal F}}{\varsigma}\Big).
$$

$\bar\delta_{\mathcal F}\ge0$ 时，$I=\varsigma\varphi(\bar\delta_{\mathcal F}/\varsigma)-\bar\delta_{\mathcal F}\Phi(-\bar\delta_{\mathcal F}/\varsigma)$。$\bar\delta_{\mathcal F}<0$ 时，

$$
I=\bar\delta_{\mathcal F}-\bar\delta_{\mathcal F}\Phi(-\bar\delta_{\mathcal F}/\varsigma)+\varsigma\varphi(\bar\delta_{\mathcal F}/\varsigma)=\bar\delta_{\mathcal F}\Phi(\bar\delta_{\mathcal F}/\varsigma)+\varsigma\varphi(\bar\delta_{\mathcal F}/\varsigma)=\varsigma\varphi(|\bar\delta_{\mathcal F}|/\varsigma)-|\bar\delta_{\mathcal F}|\Phi(-|\bar\delta_{\mathcal F}|/\varsigma).
$$

两种情形合并为

$$
I=\varsigma\,\psi\!\Big(\frac{|\bar\delta_{\mathcal F}|}{\varsigma}\Big),\qquad \psi(t)=\varphi(t)-t\,\Phi(-t).
$$

上式对 $\varsigma>0$ 成立，$\varsigma=0$ 时 $I=0$。两者在 $\varsigma\to0^+$ 处衔接：$t\Phi(-t)\ge0$ 给出 $\psi(t)\le\varphi(t)\le\varphi(0)$，所以 $0\le \varsigma\,\psi(|\bar\delta_{\mathcal F}|/\varsigma)\le0.3989\,\varsigma\to0$。

$\psi(t)$ 是标准正态变量 $X$ 超出 $t$ 部分的期望：

$$
\psi(t)=\int_t^\infty(x-t)\,\varphi(x)\,dx=\varphi(t)-t\,\Phi(-t)=\mathbb E\big[(X-t)^+\big]>0 .
$$

由 $\varphi'(t)=-t\varphi(t)$ 与 $\tfrac{d}{dt}\Phi(-t)=-\varphi(t)$，

$$
\psi'(t)=-t\varphi(t)-\Phi(-t)+t\varphi(t)=-\Phi(-t)<0 ,
$$

所以 $\psi$ 在 $t\ge0$ 上单调下降，$\psi(0)=\varphi(0)=0.3989$。决策越接近边界（$|\bar\delta_{\mathcal F}|$ 越小），查询越有价值，最大改善为 $0.3989\,\varsigma$。远离边界时改善下降很快：$\psi(1)=0.0833$，$\psi(2)=8.49\times10^{-3}$，$\psi(3)=3.82\times10^{-4}$，$\psi(4)=7.15\times10^{-6}$。

这一公式描述理想决策器：H 的输出等于 $\mathbb E[\Delta\ell\mid\mathcal F]$，Q 的输出等于 $\mathbb E[\Delta\ell\mid\mathcal G]$，成本预测同时等于 $\mathbb E[\Delta c\mid\mathcal F]$ 与 $\mathbb E[\Delta c\mid\mathcal G]$。三条都成立时，H 与 Q 的决策量就是 $\bar\delta_{\mathcal F}$ 与 $\bar\delta_{\mathcal G}$。已训练的 H、Q 与公共成本模型偏离这三条，带来两处差别。

第一处差别：两个模型预测之差的平方把估计误差计作信息。记 $e=\Delta\hat\ell_Q-\Delta\hat\ell_H$，它的条件二阶矩为

$$
\mathbb E[e^2\mid\mathcal F]=\operatorname{Var}(e\mid\mathcal F)+\big(\mathbb E[e\mid\mathcal F]\big)^2 .
$$

右边第二项是 Q 相对 H 的系统偏差；第一项除了 $\mathcal G$ 带来的信息，还包含 Q 的估计噪声。两项都抬高 $\varsigma$，而 $\varsigma\,\psi(|\bar\delta_{\mathcal F}|/\varsigma)$ 恒为正，表示不出“按 Q 决策更差”。取 $\lambda=0$，此时 $\delta=\Delta\ell$，两个例子：

1. 系统偏差：真实 $\Delta\ell\equiv1$，H 输出 1，Q 输出 $-1$。平方差恒为 4，按 $\bar\delta_{\mathcal F}=1$、$\varsigma=2$ 得 $I=2\psi(0.5)=0.3956$。实际上 H 选 $r=1$，Q 改选 $r=2$，代价增加 1。
2. 估计噪声：H 输出 $\bar\delta_{\mathcal F}=\mathbb E[\Delta\ell\mid\mathcal F]$，Q 输出 $\bar\delta_{\mathcal F}+\eta$，$\eta\sim\mathcal N(0,\sigma_\eta^2)$ 与 $\Delta\ell$ 独立，Q 不带来新信息。此时 $\mathbb E[e\mid\mathcal F]=0$，$\mathbb E[e^2\mid\mathcal F]=\sigma_\eta^2$，公式给出 $\sigma_\eta\,\psi(|\bar\delta_{\mathcal F}|/\sigma_\eta)>0$。实际上 Q 以概率 $\Phi(-|\bar\delta_{\mathcal F}|/\sigma_\eta)$ 选与 H 相反的轮数，每次使期望代价增加 $|\bar\delta_{\mathcal F}|$，查询的期望收益为 $-|\bar\delta_{\mathcal F}|\,\Phi(-|\bar\delta_{\mathcal F}|/\sigma_\eta)$。$|\bar\delta_{\mathcal F}|=0.5\sigma_\eta$ 时，公式给出 $0.1978\,\sigma_\eta$，实际为 $-0.1543\,\sigma_\eta$。

第二处差别：公共成本模型使实现中的决策量与 $\bar\delta_{\mathcal F}$、$\bar\delta_{\mathcal G}$ 不同。H 与 Q 共用只读 $z$ 的成本预测，查询只更新 NLL 的预测。取 $\lambda=1$、$\Delta\ell\equiv-1$，查询揭示两种等概率的类型，成本差分别为 0.5 与 2，公共成本预测为 1.25，H 与 Q 都输出 $-1$。理论量为 $\bar\delta_{\mathcal F}=-1+1.25=0.25$，$\bar\delta_{\mathcal G}\in\{-0.5,\,1\}$，

$$
I=\min(0,0.25)-\tfrac12\big[\min(0,-0.5)+\min(0,1)\big]=0.25 .
$$

实现中 H 与 Q 都按 $-1+1.25>0$ 选 $r=1$，查询的实际收益为 0。$I$ 衡量的是查询后同时更新成本预测的决策器。

门控因此直接学习已训练规则的真实收益。记公共成本模型的成本差预测为 $\widehat{\Delta c}_d$（第 7.1 节），价格 $\lambda$ 下 H 与 Q 的动作为

$$
a_{H,d}(\lambda)=\mathbf 1\big[\Delta\hat\ell_{H,d}+\lambda\widehat{\Delta c}_d<0\big],
\qquad
a_{Q,d}(\lambda)=\mathbf 1\big[\Delta\hat\ell_{Q,d}+\lambda\widehat{\Delta c}_d<0\big],
$$

即附图的选择规则分别使用 H 与 Q 时的选择，取 1 表示 $r=2$。以“全部取 $r=1$”为参照，动作 $a$ 的实际代价增量为 $a\,\delta_d(\lambda)$，其中 $\delta_d(\lambda)=\Delta\ell_d+\lambda\Delta c_d$ 用真实标签与实际账本。查询的真实收益定义为

$$
\Delta^{\rm Q}_d(\lambda)=a_{H,d}(\lambda)\,\delta_d(\lambda)-a_{Q,d}(\lambda)\,\delta_d(\lambda)
=\big(a_{H,d}(\lambda)-a_{Q,d}(\lambda)\big)\big(\Delta\ell_d+\lambda\Delta c_d\big).
$$

两条规则选择相同时 $\Delta^{\rm Q}_d(\lambda)=0$；Q 改选后代价下降时 $\Delta^{\rm Q}_d(\lambda)>0$，上升时 $\Delta^{\rm Q}_d(\lambda)<0$。系统偏差与估计噪声直接表现为负收益，成本的差别由实际账本 $\Delta c_d$ 计入。

**命题 4。** 固定 H、Q 与公共成本模型，门控只读取 $\mathcal F$。记 $\gamma\in\{0,1\}$ 为是否查询，$c_Q=C_Q(P)/n$ 为实际的每答案 token 查询成本，单个请求的代价增量为 $(1-\gamma)a_H\delta+\gamma(a_Q\delta+\lambda c_Q)$。在所有只读 $\mathcal F$ 的门控规则中，期望代价最小的规则为

$$
\gamma^*=\mathbf 1\Big[\mathbb E\big[\Delta^{\rm Q}(\lambda)\mid\mathcal F\big]>\lambda\,\mathbb E\big[c_Q\mid\mathcal F\big]\Big].
$$

若 H、Q 与成本预测满足上述三个理想条件，则 $\mathbb E[\Delta^{\rm Q}(\lambda)\mid\mathcal F]=I$。

**证明。** $\gamma$ 与 $a_H$ 只依赖 $\mathcal F$，可以移出条件期望：

$$
\begin{aligned}
&\mathbb E\big[(1-\gamma)a_H\delta+\gamma(a_Q\delta+\lambda c_Q)\mid\mathcal F\big]\\
&\quad=a_H\,\mathbb E[\delta\mid\mathcal F]-\gamma\Big(a_H\,\mathbb E[\delta\mid\mathcal F]-\mathbb E[a_Q\delta\mid\mathcal F]-\lambda\,\mathbb E[c_Q\mid\mathcal F]\Big)\\
&\quad=a_H\,\mathbb E[\delta\mid\mathcal F]-\gamma\Big(\mathbb E\big[\Delta^{\rm Q}(\lambda)\mid\mathcal F\big]-\lambda\,\mathbb E[c_Q\mid\mathcal F]\Big).
\end{aligned}
$$

第一项与 $\gamma$ 无关；括号为正时取 $\gamma=1$ 使第二项最小，否则取 $\gamma=0$。评价目标对文档可分（第 5.1 节），逐请求取最小即得全局最优。

理想条件下 $a_H=\mathbf 1[\bar\delta_{\mathcal F}<0]$，$a_Q=\mathbf 1[\bar\delta_{\mathcal G}<0]$。$a_Q$ 只依赖 $\mathcal G$，由全期望公式

$$
\mathbb E[a_Q\delta\mid\mathcal F]
=\mathbb E\big[a_Q\,\mathbb E[\delta\mid\mathcal G]\mid\mathcal F\big]
=\mathbb E\big[\mathbf 1[\bar\delta_{\mathcal G}<0]\,\bar\delta_{\mathcal G}\mid\mathcal F\big]
=\mathbb E\big[\min(0,\bar\delta_{\mathcal G})\mid\mathcal F\big],
$$

同理 $a_H\,\mathbb E[\delta\mid\mathcal F]=\mathbf 1[\bar\delta_{\mathcal F}<0]\,\bar\delta_{\mathcal F}=\min(0,\bar\delta_{\mathcal F})$。两式相减得 $\mathbb E[\Delta^{\rm Q}(\lambda)\mid\mathcal F]=I$。证毕。

高斯公式因此是 $\mathbb E[\Delta^{\rm Q}(\lambda)\mid\mathcal F]$ 在理想条件下的特例，本节保留它作为门控的动机：查询的价值集中在决策边界附近。一般情形下 $\mathbb E[\Delta^{\rm Q}(\lambda)\mid\mathcal F]$ 可以为负，门控此时不查询。

门控用回归估计 $\mathbb E[\Delta^{\rm Q}(\lambda)\mid\mathcal F]$，记其输出为 $\hat\Delta^{\rm Q}_d(\lambda)$。标签、价格、权重与模型规定如下：

1. 标签：拟合请求 $d$ 的 $\Delta\hat\ell_{H,d}$、$\Delta\hat\ell_{Q,d}$ 与 $\widehat{\Delta c}_d$ 取第 7.5 节嵌套交叉拟合给出的折外预测，$a_{H,d}$、$a_{Q,d}$ 由它们按上式得到；$\delta_d(\lambda)$ 用该请求的真实 $\Delta\ell_d$ 与实际账本 $\Delta c_d$。
2. 训练价格集合：记 $\lambda^{\rm H}_d=-\Delta\hat\ell_{H,d}/\widehat{\Delta c}_d$、$\lambda^{\rm Q}_d=-\Delta\hat\ell_{Q,d}/\widehat{\Delta c}_d$ 为两条规则在请求 $d$ 上的保本价格，$\widehat{\Delta c}_d>0$ 时 $a_{H,d}(\lambda)=1$ 当且仅当 $\lambda<\lambda^{\rm H}_d$，Q 同理。令 $\lambda_{\rm lo}$、$\lambda_{\rm hi}$ 为全部拟合请求的正保本价格中的最小值与最大值，训练价格集合 $\Lambda_{\rm fit}$ 由 $\lambda=0$ 与 $[\lambda_{\rm lo},\lambda_{\rm hi}]$ 上 64 个对数等距的价格组成，共 65 个，在 S4 内由拟合集确定。$\lambda\ge\lambda_{\rm hi}$ 时两条规则在全部拟合请求上都选 $r=1$，$\Delta^{\rm Q}$ 恒为零；$0<\lambda<\lambda_{\rm lo}$ 时两条规则的动作与 $\lambda=0$ 时相同，$\Delta^{\rm Q}$ 随 $\lambda$ 线性变化。$\Lambda_{\rm fit}$ 因此覆盖拟合集上 $\Delta^{\rm Q}$ 随价格变化的全部区间。
3. 样本与权重：每个拟合请求在每个价格上提供一行，20,000 个拟合请求共 1,300,000 行，每行权重为 1，即文档等权、价格等权。权重只依赖价格，价格又是门控的输入，所以加权均方误差在每个 $(\mathcal F,\lambda)$ 处的总体最小值点仍是 $\mathbb E[\Delta^{\rm Q}(\lambda)\mid\mathcal F]$。
4. 模型：多层感知机 $2056\to64\to64\to1$，GELU 激活，输出为线性，不加非负约束。输入为 $[h^1_{d,P};z_d;\Delta\hat\ell_{H,d};\widehat{\Delta c}_d;\lambda\widehat{\Delta c}_d;\Delta\hat\ell_{H,d}+\lambda\widehat{\Delta c}_d]$，按训练集合的统计量标准化；价格以 $\lambda\widehat{\Delta c}_d$ 与 H 的决策边际进入输入，$\lambda=0$ 也能表示。参数为 $2056\times64+64+64\times64+64+64+1=135{,}873$ 个。训练设置同 H：AdamW 学习率 $10^{-3}$，权重衰减 0.01，每批 256 个请求，每个请求的 65 行在同一批，至多 100 个 epoch；按文档哈希留出 10% 的请求连同其全部价格行作验证，连续 5 个 epoch 不改善即停止，种子 17。

部署规则实现附图的判断“预计查询改善 > λ × 查询成本”，预计查询改善取 $\hat\Delta^{\rm Q}_d(\lambda)$。$\lambda\le\lambda_{\rm hi}$ 时，

$$
\text{查询 Q}\iff\hat\Delta^{\rm Q}_d(\lambda)>\lambda\,\hat c_{Q,d},
\qquad
\hat c_{Q,d}=C_Q(P_d)\,\hat\mu_{-1}(z_d),
$$

查询时按 $a_{Q,d}(\lambda)$ 选择轮数，否则按 $a_{H,d}(\lambda)$。$\hat c_{Q,d}$ 是按答案 token 归一的查询成本 $c_{Q,d}=C_Q(P_d)/n_d$ 的预测，$\hat\mu_{-1}(z_d)$ 是公共成本模型对 $\mathbb E[1/n_d\mid z_d]$ 的预测（第 7.1 节），用它代替 $\mathbb E[1/n_d\mid\mathcal F]$。$\lambda>\lambda_{\rm hi}$ 时不查询，按 H 决策，因为拟合集上这些价格处 $\Delta^{\rm Q}$ 恒为零。S5 为 HQ 族锁定价格网格时门控已经固定，$\lambda$ 只是它的输入，校准集不参与门控的训练。门控的校准在校准集上检验（第 8.5 节第 2 项）。

按 FLOPs 账本，Q 的费用很小。GSM8K 类请求取 $P=100$、$n=150$ 时，$C_Q=8.4\times10^6+4096\times100\approx8.81\times10^6$ FLOPs，整次请求在 $r=1$ 下约 $1.49\times10^{12}$ FLOPs（位置 1 到 249 上的 48 层与 16 层 LoRA，加 150 个预测位置上的词表头），比值约 $5.9\times10^{-6}$；以全部 $r=1$ 的每 token 成本为单位，$c_Q\approx5.9\times10^{-6}$。价格 $\lambda=1$ 时阈值 $\lambda c_Q\approx5.9\times10^{-6}$ nat/token，为实用门槛 0.005 的 0.12%。

阈值接近零，门控因此几乎只按 $\hat\Delta^{\rm Q}_d(\lambda)$ 的符号决定：预计按 Q 决策更好的请求查询，预计 Q 会改坏决策的请求按 H 决策。查询率由 $\hat\Delta^{\rm Q}_d(\lambda)$ 的分布决定，在校准集上按价格报告；查询成本低只说明阈值低。理想高斯情形同样如此：$\varsigma=0.005$、$\lambda=0.1$ 时，$\varsigma\,\psi(|\bar\delta_{\mathcal F}|/\varsigma)>\lambda c_Q$ 只在 $|\bar\delta_{\mathcal F}|<3.32\,\varsigma=0.0166$ 的请求上成立。

同一价格 $\lambda$ 下，HQ 与“总是查询”的 Q 的确定性策略只在门控不查询的请求上不同。两族在主预算 $B$ 处的严格同成本差由第 8.5 节第 2 项测量；两族的价格网格不同，达到 $B$ 所用的价格点与混合权重一般也不同，所以这一差值还包含被查询请求上随价格改变的决策。P3 比较 H 与 HQ，衡量查询与门控合在一起的增益。

成本计入首 token 延迟时阈值变大，门控同时决定是否为查询付费；成本口径列为待确认事项（第 12 节第 4 项）。

### 7.5 嵌套交叉拟合

拟合请求按哈希分成 5 折，写法与第 4.2 节相同：

$$
\operatorname{fold}(d)=\operatorname{int}_{\rm BE}\big[\operatorname{SHA256}(\text{UTF-8}(\texttt{jev-v4-request2-fold})\,\|\,\texttt{0x00}\,\|\,\text{UTF-8}(\text{请求标识}))\big]\bmod5 .
$$

记 $\mathcal D_{-k}=\{d:\operatorname{fold}(d)\ne k\}$ 为第 $k$ 折以外的拟合请求，$\mathcal D_{-jk}=\{d:\operatorname{fold}(d)\notin\{j,k\}\}$。协议要求：用在第 $k$ 折请求上的任何折外预测，其模型参数、输入标准化统计量、早停验证划分与超参数选择都只由 $\mathcal D_{-k}$ 中请求的特征与标签决定。Q 以 H 的预测为残差基，门控的标签同时用到 H、Q 与成本模型的预测，拟合因此分六步：

1. 内层 H：对每个无序折对 $\{j,k\}$，在 $\mathcal D_{-jk}$ 上训练 H$_{-jk}$，共 $\binom52=10$ 个。
2. 外层 H 与成本模型：对每个 $k$，在 $\mathcal D_{-k}$ 上训练 H$_{-k}$ 与公共成本模型。请求 $d$ 的折外预测 $\Delta\hat\ell^{\rm oof}_{H,d}$ 与 $\widehat{\Delta c}^{\rm oof}_d$ 由 $k=\operatorname{fold}(d)$ 的外层模型给出。
3. 外层 Q：对每个 $k$，在 $\mathcal D_{-k}$ 上训练 Q$_{-k}$ 的残差项 Q$^{\rm res}_{-k}$。$\mathcal D_{-k}$ 中第 $j$ 折请求的残差基取 H$_{-jk}$ 的预测，标准化统计量与早停验证集都取自 $\mathcal D_{-k}$。第 $k$ 折请求的折外预测为 $\Delta\hat\ell^{\rm oof}_{Q,d}=\mathrm H_{-k}(d)+\mathrm Q^{\rm res}_{-k}(d)$，与部署时“最终 H 加残差项”的形式相同。
4. 最终 H、Q 与成本模型：H 与成本模型在全部拟合请求上训练；Q 的残差项在全部拟合请求上训练，残差基取第 2 步的 $\Delta\hat\ell^{\rm oof}_{H,d}$，部署时以最终 H 为基。
5. 门控：用第 2、3 步的折外预测按第 7.4 节构造价格集合 $\Lambda_{\rm fit}$ 与标签 $\Delta^{\rm Q}_d(\lambda)$，在全部拟合请求上训练一次。门控的预测只用于校准集与确认集。
6. R、Z、N 与四个停止控制器不以其他控制器的预测为输入或标签：按外层 5 折给出拟合集上的折外预测作诊断，部署模型在全部拟合请求上训练。

第 $k$ 折上的折外预测满足上述要求。H$_{-jk}$（$j\ne k$）只用 $\mathcal D_{-jk}\subset\mathcal D_{-k}$，H$_{-k}$ 与外层成本模型只用 $\mathcal D_{-k}$，Q$^{\rm res}_{-k}$ 的目标与残差基都来自 $\mathcal D_{-k}$。所以给定第 $k$ 折请求的特征，$a_{H,d}$、$a_{Q,d}$ 与门控的输入都与该折的标签 $\Delta\ell_d$、$\Delta c_d$ 无关，$\Delta^{\rm Q}_d(\lambda)$ 与 $\delta_d(\lambda)$ 的关系同新请求上一样，差别只在外层模型少用五分之一的拟合请求。直接复用全局折外 H 表会破坏这一要求：$\mathcal D_{-k}$ 中第 $j$ 折请求的残差基若取 H$_{-j}$ 的预测，而 H$_{-j}$ 在包含第 $k$ 折的 $\mathcal D_{-j}$ 上训练，Q$_{-k}$ 的参数就经由残差基依赖第 $k$ 折的标签。残差基若取 H$_{-k}$ 在自身训练请求上的预测，残差目标来自样本内拟合，比部署时 H 的样本外误差小，训练与部署不一致。

拟合次数为 H 16 次（内层 10、外层 5、最终 1），Q、成本模型、R、Z、N 与四个停止控制器各 6 次，门控 1 次。拟合请求为 20,000 个时，H 每次的训练行不超过 18,000 行，按每参数每行 6 FLOPs、至多 100 个 epoch 计，单次不超过 $18{,}000\times591{,}617\times6\times100\approx6.4\times10^{12}$ FLOPs，第 10 节的时间安排不变。校准集与确认集不参与任何拟合。

### 7.6 停止控制器

停止决策只在第二轮仍在运行时做出，此时之前全部块都取 $r=2$，历史唯一，标签不需要行为策略。决策规则采用分块扩展第 5.1 节的一步前瞻：在边界 $b_c$（$2\le c\le K_d$）处，比较“现在停止”与“再执行一块第二轮后停止”。现在停止使 NLL 增加

$$
y_{d,c}=\ell^{[c]}_d-\ell^{[c+1]}_d,
$$

同时节省第 $c$ 块上的第二轮费用

$$
c^{[c+1]}_d-c^{[c]}_d=\frac{U_{d,c}}{n_d},
$$

$U_{d,c}$ 为第 $c$ 块各位置上第二轮与混合的账本成本之和。$y_{d,c}$ 包含停止对之后各块的影响：停止改变生成尾的历史，后续块的预测随之改变。

边界处第 $c$ 块的长度 $n_{d,c}$ 与回答总长 $n_d$ 都未知，块起点 $b_c=P_d+m_{d,c}$ 已知（第 4.2 节）。由第 7.1 节的 $k(j)=k_0+k_1j$ 逐位置求和：

$$
\begin{aligned}
U_{d,c}
&=\sum_{j=b_c}^{b_c+n_{d,c}-1}(k_0+k_1j)
=k_0n_{d,c}+k_1\Big[n_{d,c}\,b_c+\frac{n_{d,c}(n_{d,c}-1)}2\Big]\\
&=k\Big(b_c-\frac12\Big)\,n_{d,c}+\frac{k_1}2\,n_{d,c}^2 .
\end{aligned}
$$

$k(b_c-\frac12)$ 在边界处已知，所以

$$
\mathbb E\Big[\frac{U_{d,c}}{n_d}\,\Big|\,z_{d,c}\Big]
=k\Big(b_c-\frac12\Big)\,\mathbb E\Big[\frac{n_{d,c}}{n_d}\,\Big|\,z_{d,c}\Big]
+\frac{k_1}2\,\mathbb E\Big[\frac{n_{d,c}^2}{n_d}\,\Big|\,z_{d,c}\Big].
$$

两个条件矩都要估计：$(n_{d,c},n_d)=(10,100)$ 与 $(20,200)$ 的 $n_{d,c}/n_d$ 都是 0.1，$n_{d,c}^2/n_d$ 分别为 1 与 2。$P_d=100$、$m_{d,c}=40$、$n_{d,c}=40$、$n_d=150$ 时，$k(b_c-\frac12)=1{,}425{,}315{,}840$，$U_{d,c}/n_d=380{,}084{,}224+1{,}048{,}576=381{,}132{,}800$，第二项占 0.28%。公共成本模型为此增加第三个岭回归，构造与第 7.1 节相同：$\tilde z_{d,c}$ 是 $z_{d,c}$ 按拟合折统计量标准化后加截距的 7 维向量，特征为 $[k(b_c-\frac12)\tilde z_{d,c};\tilde z_{d,c}]$，共 14 个参数，目标为 $U_{d,c}/n_d$，预测为

$$
\widehat{\Big(\frac{U_{d,c}}{n_d}\Big)}=\max\Big\{0,\ \hat\zeta_U^\top\big[k(b_c-\tfrac12)\,\tilde z_{d,c};\ \tilde z_{d,c}\big]\Big\}.
$$

两个条件矩都是 $\tilde z_{d,c}$ 的线性函数时，模型正确设定；目标恒为正，截断不增大平方误差。每个内部边界一行，样本权重见本节下文；标准化、正则与选择规则同第 7.1 节。全部停止控制器共用这一估计，评价一律使用实际账本。

四个停止控制器以 $y_{d,c}$ 为目标，与请求级的 R、Z、H、N 一一对应。Z$_{\rm stop}$、H$_{\rm stop}$、N$_{\rm stop}$ 由同一份训练代码按输入列生成，R$_{\rm stop}$ 与 R 一样只作描述性线性基线：

1. R$_{\rm stop}$：在 6 维边界状态 $z_{d,c}$ 上做岭回归。$z_{d,c}$ 由 $\log(1+P_d)$、两维来源独热编码、块序号 $c$、$\log(1+m_{d,c})$ 与 $\log(1+\text{上一块长度})$ 组成，上一块长度为 $b_c-b_{c-1}$，$m_{d,c}=b_c-P_d$ 是时刻 $b_c$ 已经输入的回答 token 数，即第 $c$ 块之前的回答 token 数（第 4.2 节的约定）。六维在时刻 $b_c$ 都已知。
2. Z$_{\rm stop}$：与 H$_{\rm stop}$ 相同，输入只有 $z_{d,c}$，结构为 $6\to256\to256\to1$，参数为 $(6\times256+256)+(256\times256+256)+(256+1)=1{,}792+65{,}792+257=67{,}841$ 个。来源独热编码在本计划的数据上为常数，Z$_{\rm stop}$ 实际读取 $\log(1+P_d)$、块序号 $c$、$\log(1+m_{d,c})$ 与 $\log(1+\text{上一块长度})$ 四个变量。
3. H$_{\rm stop}$：结构为 $2054\to256\to256\to1$ 的多层感知机，输入为边界位置的首轮出口 $h^1_{d,b_c}$ 与 $z_{d,c}$，参数 592,129 个。$S$ 与 $F^1$ 的计算与动作无关，位置 $b_c$ 的输入 $x_{b_c}$ 是第 $c-1$ 块的最后一个 token，首轮出口 $h^1_{d,b_c}$ 在决策前已经算出；决策决定 $F^2$ 是否在位置 $b_c$ 执行，影响 $x_{b_c+1}$ 及之后的预测。
4. N$_{\rm stop}$：与 H$_{\rm stop}$ 相同，只是把 $h^1_{d,b_c}$ 换成按请求标识与块序号播种的 2048 维标准正态噪声，参数 592,129 个。它的对照对象是 Z$_{\rm stop}$，两者只差 2048 维噪声输入。各边界的噪声彼此独立，也与该请求的停止点标签独立，H＋N$_{\rm stop}$ 的期望 NLL 与期望成本等于“提示词末位用 H、每个边界以只依赖 $z_{d,c}$ 的概率停止”的随机规则，第 7.2 节的结论与解读同样适用。

样本权重：每个边界样本的权重相同，取 1，停止控制器与第三个成本回归都如此。在价格 $\lambda$ 下，文档 $d$ 在边界 $c$ 处现在停止与再执行一块后停止，使目标 $\frac1D\sum_d\big[\ell_d+\lambda c_d\big]$ 相差 $\frac1D\big(y_{d,c}-\lambda U_{d,c}/n_d\big)$。每个边界决策都以同一系数 $1/D$ 进入目标，$y_{d,c}$ 与 $U_{d,c}/n_d$ 已按答案 token 归一，所以权重与文档的边界数无关。

记 $\mathcal F_{d,c}$ 为时刻 $b_c$ 决策前已知的信息（第 4.2 节的时刻约定）：提示词、位置 $b_c$ 及之前的 token，以及由它们确定的各轮表示与边界状态。一步前瞻需要 $\mathbb E[y_{d,c}\mid\mathcal F_{d,c}]$。以权重 $\omega$ 做加权均方误差回归时，对固定的 $\mathcal F_{d,c}$ 令一阶条件为零：

$$
\frac{\partial}{\partial\hat y}\,\mathbb E\big[\omega\,(y_{d,c}-\hat y)^2\mid\mathcal F_{d,c}\big]
=2\,\mathbb E\big[\omega\,(\hat y-y_{d,c})\mid\mathcal F_{d,c}\big]=0
\quad\Longrightarrow\quad
\hat y^\ast=\frac{\mathbb E[\omega\,y_{d,c}\mid\mathcal F_{d,c}]}{\mathbb E[\omega\mid\mathcal F_{d,c}]}.
$$

$\omega$ 由 $\mathcal F_{d,c}$ 决定时可以提到条件期望之外，$\hat y^\ast=\mathbb E[y_{d,c}\mid\mathcal F_{d,c}]$。按文档平分的权重 $\omega=1/(K_d-1)$ 依赖边界处未知的总块数，$\hat y^\ast$ 偏向块数少的回答。例：同一 $\mathcal F_{d,c}$、$c=2$，此后以相同概率出现 $(K_d,y_{d,c})=(2,0.01)$ 或 $(3,-0.015)$。真实条件均值为 $-0.0025$，而

$$
\hat y^\ast=\frac{\frac12\times1\times0.01+\frac12\times\frac12\times(-0.015)}{\frac12\times1+\frac12\times\frac12}
=\frac{0.00125}{0.75}=\frac1{600}>0,
$$

$\lambda=0$ 时前者要求停止，后者要求继续。

交叉验证折与早停的验证集仍按文档划分；岭系数网格、网络训练设置、交叉拟合与早停规则同第 7.2、7.5 节，多层感知机每批 256 行边界样本。

部署时，提示词末位仍由请求级控制器决定是否启用第二轮；启用后，在第一个满足

$$
\hat y_{d,c}<\lambda\,\widehat{\Big(\frac{U_{d,c}}{n_d}\Big)}
$$

的边界停止，没有边界满足时第二轮执行到回答结束。$\lambda$ 与提示词末位的决策共用，族的价格网格与两个强制端点一起描出整条成本曲线（第 8.2 节）。第一级不在块边界调用 Q。

一步前瞻的在线最优性由分块扩展的命题 2 给出充分条件。记 $J^{[s]}_d=\ell^{[s]}_d+\lambda c^{[s]}_d$，以及

$$
\Delta J_{d,c}=J^{[c]}_d-J^{[c+1]}_d=y_{d,c}-\lambda\,\frac{U_{d,c}}{n_d},
$$

即现在停止相对“再执行一块第二轮后停止”的代价差，取负值时现在停止更优。$\mathcal F_{d,c}$（定义见上文样本权重一段）随 $c$ 递增，构成 σ 代数流（filtration）。理想的一步前瞻停在第一个满足 $\mathbb E[\Delta J_{d,c}\mid\mathcal F_{d,c}]<0$ 的边界，即 $\mathbb E[y_{d,c}\mid\mathcal F_{d,c}]<\lambda\,\mathbb E[U_{d,c}/n_d\mid\mathcal F_{d,c}]$；部署规则分别用 $\hat y_{d,c}$ 与成本预测代替这两个条件期望。分块扩展的命题 2 要求停止区域吸收：某个边界按当时的信息判定现在停止更优之后，不论下一块生成什么内容，此后每个边界按更新后的信息也判定现在停止更优。

条件期望针对请求与参考答案的总体分布。校准集中各篇文档的提示词几乎都互不相同，按经验分布对 $\mathcal F_{d,c}$ 取条件期望只会退回该文档自身的标签，所以吸收条件不能在校准集上直接计算，下面的诊断都不能验证一步前瞻的在线最优性。一步前瞻作为可检验的策略部署，其价值由 P4 衡量。

对 H＋H$_{\rm stop}$ 价格网格中的每个 $\lambda$，在 $K_d\ge3$ 的校准请求上报告三项诊断，主预算处夹逼所用的价格点单列（强制端点没有价格，不在此列）。$K_d\le2$ 时至多一个内部边界，三项都恒成立，只报告这类请求所占的比例。

1. 事后一步前瞻最优率：用真实的 $\Delta J_{d,c}$ 执行一步前瞻，停止点 $\hat s_d$ 取第一个 $\Delta J_{d,c}<0$ 的边界，没有这样的边界时 $\hat s_d=K_d+1$；统计 $J^{[\hat s_d]}_d=\min_{2\le s\le K_d+1}J^{[s]}_d$ 的请求比例，按代价比较，并列的停止点视为一致。同时报告事后一步前瞻差距 $J^{[\hat s_d]}_d-\min_{2\le s\le K_d+1}J^{[s]}_d$ 的文档等权平均。
2. 逐路径符号单调率：序列 $\Delta J_{d,2},\ldots,\Delta J_{d,K_d}$ 一旦出现负值、之后各项都为负的请求比例。
3. 预测停止区域的逐路径吸收率：把 $\Delta J_{d,c}$ 换成部署规则使用的 $\hat y_{d,c}-\lambda\widehat{(U_{d,c}/n_d)}$，统计同样“一旦为负、之后都为负”的请求比例。教师强制下各边界的 $h^1_{d,b_c}$ 与 $z_{d,c}$ 都与动作无关，全部内部边界的预测都可以算出。

前两项按真实标签计算，对应每个请求的全部 $J^{[s]}_d$ 在决策时已知的完全信息问题。逐路径符号单调的请求上，$J^{[s]}_d$ 在 $s\le\hat s_d$ 上不增、在 $s\ge\hat s_d$ 上严格增，一步前瞻取到最小值，所以第二项不超过第一项。两者之差来自 $(J^{[2]}_d,J^{[3]}_d,J^{[4]}_d)=(1,3,2)$ 这类序列：一步前瞻在第一个边界就取到最小值，序列在下一个边界却离开停止区域。实际标签等于条件期望加上边界处无法预测、条件均值为零的波动，单个参考答案的逐 token 噪声属于这种波动，它改变前两项，不改变条件停止区域。分块扩展第 5.1 节给出两个例子：一个分布上两项都是 100%，一步前瞻严格次优；另一个分布上两项都是 50%，一步前瞻在线最优。前两项描述的是标签序列的形状；第一项低时，即使边界处准确知道再执行一块的净代价，一步前瞻也会停在局部最小值。

第三项针对部署规则实际使用的停止区域。它低于 1 时，部分请求在部署规则停止之后的某个边界，预测又判定继续更优，按预测本身一步前瞻的短视在起作用。它等于 1 也不能推出真实的条件停止区域吸收，因为预测含估计误差，每个请求也只提供后续信息的一个实现。

对偶下界给出部署规则可被改善的上限：任何期望成本不超过 $B$ 的单向停止规则（包括在线最优规则）在同一批文档上的同成本 NLL 都不低于 $\mathrm{LB}_{\rm stop}(B)$，所以第 6.5 节的 $e_S(B)=L_{\rm H+H_{stop}}(B)-\mathrm{LB}_{\rm stop}(B)$ 是任何规则在主预算处相对 H＋H$_{\rm stop}$ 的改善上限（第 8.5 节第 8 项）。它不区分信息不足、一步前瞻的短视与预测误差三种来源。

### 8.2 预算、价格网格与强制端点

预算以“全部 $r=1$、不运行控制器”的文档平均每 token 完整账本为单位。每次自助重采样都以该重采样中全部 $r=1$ 的文档平均成本为单位（与 v3.3 的 `analyze.py` 相同），所以每次重采样中都有 $C(1)=1$。

非负价格不保证策略族达到全部 $r=2$ 的成本。请求级族在 $\Delta\hat\ell_d+\lambda\widehat{\Delta c}_d<0$ 时取 $r=2$；预测成本差为正时，预测 $\Delta\hat\ell_d\ge0$ 的请求在所有 $\lambda\ge0$ 下都取 $r=1$。GL1 只约束平均效应，与部分请求的预测为正相容。停止族在 $\lambda=0$ 时仍在 $\hat y_{d,c}<0$ 的边界停止。族的最高成本低于预算时，族内没有夹住预算的两点，比较不可估。

每个策略族因此由下列确定性策略及其文档级随机混合构成：

1. 两个强制端点：强制全程 $r=1$（每个请求 $s=1$）与强制全程 $r=2$（每个请求 $s=K_d+1$）。强制端点不运行任何控制器（请求级读出、Q、门控与停止控制器），不计控制器成本，所以在所有族中都是同两个点 $(C(1),L(1))$ 与 $(C(2),L(2))$。U-mix 只由这两个端点构成。
2. 64 个价格点：$\lambda=0$，以及 $[10^{-3}\lambda_{\max},\lambda_{\max}]$ 上对数等距的 63 个价格。$\lambda_{\max}$ 在校准集上确定，在它及更高的价格上该族全部请求取 $r=1$：请求级族取 $\max_d\hat\rho_d$，$\hat\rho_d=-\Delta\hat\ell_d/\widehat{\Delta c}_d$；HQ 取 H 与 Q 两组 $\hat\rho_d$ 的最大值；停止族在提示词末位用 H，取 H 的 $\max_d\hat\rho_d$。$\lambda_{\max}\le0$ 时，族在所有非负价格下都取全部 $r=1$，价格点只取 $\lambda=0$。价格点上运行该族的控制器，并计入控制器成本。

族的成本曲线是这些确定性策略（一般为 66 个）按实际成本排序后相邻两点的连线。预算 $B$ 处取夹住 $B$ 的第一对相邻点 $a$、$b$（$\overline C_a\le B\le\overline C_b$ 且 $\overline C_a<\overline C_b$），按数学验证第 12.2 节作文档级随机混合：每篇文档独立地以概率 $w_{ab}=(B-\overline C_a)/(\overline C_b-\overline C_a)$ 执行成本较高的 $b$，否则执行 $a$，期望成本恰为 $B$；U-mix 的 $w_{ab}$ 就是第 6.2 节的 $w(B)$。分到强制端点的文档不运行控制器，分到价格点的文档运行控制器并计费。部署与自由生成（第 8.5 节）使用校准集上锁定的夹逼对与混合权重。

共同可达预算的检查如下。每个确定性策略在每篇文档上的成本都不低于 $c_d(1)$，所以强制全程 $r=1$ 是成本最低的点，成本为 1；强制全程 $r=2$ 的成本为 $C(2)$。$1<B\le C(2)$ 时，按成本排序的点列中第一个成本不低于 $B$ 的点与它前一个点夹住 $B$，每个族都可估。重采样中文档 $d$ 被抽中 $m_d$ 次时，

$$
C(2)=\frac{\sum_dm_dc_d(2)}{\sum_dm_dc_d(1)}\ \ge\ \min_d\frac{c_d(2)}{c_d(1)},
$$

所以 $B\le\min_dc_d(2)/c_d(1)$ 保证任何重采样中任何族都不会夹逼失败。这一比值只依赖账本、$P_d$ 与 $n_d$，在读取确认集 NLL 之前计算。

下面按第 7.1 节账本的主要项（记号见第 4.5 节）求这一比值的下界。位置 $i$ 上第二轮与混合的费用和单轮费用分别为

$$
\begin{aligned}
k(i)&=12\big(c_{\rm proj}+c_{\rm att}(i)+c_{\rm LoRA}\big)+6{,}144,\\
c^{(1)}(i)&=48\big(c_{\rm proj}+c_{\rm att}(i)\big)+16c_{\rm LoRA}+c_{\rm voc}\mathbf 1[i\ge P_d],
\end{aligned}
$$

词表头只在预测位置上。按位置是否有词表头分两种情形：

1. 无词表头的位置。$12c_{\rm LoRA}+6{,}144=32{,}643{,}072>16c_{\rm LoRA}/4=10{,}878{,}976$，所以 $k(i)/c^{(1)}(i)>12/48=0.25$。
2. 有词表头的位置。记 $y=c_{\rm proj}+c_{\rm att}(i)$，则

   $$
   \frac{k(i)}{c^{(1)}(i)}=\frac{12y+12c_{\rm LoRA}+6{,}144}{48y+16c_{\rm LoRA}+c_{\rm voc}}.
   $$

   这一比值对 $y$ 的导数分子为

   $$
   12\big(16c_{\rm LoRA}+c_{\rm voc}\big)-48\big(12c_{\rm LoRA}+6{,}144\big)=6{,}423{,}281{,}664>0,
   $$

   所以比值随位置增大。$c_{\rm att}(i)=16{,}384\,i>0$，以 $c_{\rm att}=0$（即 $y=c_{\rm proj}$）代入得严格下界 $1{,}397{,}889{,}024/6{,}126{,}829{,}568\approx0.228159>0.2281$。

文档成本是各位置成本之和，所以每篇文档有 $c_d(2)/c_d(1)>1.2281$。账本省略的归一化、softmax 与 RoPE 等项不到每个位置主要项的 1%，计入后下界仍高于 $1+0.2281/1.01\approx1.22584>1.2258$。三个候选预算都低于这一下界，夹逼失败在构造上不会发生。

门控的训练价格集合 $\Lambda_{\rm fit}$（第 7.4 节）只用于训练门控，与此处的族价格网格无关；门控以 $\lambda$ 为输入，族价格网格的任何取值都不需要重新训练门控。

教师强制评价是查表（命题 2），密集网格不增加 GPU 开销，并减小严格同成本插值的端点间距。

### 8.3 主检验与判定

在主预算 $B$ 处，主检验以严格同成本计算，正值表示后者 NLL 更低。四项比较沿 U-mix、Z、H、HQ 的顺序与从 H 到 H＋H$_{\rm stop}$ 的分支排列，每项两端只差一个因素：P1 差是否按 $z$ 分配，P2 差是否读 $h^1_{d,P}$，P3 差是否查询 Q，P4 差是否在块边界停止。P2、P3、P4 以同一个 H 为一端，P3、P4 与 Z 无关。P4 的两端在提示词末位使用同一个 H 与同一条选择规则，但停止改变了成本曲线，两族在预算 $B$ 处的夹逼对一般落在不同的价格上，提示词末位启用第二轮的请求随之不同：第 6.5 节的例子中，H 只对文档 2 启用第二轮，H＋H$_{\rm stop}$ 对文档 2 总是启用，对文档 1 以概率 0.9 启用。P4 因此包含停止省下的成本在提示词末位的重新分配（第 6.5 节）。

1. P1：$g_{{\rm mix},Z}=L_{\rm mix}(B)-L_Z(B)$，已知状态的分配价值。
2. P2：$g_{ZH}=L_Z(B)-L_H(B)$，首轮表示的预测价值。H 与 Z 的结构和训练相同，只差输入是否含 $h^1_{d,P}$。
3. P3：$g_{H,HQ}=L_H(B)-L_{HQ}(B)$，只读查询的增益，计入查询成本。
4. P4：$g_{H,{\rm stop}}=L_H(B)-L_{\rm H+H_{stop}}(B)$，块边界停止的增益。两者在提示词末位用同一个 H，只差停止控制器。

确认族在读取确认集前锁定。第 6.4 节判为确认性检验时，确认族为 P1–P4，族大小 $m=4$（第 6.5 节）。第 6.4 节判为只报告估计时没有确认族，P1–P4 都按下文的族外口径报告。

确认族与全部锁定的策略只依赖拟合与校准文档。确认文档按哈希分桶，与这两类文档不相交；在文档独立抽样的模型下，给定这些锁定结果，确认集上的 p 值保持有效。下文的族错误率（family-wise error rate）因此不超过 0.05。

文档自助法重采样 $N_{\rm b}=10{,}000$ 次，种子 20261016，每次重采样重算成本、夹逼端点与插值权重。记比较 $j$ 的真实同成本差为 $g_j$，确认集上的估计为 $\hat g_j$，第 $b$ 次重采样的值为 $\hat g^{*b}_j$。单侧 p 值沿用一天方案的定义：

$$
p_j=\frac{\#\{b:\hat g^{*b}_j\le0\}}{N_{\rm b}} .
$$

对 $0<a\le0.05$，令 $\kappa(a)=\lceil aN_{\rm b}\rceil$。下分位 $q^-_j(a)$ 取 $N_{\rm b}$ 个复本中从小到大第 $\kappa(a)$ 个值，上分位 $q^+_j(a)$ 取从大到小第 $\kappa(a)$ 个值；分位按位次取值，不做插值。

**关系 0。** $q^-_j(a)>0\iff p_j<a$；$q^+_j(a)<0\Rightarrow p_j>1-a$。

**证明。** 记 $c_j=\#\{b:\hat g^{*b}_j\le0\}$。$q^-_j(a)>0$ 当且仅当不超过 0 的复本少于 $\kappa(a)$ 个，即 $c_j\le \kappa(a)-1$。由 $\kappa(a)-1<aN_{\rm b}\le \kappa(a)$ 与 $c_j$ 为整数，$c_j\le \kappa(a)-1\iff c_j<aN_{\rm b}\iff p_j<a$。同理，$q^+_j(a)<0$ 当且仅当不小于 0 的复本少于 $\kappa(a)$ 个，此时 $\#\{b:\hat g^{*b}_j\ge0\}\le \kappa(a)-1<aN_{\rm b}$，所以 $p_j\ge\#\{b:\hat g^{*b}_j<0\}/N_{\rm b}>1-a$。证毕。

线性插值分位在位次边界上破坏关系 0。取族外水平 $a=0.05$，$\kappa(0.05)=500$；若恰有 500 个复本不超过 0，则 $p_j=0.05$，族外检出要求 $p_j<0.05$，而 v3.3 `analyze.py` 所用的线性插值分位落在第 500、501 个值之间，第 501 个值为正时它可以为正。

检出由 Holm 调整 p 值决定。把确认族的 p 值从小到大排为 $p_{(1)}\le\cdots\le p_{(m)}$，令

$$
\tilde p_{(k)}=\min\Big\{1,\ \max_{1\le i\le k}(m-i+1)\,p_{(i)}\Big\},
$$

比较 $j$ 判为检出当且仅当 $\tilde p_j\le0.05$。Holm 逐步法拒绝第 $k$ 名，当且仅当 $p_{(i)}\le0.05/(m-i+1)$ 对全部 $i\le k$ 成立，即 $\max_{i\le k}(m-i+1)p_{(i)}\le0.05$，与 $\tilde p_{(k)}\le0.05$ 等价。p 值相等的比较得到相同的调整值，名次如何排定不影响结论。夹逼失败的比较不可估，在确认族中按 $p_j=1$ 计入，$m$ 保持不变。

判定表另用两个 Bonferroni 同时界：

$$
\ell^{\rm B}_j=q^-_j(0.05/m),\qquad u^{\rm B}_j=q^+_j(0.05/m).
$$

$m=4$，取第 125 位。它们与 Holm 检出满足三条关系：

1. $\ell^{\rm B}_j>0\Rightarrow\tilde p_j\le0.05$。由关系 0，$p_j<0.05/m$。设比较 $j$ 排在第 $k$ 名，对 $i\le k$ 有 $p_{(i)}\le p_j$，所以 $(m-i+1)p_{(i)}\le m\,p_j<0.05$，从而 $\tilde p_j<0.05$。
2. $u^{\rm B}_j<0\Rightarrow\tilde p_j>0.05$。由关系 0，$p_j>1-0.0125$；又 $\tilde p_{(k)}\ge(m-k+1)p_{(k)}\ge p_{(k)}$，所以 $\tilde p_j>0.9875$。
3. $\ell^{\rm B}_j\le u^{\rm B}_j$。第 $\kappa$ 小的值不超过第 $\kappa$ 大的值，只要 $2\kappa\le N_{\rm b}+1$；本节用到的位次 $\kappa\le500$ 都满足。

在自助分布的近似下，判定表的三类陈述各自在确认族内以不低于 0.95 的概率同时成立：

- 检出陈述。设 $g_j\le0$ 的比较有 $m_0\ge1$ 个，其中 p 值最小的是 $j^\ast$（并列时任取其一）。Holm 按 p 值从小到大拒绝，若错误检出任何比较，第一个被错误检出的就是 $j^\ast$；此前被拒绝的都是 $g>0$ 的比较，至多 $m-m_0$ 个，所以这一步的水平不超过 $0.05/m_0$。错误检出因此蕴含 $p_{j^\ast}\le0.05/m_0$，其概率不超过 $\sum_{j:g_j\le0}\Pr(p_j\le0.05/m_0)\le m_0\cdot0.05/m_0=0.05$。
- 下界陈述。由 Bonferroni 不等式，$\Pr(\exists j:g_j<\ell^{\rm B}_j)\le\sum_j\Pr(g_j<\ell^{\rm B}_j)\approx m\cdot0.05/m=0.05$。
- 上界陈述。同理，$\Pr(\exists j:g_j>u^{\rm B}_j)\le0.05$。

“有增益”来自检出陈述，“达到门槛”来自下界陈述（$g_j\ge\ell^{\rm B}_j\ge\delta_{\min}$），“低于门槛”与“后者 NLL 更高”来自上界陈述（$g_j\le u^{\rm B}_j<\delta_{\min}$ 或 $g_j\le u^{\rm B}_j<0$）。实用门槛 $\delta_{\min}=0.005$ nat/token，确认族内的判定表为：

| 检出 | 同时界 | 结论 |
|---|---|---|
| $\tilde p_j\le0.05$ | $\ell^{\rm B}_j\ge\delta_{\min}$ | 有增益，达到门槛 |
| $\tilde p_j\le0.05$ | $\ell^{\rm B}_j<\delta_{\min}\le u^{\rm B}_j$ | 有增益，是否达到门槛未确定 |
| $\tilde p_j\le0.05$ | $u^{\rm B}_j<\delta_{\min}$ | 有增益，低于门槛 |
| $\tilde p_j>0.05$ | $u^{\rm B}_j<0$ | 后者 NLL 更高 |
| $\tilde p_j>0.05$ | $0\le u^{\rm B}_j<\delta_{\min}$ | 未检出，增益低于门槛 |
| $\tilde p_j>0.05$ | $u^{\rm B}_j\ge\delta_{\min}$ | 未检出，门槛未确定 |

六档互斥且覆盖全部结果：

1. 由关系 1，$\ell^{\rm B}_j\ge\delta_{\min}$ 本身蕴含检出；未检出的比较都有 $\ell^{\rm B}_j\le0$。
2. 由关系 3，检出的三档按 $\delta_{\min}$ 相对 $[\ell^{\rm B}_j,u^{\rm B}_j]$ 的位置划分，互斥且穷尽。
3. 由关系 2，检出的比较都有 $u^{\rm B}_j\ge0$；未检出的三档按 $u^{\rm B}_j$ 相对 0 与 $\delta_{\min}$ 的位置划分。

Holm 检出的比较可以有 $\ell^{\rm B}_j\le0$（在第 2 步及以后检出，或 $p_j$ 恰等于 $0.05/m$），这时“有增益”只由 Holm 给出，报告写出 $\ell^{\rm B}_j$ 的实际值。

同时界取 Bonferroni 水平，依据有两条：

1. 按 Holm 名次取分位的下界（第 $k$ 名用 $0.05/(m-k+1)$ 分位，Holm 停止后其余各项沿用停止那一步的水平）与 Holm 拒绝一致，但没有同时覆盖。正态近似下，四个估计相互独立、真实效应都远大于零且彼此分开时，四项都被拒绝且名次固定，四个下界同时成立的概率为 $(1-0.0125)(1-0.05/3)(1-0.025)(1-0.05)=0.8994$，同时不覆盖的概率为 0.1006；同一情形下 Bonferroni 下界的同时不覆盖概率为 $1-(1-0.0125)^4=0.0491$。
2. 以 Bonferroni 局部检验按划分原理构造、与 Holm 拒绝相容的同时下界，在并非全部比较被拒绝时对被拒绝的比较只给出 0，在全部被拒绝时等于 $\max(0,\ell^{\rm B}_j)$。它判出 $\ge\delta_{\min}$ 的情形全部包含在 $\ell^{\rm B}_j\ge\delta_{\min}$ 之中。

族外的比较使用同一张表的边际版本，包括第 8.5 节各项，以及第 6.4 节判为只报告估计时的 P1–P4。检出改为 $p_j<0.05$，$\ell^{\rm B}_j$ 换成单侧 95% 下界 $q^-_j(0.05)$（第 500 小），$u^{\rm B}_j$ 换成双侧 95% 区间上端 $q^+_j(0.025)$（第 250 大）。由关系 0，$q^-_j(0.05)>0\iff p_j<0.05$，$q^+_j(0.025)<0\Rightarrow p_j>0.975$；第 500 小的值不超过第 250 大的值（第 9,751 小的值），六档同样互斥且穷尽。这些结论是边际结论，报告中如此标注。

每个比较报告 $\hat g_j$、$p_j$、边际双侧 95% 区间 $[q^-_j(0.025),q^+_j(0.025)]$ 与相对改善 $\hat g_j/L_{\rm mix}(B)$；确认族内的比较另报告 $\tilde p_j$、$\ell^{\rm B}_j$ 与 $u^{\rm B}_j$。任一次重采样夹逼失败时，该比较不可估，不下结论。

### 8.4 样本量

按数学验证第 15 节的公式，取 $\sigma=0.067$、$\delta=0.005$、功效 0.8，检验水平取 Bonferroni 水平 $0.05/m$。由第 8.3 节关系 1 的证明，$p_j<0.05/m$ 时 Holm 必定检出比较 $j$，与其余比较的结果无关，所以按这一水平算出的功效是 Holm 检出该比较的功效下界。$m=4$ 时水平为 0.0125，$z_{0.9875}=2.2414$，$z_{0.8}=0.8416$：

$$
n\ge\left(\frac{(2.2414+0.8416)\times0.067}{0.005}\right)^2=(3.0830\times13.4)^2=1706.7,
$$

确认集至少 1,707 篇。默认确认集约 2,989 篇，满足这一要求，全部可以查表评价。

上述 0.8 是真实效应为 0.005 时判定表落入“有增益”三档之一的概率下界。判为“达到门槛”需要 $\ell^{\rm B}_j\ge\delta_{\min}$，概率另算。记 $\mathrm{se}=\sigma/\sqrt n$。正态近似下 $\hat g_j\sim\mathcal N(g_j,\mathrm{se}^2)$，$\ell^{\rm B}_j=\hat g_j-z_{1-0.05/m}\,\mathrm{se}$，所以

$$
\Pr\big(\ell^{\rm B}_j\ge\delta_{\min}\big)
=\Pr\Big(\frac{\hat g_j-g_j}{\mathrm{se}}\ge\frac{\delta_{\min}-g_j}{\mathrm{se}}+z_{1-0.05/m}\Big)
=\Phi\Big(\frac{g_j-\delta_{\min}}{\mathrm{se}}-z_{1-0.05/m}\Big).
$$

真实效应恰为 $\delta_{\min}$ 时，这一概率为 $\Phi(-z_{1-0.05/m})=0.05/m$，$m=4$ 时为 0.0125。令它等于 0.8，即 $(g_j-\delta_{\min})/\mathrm{se}-z_{1-0.05/m}=z_{0.8}$，得

$$
g_j=\delta_{\min}+\big(z_{1-0.05/m}+z_{0.8}\big)\,\mathrm{se}.
$$

$n=1{,}707$ 时 $\mathrm{se}=0.067/\sqrt{1707}=0.0016217$，$g_j=0.005+3.0830\times0.0016217=0.0100$，为门槛的两倍。默认的 $n=2{,}989$ 时 $\mathrm{se}=0.067/\sqrt{2989}=0.0012255$，$g_j=0.005+3.0830\times0.0012255=0.0088$。按规划值 $\sigma=0.067$，确认集的规模使真实效应为 0.005 时检出增益的概率不低于 0.8；以 0.8 的概率判为“达到门槛”，默认确认集需要真实效应约 0.009。

若真实效应只有 0.002，取 $n=2{,}989$。Holm 各步的水平都在 $[0.05/m,\,0.05]$ 内，所以检出概率不低于按 $0.05/m$ 算出的值，也不高于按 0.05 算出的值：

- $\sigma=0.067$ 时 $0.002\sqrt{2989}/0.067=1.632$。检出概率介于 $\Phi(1.632-2.2414)=\Phi(-0.609)=0.27$ 与 $\Phi(1.632-1.6449)=\Phi(-0.013)=0.49$ 之间。
- $\sigma=0.051$ 时 $0.002\sqrt{2989}/0.051=2.144$。检出概率介于 $\Phi(-0.097)=0.46$ 与 $\Phi(0.499)=0.69$ 之间。

同一效应下，判为“达到门槛”的概率在 $\sigma\in\{0.067,0.051\}$ 两种情形下都小于 $10^{-5}$。

“有增益”的前两档都要求 $u^{\rm B}_j\ge\delta_{\min}$，所以判定表落入“低于门槛”或“未检出”各档的概率不低于

$$
\Pr\big(u^{\rm B}_j<\delta_{\min}\big)=\Phi\Big(\frac{\delta_{\min}-g_j}{\mathrm{se}}-z_{1-0.05/m}\Big).
$$

$\sigma=0.067$ 时 $(0.005-0.002)/0.0012255=2.448$，为 $\Phi(0.207)=0.58$，$\sigma=0.051$ 时为 $\Phi(3.216-2.2414)=\Phi(0.975)=0.84$。读取确认集前，用校准集重估 $\sigma$ 并报告预测功效。

### 8.5 次要分析

以下比较按第 8.3 节的族外口径报告估计与边际区间，结论标为边际结论：

1. $G_{\rm two}$ 取 $r=1$ 对 $G_{\rm one}$：单因素对照，衡量三分之二的请求在全部或部分位置经第二轮训练对单轮质量的影响。
2. Q（总是查询）对 HQ：门控的价值。同一价格下，两族只在门控不查询的请求上不同：Q 在这些请求上按 $a_{Q,d}(\lambda)$ 决策并支付 $C_Q$，HQ 按 $a_{H,d}(\lambda)$ 决策且不付查询费用。第 8.3 节的同成本比较在预算 $B$ 处为两族各取夹逼对，两族的价格一般不同。门控查询哪些请求、被查询请求按 $a_{Q,d}(\lambda)$ 选择的轮数都随价格改变，所以被查询的请求同样贡献 NLL 之差；两族的期望总成本都恰为 $B$。同成本差因此衡量门控的整体作用，包括在不查询的请求上改用 H 的决策、省下的查询费用，以及两者引起的价格与预算重新分配。门控能否识别按 Q 决策会变差的请求，由下面按价格报告的分箱校准检验。同时在校准集上按价格报告查询率，并按 $\hat\Delta^{\rm Q}_d(\lambda)$ 的十分位分箱，比较箱内 $\hat\Delta^{\rm Q}_d(\lambda)$ 与实际 $\Delta^{\rm Q}_d(\lambda)$ 的均值。
3. 阴性对照与 P2 的分解：$g_{ZN}=L_Z(B)-L_N(B)$，$g_{NH}=L_N(B)-L_H(B)$，两者之和恰为 P2 的 $g_{ZH}$。N 与 Z 只差 2048 维噪声输入，$g_{ZN}$ 是这些无信息输入在同一训练流程下的作用；H 与 N 结构相同，$g_{NH}$ 只比较这 2048 维是 $h^1_{d,P}$ 还是噪声。$g_{ZN}$ 的双侧 95% 区间位于零以上时，P2 的结论注明“基线 Z 离只读 $z$ 的最优值较远，或评价流程泄漏了标签信息”（第 7.2 节）。线性基线 R 对 Z 的差 $g_{RZ}=L_R(B)-L_Z(B)$ 衡量同一输入上非线性读出的作用，作描述。

## 10. 资源与 24 小时安排

$G_{\rm two}$ 训练时每卡显存估算如下：

1. 冻结基座 BF16 权重 56.9 GiB（30,532,122,624 个参数）。
2. 生成侧 281,282,560 个参数的 FP32 主副本、梯度与 AdamW 两个矩，16 字节/参数，约 4.2 GiB。
3. 激活：按层边界重算时，$r=2$ 样本每 token 保存 28 个可训练层的输入（其中 $F^1$ 第 32 层的输入即 $u_i$）与 $h_i^1$，共 29 个 2048 维 BF16 向量，即 118,784 字节；一条 4096 token 的序列约 0.45 GiB，每卡每步 4 条约 1.8 GiB，加重算峰值约 3 GiB。
4. 词表 logits 按 1,024 token 分块计算交叉熵，logits 与梯度约 1.2 GiB。

合计约 65 GiB，低于 H200 每卡 143,771 MiB（约 140.4 GiB）的 85%，即 119.3 GiB。数据并行时每卡放一份完整模型即可，以 E10 的实测为准。

| 时段 | 工作 | 完成条件 |
|---|---|---|
| 0–6 小时 | S0 验收、显存与吞吐短跑 | E1–E11、M1–M5、C1–C3 通过 |
| 6–16 小时 | S1：$G_{\rm two}$ 与 $G_{\rm one}$ 各 $2\times10^8$ token | 两个检查点锁定 |
| 16–17 小时 | S2 双动作与停止点标签、S3 门槛与主预算 | GL1、GL2 判定，$\Delta_{\rm stop}(B)$ 记录，主预算锁定 |
| 17–19 小时 | S4 控制器（含停止控制器与对照 Z、N、R）交叉拟合与训练、S5 价格校准与校准集上的 $g_{ZN}$ 核对 | 全部预测器与价格锁定 |

吞吐不足时依次缩减：自由生成从 256 题减为 128 题；取消通用文本的描述性评价；仍不足时报告预计延长时间。两臂各 $2\times10^8$ token 与确认集规模不缩减，后者只需查表。

中止条件如下：

1. E1–E11、M1–M5 或 C1–C3 失败时停下修复，只许重跑一次，第二次失败即中止并报告。
2. GL1 与 GL2 都未通过时，不作控制器比较。
3. 数值异常时保存状态并中止相应阶段，成功完成的检查不能替代未通过的检查。

## 11. 风险

1. 第二轮的平均效应不足。Qwen3-30B-A3B 没有循环预训练，第 32–43 层再执行一次能否降低 NLL 没有测量；GL1 直接检验这一点。
2. 请求间差异难以预测。loopjev 的四个免训练读出回收率为 0。只读已知状态的 Z 是否优于随机分配由 P1 检验，H 是否优于结构与训练相同的 Z 由 P2 检验，HQ 是否优于 H 由 P3 检验。阴性对照 N 与 Z 只差 2048 维噪声输入，样本外评价下 N 的期望 NLL 不低于只读 $z$ 的最优值；N 明显优于 Z 时，Z 离这一最优值较远或评价流程泄漏了标签信息，P2 按第 7.2 节的规则处理。
3. 单个参考答案带来标签噪声，对偶上界偏乐观。跨半选择评价用答案的一半选择、另一半评价。给定后半真实效应、全部前半标签与全部成本时，若后半噪声的条件均值为零，它就是所选分配在后半上真实改善的无偏估计；成本由答案长度决定，可以与后半噪声相关，使这一条件不成立。它评价的是带噪选择得到的那一个分配，只作诊断（第 6.3 节）。
4. 训练时一半位置取 $r=2$，只与 $B=1.125$ 附近的部署比例一致；v3.1 的相关证据只有单种子、无区间。
5. 三分之二的请求在全部或部分位置经第二轮训练，对单轮质量的影响由 $G_{\rm two}(r=1)$ 对 $G_{\rm one}$ 的单因素比较测量。
6. 自由生成中 $r$ 会改变回答长度，实际成本与教师强制成本不同。
7. Qwen 指令模型的训练数据是否包含 GSM8K 无法核实；若包含，绝对 NLL 偏低，同一文档上的配对比较仍然有效。
8. 门控的标签只在 H 与 Q 选择不同的请求上非零。两者分歧少时 $\hat\Delta^{\rm Q}_d(\lambda)$ 的估计噪声大，门控在分歧请求上采用 Q 还是 H 的决策接近随机。按 FLOPs 计费时查询成本只占整次请求的约 $5.9\times10^{-6}$，门控的作用集中在这一选择上，它的价值由第 8.5 节第 2 项测量。
9. GSM8K 的回答平均只有 3.58 行，单向停止相对请求级的事后额外空间受块数限制，大小由 GL3 的 $\Delta_{\rm stop}(B)$ 直接测量。P4 另含 $e_H-e_S$ 一项：停止控制器纠正提示词末位误判时它增大，停止控制器在不当的块边界停止或继续时它减小并可以为负。这一项不受 $\Delta_{\rm stop}$ 约束（第 6.5 节）。
10. 一步前瞻只在条件停止区域吸收时保证在线最优（分块扩展命题 2）。某一块第二轮的期望收益很小、后面的块期望收益又变大时，停止区域不吸收，一步前瞻会过早停止。吸收条件由总体分布上的条件期望定义，第 7.6 节的三项诊断都不能验证它；部署规则的价值由 P4 衡量，第 6.5 节的 $e_S(B)$ 给出任何单向停止规则在主预算处所能再改善的上限。需要更接近在线最优的停止规则时，应在 $(d,s)$ 表上逆向回归拟合包含后续重新决策价值的继续价值函数，这属于第一级之外的扩展。
11. 部署用到的“$h^2$ 历史接 $h^1$”只出现在停止类中，占 $G_{\rm two}$ 训练请求的 1/6。生成尾若没有学好这种历史，停止后的 NLL 会升高；停止点标签直接测量停止后的 NLL，这一损失体现为 $\Delta_{\rm stop}$ 与 P4 变小，不进入 P1–P3。
12. 预测器对部分请求给出 $\Delta\hat\ell_d\ge0$ 时，策略族的价格点达不到全部 $r=2$ 的成本。主预算高于族的最高成本价格点时，严格同成本值由该点与强制全程 $r=2$ 端点混合得到，分到端点的文档的轮数与提示词无关，比较对象仍是可部署的随机化策略。报告各族在主预算处分到强制端点的文档比例。

## 12. 待用户确认的事项

1. 训练数据：通用文本 $10^8$ 与数学解答 $10^8$ token 的数据集名称、版本与许可，以及通用文本整篇监督的格式。
2. 评价与拟合数据：GSM8K 默认分桶，以及补足 20,000 个拟合请求的数学语料来源。
3. 实用门槛：沿用 0.005 nat/token，或改为相对门槛。默认确认集约 2,989 篇时，判定表以 0.8 的概率给出“达到门槛”需要真实效应约 0.0088（$m=4$，第 8.4 节）。
4. Q 的成本口径：只计 FLOPs（查询成本约为整次请求的 $5.9\times10^{-6}$，门控阈值接近零，门控主要在 H 与 Q 的决策之间选择），或把首 token 延迟计入成本（阈值变大，门控同时决定是否为查询付费）。
5. 是否保留单轮对照 $G_{\rm one}$（另需约 3.5 小时训练）。
6. 8×H200 节点的使用窗口，以及运行是否允许超过 24 小时。
7. 本方案与按行循环方案的关系：以本方案为执行依据，还是两者并行。
8. 块的定义：数学解答按行（超过 64 token 的行在 64 token 处切开），通用文本按句（超过 32 token 的句子在 32 token 处切开），见第 4.2 节。两种边界都只由已经输入的 token 判定，通用文本的分句规则按这一要求选定。
