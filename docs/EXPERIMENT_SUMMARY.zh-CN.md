# 循环深度控制实验汇总：v1 到 v4

本文汇总本仓库在 2026-10-11 至 2026-10-15 间完成的循环深度控制实验，范围从 v1 计划到 v4 设计。这些实验与仓库主体的路由算法包相互独立：实验代码不调用 Canopy-Jev，也不导入 `jev_routing`，只借用 Canopy-Jev 公开的 Dirichlet 留一策略梯度配方作为一个训练臂。

材料快照取自 2026-10-15 03:26 UTC 的原工作区。本分支第一次提交（`75746a7`）中的实验文件与快照逐字节一致，唯一的改动是把集群用户 ID 替换为 `<cluster-user>`（见第 8 节）。第二次提交按[实验依据审核](ARCHITECTURE_REVIEW.v4.zh-CN.md)修订了四份 v4 按行循环架构文档，并新增本文、审核文档与配置 `EXPERIMENT_CONFIG.v4-rowloop.json`；第 6.2 节描述的是修订前的快照版本。

全文损失单位是 nat/token，即计分 token 的平均负对数似然（Negative Log-Likelihood，NLL）。“改善”一律写作对照 NLL 减被评策略 NLL，正值表示被评策略更好。区间若无特别说明，是以文档为单位的配对自助法（bootstrap）95% 百分位区间，只反映文档抽样误差，条件于已经训练好的模型。“不放行”指先导或阶段判据未满足、协议按预先规定停止。

## 1. 研究主线与版本关系

各版本研究同一个问题：让模型在推理时按内容分配循环深度，在相同计算预算下取得比输入无关的固定日程更低的 NLL。

v1 到 v3.3 都在 Huginn-0125 上进行。Huginn-0125 是循环深度语言模型，由 2 层前置块、4 层可重复执行的循环核心和 2 层末端块组成，循环核心的执行次数在推理时可选。v4 转到 Qwen 系列模型，需要先把非循环模型改造成可循环执行。

版本之间的递进如下：

1. v2 在通用文本上每请求决定一次深度。先导发现预算 1 附近几乎没有可分配空间。
2. v3 与 v3.1 改为在 GSM8K 解答上逐行决定深度。冻结模型的第 0 阶段测到明确的空间，联合训练的控制器在先导中没有超过位置日程。
3. v3.2 把读出与共享训练拆成两个阶段。阶段一的读出未达门槛；追加实验用只差控制损失的匹配臂，测到控制梯度损害生成。
4. v3.3 在 3 张 A10 上做确认性实验。表示读出相对位置日程的增益在单侧检验下被检出，双侧 95% 区间含零，增益低于实用门槛。控制梯度经共享 AdamW 损害生成的结论在三个种子上成立；把控制梯度放进独立 AdamW 后，损害的点估计降到原来的约 22%，这一比值没有区间。
5. v4 有两条设计线，均未运行。

## 2. v1 与 v2：共享末端深度控制

### 2.1 设计

v2 检验共享末端机制：Huginn 末端两层同时负责预测下一个词和决定循环次数。在这两层上训练一组低秩适配（Low-Rank Adaptation，LoRA），生成损失与深度选择共用同一组参数。

基座固定为 `tomg-group-umd/huginn-0125` 版本 `bb6621b6`，3,564,976,800 个参数全部冻结。LoRA 覆盖两个末端块的 `Wqkv`、`proj`、`fc`、`proj` 四个投影，rank 8、alpha 16，共 1,536,000 个参数。深度读出是 4×5280 的线性层加偏置，共 21,124 个参数，在预热集上训练后冻结。

每个请求是 256 token 的窗口，前 128 token 为前缀，后 128 token 为计分目标。控制器读取前缀末位置的末端表示，在 $D\in\{4,8,16,32\}$ 中为整个目标段选一次循环核心执行次数。数据取 SmolLM-Corpus 的 fineweb-edu-dedup 分片，按规范化全文哈希分桶，清单共 8,640 篇。先导使用其中四个集合：预热集 1,024 篇、先导训练集 256 篇、先导校准集 64 篇、先导筛选集 384 篇。

成本按矩阵乘 FLOPs 计算，以冻结模型全用深度 16 的成本为 1。动态策略在 $D>4$ 时要把前缀续算到深度 $D$ 并重跑末端，计划成本因此含 0.014191 的控制额外成本：

$$
f_{\rm plan}(4,8,16,32)=(0.29708,\ 0.54558,\ 1.01419,\ 1.95141).
$$

四个训练臂只在梯度构成上不同：

| 臂 | 生成梯度 | 路由梯度 |
|---|---|---|
| E | 按读出概率加权的各深度生成损失 | 期望成本的精确梯度 |
| J | 同 E | 64 个 Dirichlet 样本的留一 score 梯度，即 Canopy-Jev 配方 |
| F16-A | 只用深度 16 的生成损失 | 无 |
| FMIX-A | 四个深度生成损失的平均 | 无 |

先导放行要求三项同时满足：技术检查全过；正式阶段的资源预测在上限内；“预热读出加零 LoRA”的探针相对静态参照的改善不低于 0.002，且单侧 95% 下界大于零。

v1 没有运行过模型，唯一执行的是 CPU 代数自检。v2 相对 v1 有三项主要改动：

1. 放行判据由“事后最优相对最佳静态混合的改善不低于 0.005，且 95% 下界大于 0.005”改为可预测性探针，理由是事后判据对噪声没有区分力。
2. 删除 S 臂。S 已含成本软标签，S 与 E 之差不等于“有无策略梯度”。
3. 训练文档由 2,048 篇增至 4,096 篇，以减少文档被记忆后成本差被压缩。

v2.1 是一次经用户批准的修订。首次实现检查中，BF16 的逐文档误差门槛未通过，修订为平均符号差门槛；64 篇上的合并平均差为 $+3.94\times10^{-5}$，95% 区间 $[-2.70\times10^{-4},\ +3.49\times10^{-4}]$。修订发生在先导训练之前，与最终判定无关。

### 2.2 先导结果

冻结模型在先导筛选集上的深度曲线为 2.6774、2.3010、2.2213、2.2176（深度 4、8、16、32）。预热集上相邻深度的平均收益依次为 0.3801、0.0796、0.0033。深度 8 到 16 收益大且各文档一致，深度 16 到 32 几乎为零。

| 量（先导筛选集 384 篇，预算 1） | 点估计 | 区间或下界 |
|---|---:|---|
| 探针相对冻结纯深度 16 的改善 | −0.00357 | 95% [−0.00674, −0.00142]；单侧 95% 下界 −0.00615 |
| 事后最优：用真实后缀逐文档选深度 | +0.0019 | 无 |
| 分半上界：前 64 个目标 token 选深度，后 64 个评价 | −0.0097 | 无 |
| E 动态策略相对自身静态策略 | −0.0032 | [−0.0057, −0.0014] |
| J 动态策略相对自身静态策略 | −0.0031 | [−0.0054, −0.0014] |

探针的两项放行条件都不满足，`decision` 为 `no_go`。四个臂的 LoRA 都带来小幅静态收益，E、J、F16-A、FMIX-A 依次为 +0.0006、+0.0007、+0.0017、+0.0016，区间都在零以上。

预算扫描是一项事后诊断：静态参照在被评估的同一筛选集上选出，没有区间，不参与判定。预算 0.35 处（深度 4 与 8 之间）事后上界为 0.0425，计入控制开销的分半上界为 0.0163；预算 1.0 处两者分别为 0.0019 与 −0.0097。

### 2.3 判定与可依赖的结论

先导不放行，协议按计划停止。有匹配对照支撑的结论有两条：

1. 预算 1 附近逐请求分配深度的空间很小。事后最优只有 0.0019，预热集复现为 0.0017。这个点估计与 0.002 门槛只差 0.0001，且没有区间，先导报告中“任何只依赖前缀的控制器都无法通过放行判据”的说法缺少区间支撑。
2. E、J 的动态路由在预算 1 下不带来收益。同一检查点上，动态策略比自身静态策略差约 0.003，区间整体在零以下。这一对比同时包含路由质量与控制开销计费。

先导报告第 8 节把亏损归因于控制开销，写为“预算 1 处控制开销造成约 0.0024 nat 的损失”；v3 与 v3.1 计划的设计原则表据此写成“1.4% 的控制开销造成 0.0024 nat 损失”。这个数来自一阶算式：

$$
x=\frac{0.0142}{f(16)-f(8)}=\frac{0.0142}{0.4686}=0.0303,
\qquad
x\times0.0796\approx0.0024.
$$

它描述的是一个随机把 3.0% 文档降到深度 8 的无信息控制器，没有“同一策略去掉开销”的对照。预算扫描中“计开销”与“不计开销”的比较才是单因素对照：预算 1 处，事后上界由 0.0024 降到 0.0019，分半上界由 −0.0098 变为 −0.0097。因此“控制开销本身超过可分配空间”尚未归因。v3 的设计原则引用了 0.0024，引用时需要带上这一限定。

## 3. v3 与 v3.1：按行深度控制

### 3.1 改动

v3 根据 v2.1 的停止结论改动四处：

1. 任务改为 GSM8K 参考解答。文本格式为 `Question: … Answer: …`，删去计算器标注与最终答案行，长度不超过 320 token。
2. 决策粒度改为解答的每一行。每行开始前，在上一行末位置读取已算出的末端表示，从 {4, 6, 8, 12, 16} 中选深度。题目段固定深度 16，不计入预算。
3. 预算改为 0.5，即全部解答行用深度 16 时成本的一半。五个深度的相对成本 $r(d)$ 依次为 0.301、0.418、0.534、0.767、1.000。
4. 控制读出复用已经算出的表示，额外开销为 $2\times5290\times5=52{,}900$ FLOPs，约为深度 8 单个位置的 1/570,000。

本线的主对照是位置日程 R：用 10 维位置特征 $\varphi$（行序号 one-hot 与上一行长度/50）做岭回归，预测各深度的每 token NLL，再按

$$
d_c=\arg\min_d\left\{\hat\ell_d(\varphi_c)+\nu\,r(d)\right\}
$$

选深度。R 只知道“第几行”与“上一行多长”，不读文本内容。

混合深度执行会在键值缓存（Key–Value cache，KV 缓存）中留下缺口。某一行用深度 12 时，此前用深度 6 的行在第 7–12 轮没有缓存。v3.1 用 634 行数据回归这一代价：

$$
\Delta\ell\approx-0.0032+0.0130\,s_c-0.0023\,e_c,
$$

其中 $s_c$、$e_c$ 是按历史位置平均的缺失轮数与超出轮数，两个系数的标准误为 0.0018 与 0.0010。每缺一轮约损失 0.013 nat/token。

### 3.2 第 0 阶段：冻结模型上的可分配空间

v3 的原始测量中，收益数字已被 v3.1 作废。作废原因包括：决策成本用到了尚未生成的当前行长度；用离线重放代替在线决策；题目段深度与静态对照不一致。保留的只有深度曲线：去掉答案行后，解答 NLL 在深度 4、6、8、12、16、24、32 依次为 1.637、1.222、0.998、0.868、0.843、0.838、0.840，深度 16 以后饱和。

v3.1 按正式语义在线重做，测试集 300 题：

| 预算 | 策略 | NLL | 实测相对成本 | 相对静态混合的改善 |
|---|---|---:|---:|---|
| 0.5 | 静态混合（深度 6 占 0.294，深度 8 占 0.706） | 1.0632 | 0.5000 | 无 |
| 0.5 | 位置策略 | 1.0290 | 0.5009 | 0.0342 [0.0276, 0.0408] |
| 0.5 | 表示策略 | 1.0273 | 0.4996 | 0.0358 [0.0291, 0.0426] |
| 0.5 | 问题级策略 | 1.0196 | 0.5102 | 0.0436 [0.0348, 0.0520] |
| 0.6 | 位置策略 | 0.9283 | 0.6027 | 0.0226 [0.0157, 0.0302] |
| 0.6 | 表示策略 | 0.9280 | 0.5984 | 0.0229 [0.0140, 0.0328] |

两点结论有对照支撑：

1. 冻结模型按行分配深度，相对统一深度混合有明确空间。预算 0.5 时位置策略改善 0.0342 [0.0276, 0.0408]，成本与静态混合相差在 0.2% 以内。
2. 冻结表示在位置之外的增益不可分辨。表示减位置在预算 0.5 为 0.0016 [−0.0036, 0.0069]，在预算 0.6 为 0.0003 [−0.0067, 0.0075]，区间都含零；区间上端高于 0.005，门槛大小的增益同样没有被排除。

问题级策略的 0.0436 含超出预算 2% 的部分，不能直接与另外两行比较。

### 3.3 先导：联合训练的控制器

先导在 RTX 5080 上训练四个臂，种子 17，373 篇训练文档，93 次更新。四个臂的深度读出都在预热后冻结，训练只更新末端 LoRA。E 与 J 让生成损失和控制损失同时更新这组 LoRA；SCHED-A 只按冻结位置日程选出的深度训练生成；FMIX-A 对五个深度均匀训练生成。R 在先导校准集上从候选池中选出，结果是 SCHED-A 的 LoRA 配它自己的位置日程。

在先导筛选集 505 篇上，E 相对 R 的改善为 −0.0064，95% 区间 [−0.0134, 0.0005]，单侧 90% 下界 −0.0110，逐篇标准差 0.0791，成本比 $C_E/C_R=1.0081$。放行要求点估计不低于 0.005 且单侧 90% 下界大于零，两项都不满足。

2×2 交叉评价把这一差距拆开。令 $\theta_S$、$\theta_E$ 为 SCHED-A 与 E 的 LoRA，$\pi_S$、$\pi_E$ 为各自的位置日程，$\pi_\mu$ 为 E 的读出规则。同一日程对同一文档给出相同深度序列，同一列的成本逐篇相同。下表中的差是前者减后者，正值表示前者 NLL 更高：

| 项 | 均值 | 95% 区间 |
|---|---:|---|
| $(\theta_E,\pi_\mu)-(\theta_S,\pi_S)$：E 与 R 之差 | +0.0064 | [−0.0005, 0.0134] |
| $(\theta_E,\pi_E)-(\theta_E,\pi_\mu)$：读出相对位置日程的改善 | +0.0051 | [−0.0014, 0.0116] |
| 参数项，固定 $\pi_S$ 或固定 $\pi_E$ | +0.0121 | [0.0107, 0.0136] |
| 日程项，固定 $\theta_E$ | −0.0005 | [−0.0023, 0.0013] |
| 交互项 | 0.0000 | [−0.0001, 0.0002] |

$(\theta_E,\pi_E)$ 与 $(\theta_S,\pi_S)$ 的总差 0.0116 全部落在参数项：固定任一日程，$\theta_E$ 都比 $\theta_S$ 高 0.0121，日程项与交互项与零无法区分。

读出相对位置日程的 +0.0051 不能作为增益证据。它的区间含零；E 与 E-static 的成本又相差 0.0027（0.5054 对 0.5028）。斜率取 E-static 两个端点的割线斜率 0.90 到 v3.1 计划第 2.4 节给出的上限 1.9 nat/单位成本，成本差折合 0.0024 到 0.0051，占 +0.0051 的 47% 到 99%。

读出饱和是本线的另一项发现。Dirichlet 平滑把概率限制在 [0.00200, 0.99198]，logit 比值上限为 6.2046。E 的读出在校准集上有 82.2% 的决策顶到上限，冻结模型为 83.1%。目标函数只在两水平成本差大于 0.521 时以顶点为最优；λ=1.5 时最优点落在顶点的行只占 0.17%，六个 λ 下为 0.12% 到 0.48%。单因素对照把原因指向优化：同一目标与数据下，读出预热的学习率由 0.003 降到 $3\times10^{-5}$，训练行的饱和比例由 80.2% 降到 0%。

### 3.4 判定

先导不放行。区间含零，结论是支持停止，不足以断定 E 劣于 R。

“控制损失拖慢生成”在本线没有匹配对照。$\theta_E$ 与 $\theta_S$ 的训练同时差在生成加权（按读出概率加权对按日程选深度）和控制损失（有对无），四个臂中没有只差控制损失的一对。

J 与 E 的比较同样无法解读。E 相对 J 的改善为 +0.0033 [0.0013, 0.0054]，而 J 的预算混合含一个权重 0.0145、NLL 1.3600 的断崖分量，单这一项就把 J 的混合 NLL 抬高约 $0.0145\times(1.3600-0.9218)\approx0.0064$。先导报告自己也写明没有给出 J 与 E 的干净比较。

## 4. v3.2 与追加实验：拆开读出与共享训练

### 4.1 阶段一：冻结生成参数后的读出

v3.2 把 v3.1 混在一起的两个问题分开。阶段一把生成参数冻结在 $\theta_S$（SCHED-A 种子 17 的 LoRA），只训练读出，检验

$$
g_{\rm head}=L(\theta_S,\pi_R)-L(\theta_S,\pi_{\rm head}).
$$

两边的生成参数、文档与教师强制序列相同，差别只来自决策规则。新读出针对 v3.1 的饱和改用三项做法：未平滑概率上的软标签交叉熵、输入逐维标准化、全批量 L-BFGS。拟合数据为 4,111 篇文档，共 14,703 个计分行、57,071 个样本。

在阶段一筛选集 367 篇上，$g_{\rm head}=+0.0038$，95% 区间 [−0.0039, 0.0116]，单侧 90% 下界 −0.0012，成本比 1.0051，判定 `fail`。读出比 R 多用 0.0025 的相对成本，按校准集斜率 1.29–1.75 折算，同成本改善落在 [−0.0006, +0.0006]。

诊断项中，表示岭回归相对 R 为 +0.0058 [−0.0009, 0.0127]。它是多个诊断中点估计最大的一个，属于事后选取，又比 R 多用 0.0020 成本。按回执中三个在线点的斜率 1.01–1.14 折算，同成本改善约为 +0.0035 至 +0.0038（阶段一报告按四位小数的斜率写作 +0.0035 至 +0.0037），不能作为放行依据。R 相对均匀深度的改善为 +0.0141 [0.0081, 0.0199]。

### 4.2 追加实验：只差控制损失的匹配臂

追加实验经用户授权，从 $\theta_S$ 出发训练两个臂。E-G 只优化生成项；E-C 优化生成项加控制项。两臂的初始化、冻结读出、数据、种子、文档排列、历史抽样规则与优化器配置全部相同，在桶 70–74 的 373 篇上训练 2 个 epoch、93 次更新，在阶段二筛选集 378 篇上评价。

| 量 | 定义（正值的含义） | 点估计 | 95% 区间 |
|---|---|---:|---|
| $h_{\rm gen}$ | 同一固定日程下 E-C 减 E-G 的 NLL（E-C 生成更差） | +0.0016 | [0.0005, 0.0028] |
| $g_{\rm joint}$ | E-G 减 E-C 的部署 NLL（E-C 更好） | +0.0038 | [−0.0025, 0.0101] |
| $g_B$ | 严格同成本下的 $g_{\rm joint}$ | +0.0031 | 不可估（4.07% 的重采样夹逼失败） |

$h_{\rm gen}$ 是这条研究线上第一个有单因素对照、区间不含零的机制结论：在同一固定日程、同一深度序列与成本下，加入控制损失使生成 NLL 升高 0.0016。结论限于从 $\theta_S$ 继续训练 93 次更新、单训练种子、冻结同一读出。整体策略差 $g_{\rm joint}$ 的区间含零，不足以断定 E-C 优于 E-G。

梯度诊断在同一优化器状态上比较单步更新。生成梯度与控制梯度的余弦接近零，四个快照上在 −0.0058 到 +0.0031 之间。加入控制梯度后，固定诊断批次上的单步生成下降量在快照 0、23、46 依次减少 35.1%、30.9%、22.3%，在快照 92 增加 22.1%。

数学审核给出了余弦为零仍会减少下降量的机制。AdamW 第一步在 $\epsilon\to0$ 时退化为逐元素符号更新：

$$
\Delta_G=-\eta\,\operatorname{sign}(g_G),
\qquad
\Delta_{G+Q}=-\eta\,\operatorname{sign}(g_G+g_Q).
$$

生成损失的一阶变化是 $g_G^\top\Delta$，两种更新之差为

$$
\begin{aligned}
g_G^\top(\Delta_{G+Q}-\Delta_G)
&=\eta\sum_i\left[|g_{G,i}|-g_{G,i}\operatorname{sign}(g_{G,i}+g_{Q,i})\right]\\
&=2\eta\sum_{i:\ \operatorname{sign}(g_{G,i}+g_{Q,i})\ne\operatorname{sign}(g_{G,i})}|g_{G,i}|
\ \ge 0.
\end{aligned}
$$

上式假设各坐标的 $g_{G,i}$ 与 $g_{G,i}+g_{Q,i}$ 都不为零；若某坐标的和恰为零，符号取 0，该坐标贡献 $\eta|g_{G,i}|$，不等式仍成立。只要控制梯度翻转了某些坐标的符号，生成损失的一阶下降量就减少，与两个梯度的余弦无关。这一推导只覆盖第一步，此后 AdamW 的动量不再为零。审核给出的正交例 $g_G=(1,1)$、$g_Q=(-2,2)$ 中，$g_G^\top\Delta$ 由 $-2\eta$ 变为 0。

### 4.3 判定

阶段一不放行，按计划停止，没有进入零 LoRA 初始化的阶段二。追加实验的诊断门槛未达到，不推翻阶段一的判定。

引用追加实验时需要同时带上两项记录问题：

1. 追加实验中的两个交叉格是 v3.1 交叉评价的重跑，结果与 v3.1 回执一致到 15 位有效数字，不是新数据。
2. 预先声明次要统计量的配置文件写于两臂训练结束之后、筛选集首次读取之前。“训练前固定”不成立；“读取筛选集前固定”有文件修改时间作旁证。

## 5. v3.3：3×A10 确认性实验

### 5.1 设计

v3.3 在一次 Slurm 作业中完成两个实验，使用 3 张 NVIDIA A10，墙钟 5 小时 35 分，报告记 16.8 GPU 小时（计划 28.8，上限 40）。确认集 2,397 篇，由 GSM8K 训练集桶 50–64 的 1,087 篇与 GSM8K 测试集 1,310 篇组成；拟合集 3,024 篇（桶 10–49），校准集 612 篇。

实验 A 固定 $\theta_S$，比较两个岭回归读出。R 的输入是 10 维位置特征；H 再加上决策位置的 5,280 维表示 $\tilde z$ 和上一行深度 one-hot，共 5,295 维。两者使用同一决策规则与同一 KV 修正项。

主统计量在严格同成本（strict common cost）下计算。对每个策略族，取确认集上成本夹住预算 $B$ 的相邻两点 $(c_-,L_-)$、$(c_+,L_+)$：

$$
L_a(B)=L_-+\frac{B-c_-}{c_+-c_-}\,(L_+-L_-).
$$

它等于以概率 $w=(B-c_-)/(c_+-c_-)$ 在文档层面执行高成本端点的混合策略的期望损失，期望成本恰为 $B$。每次自助重采样都重算端点与权重；任一次重采样夹不住 $B$ 时，区间记为不可估。主检验是 $g_A=L_R(0.5)-L_H(0.5)$ 的单侧 95% 下界大于零，实用门槛为 0.005。

实验 B 固定日程 $\pi_F$，从 $\theta_S$ 出发训练三个臂，每臂三个种子（17、23、31）：

| 臂 | 梯度与优化器 | 裁剪对象 |
|---|---|---|
| G | 生成梯度 $g_G$ 进入一个 AdamW | $g_G$ |
| C | $g_G+g_Q$ 进入一个 AdamW | 两项之和 |
| D | $g_G$ 与 $g_Q$ 各进入一个 AdamW，参数更新为两个位移之和 | 两项各自 |

B1 检验 $h_C=L(\theta_C,\pi_F)-L(\theta_G,\pi_F)>0$，即控制梯度进入共享 AdamW 会损害生成；B2 检验 $\Delta_{CD}=h_C-h_D>0$，即独立优化器状态减轻损害。两项按 Holm 法控制族错误率。

### 5.2 结果

实验 A（2,397 篇）：

| 比较 | 预算 | 点估计 | 双侧 95% 区间 | 单侧 95% 下界 | 单侧 p |
|---|---|---:|---|---:|---:|
| $g_A=L_R-L_H$ | 0.5 | +0.00191 | [−0.00017, 0.00396] | +0.00017 | 0.0355 |
| $g_A$ | 0.6 | +0.00243 | [0.00007, 0.00488] | +0.00044 | 0.0228 |
| 均匀深度减 R | 0.5 | +0.01579 | [0.01404, 0.01757] | +0.01433 | <0.0001 |
| 均匀深度减 H | 0.5 | +0.01771 | [0.01590, 0.01954] | +0.01617 | <0.0001 |
| $g_A$，桶 50–64（1,087 篇） | 0.5 | +0.00255 | [−0.00060, 0.00573] | −0.00008 | 0.056 |
| $g_A$，GSM8K 测试集（1,310 篇） | 0.5 | +0.00147 | [−0.00121, 0.00409] | −0.00081 | 0.145 |

所有比较的夹逼失败比例都为 0。R 与 H 的岭系数分别为 100 与 $10^5$，都不在网格边缘。

实验 B（固定日程 $\pi_F$，2,397 篇）：

| 量 | 合并估计 | 文档 bootstrap 95% 区间 | 种子 17 / 23 / 31 | 种子 t 区间（自由度 2） |
|---|---:|---|---|---|
| $h_C$ | +0.00168 | [0.00134, 0.00203] | +0.00117 / +0.00203 / +0.00183 | [0.00056, 0.00279] |
| $\Delta_{CD}$ | +0.00130 | [0.00109, 0.00151] | +0.00130 / +0.00144 / +0.00117 | [0.00096, 0.00165] |
| $h_D$ | +0.00037 | [0.00003, 0.00073] | −0.00013 / +0.00058 / +0.00067 | [−0.00071, 0.00146] |

B1、B2 的自助 p 值都小于 1/10,000，在 Holm 法下均拒绝零假设；$h_D$ 不作检验。

### 5.3 判定与限定

实验 A 判为“表示读出有增益，增益低于实用门槛”，依据是单侧 95% 下界 +0.00017 大于零、区间上端 0.0040 小于 0.005。这个检出处在边缘：

1. 单侧 p 为 0.0355，双侧 95% 区间 [−0.0002, 0.0040] 含零，按双侧口径只能写不足以断定。
2. 两个子集单独看都未检出，合并后才越过检验线。
3. H 与 R 的输入相差表示 $\tilde z$ 与上一行深度 one-hot 两项，岭系数与拟合行数也不同（$10^5$ 对 100，41,839 行对 10,787 行），这一比较不是单因素对照。

均匀深度减 R 的 0.0158 与均匀深度减 H 的 0.0177 之比为 0.89，报告据此写“约 89% 由位置信息提供”。这个比值没有区间，而且 R 同时含位置特征、按行分配与 KV 修正，只能作描述。

实验 B 的 B1、B2 都成立，三个种子同号，计划据此规定“共享训练采用分开的优化器状态”。$h_C$ 是严格的单因素结论。$\Delta_{CD}$ 的方向有数据支持，但 C 与 D 除优化器状态外还差两处：裁剪对象不同；D 的平均参数位移约为 G 的 1.39 倍，C 约为 1.0 倍。“约 77% 的损害来自状态共享”是点估计之比

$$
\frac{\Delta_{CD}}{h_C}=\frac{0.0013026}{0.0016768}=0.777,
$$

没有区间，逐种子依次为 111%、71%、64%。剩余损害 $h_D$ 的种子 t 区间含零，不足以断定是否存在。

部署次要量只来自种子 17 与交叉熵读出。在 GSM8K 测试集上，C 与 D 都比只训练生成的 G 好，差值为 +0.0040 [0.0016, 0.0064] 与 +0.0053 [0.0029, 0.0077]。这一结果混合了生成参数差与冻结读出对各自表示的失配，没有多种子检验。

实验 B 的结论限于从 $\theta_S$ 出发的 93 次更新，不推广到零 LoRA 初始化或更长训练。三个种子只改变文档排列与历史抽样，初值都是 $\theta_S$，训练文档也是 $\theta_S$ 训练过的同一批 373 篇，种子区间不含初始化与数据抽样的方差。

## 6. v4：两条设计线

### 6.1 Qwen3.8-27B 计划（`jev-v4`）

这份计划由 `EXPERIMENT_PLAN.v4.zh-CN.md`（3,146 行）与 `EXPERIMENT_CONFIG.v4.json` 组成，状态为“设计，未运行”。基座是冻结的 Qwen3.8-27B 文本主干：64 层，宽度 5,120，门控 DeltaNet 与全注意力按 3:1 交替，稠密 SwiGLU，共 26,895,998,464 个参数。

计划让一个决策器决定三类动作：

1. 循环：第 48–59 层组成循环段，每 token 或每块选 1–4 次迭代。
2. 专家：基座是稠密模型，“专家”落实为数学领域 LoRA 生成尾。
3. 工具：BM25 检索 DPR 段落，在 PopQA 上按题决定是否检索。

执行分为 S0 到 S10 十一个阶段，每个阶段设放行判据（G0 到 GU）；硬件利用率 0.25 时，全计划约 523 GPU 小时（不含条件阶段 S8 的 0–20 GPU 小时），再去掉种子 23、31 的 S9 约 263 GPU 小时。计划把 S3 的循环改造门槛 G1 列为最难通过的判据。12 项待用户确认事项仍列为待确认，17 项下载中 16 项尚未获得许可。

### 6.2 按行循环架构（Qwen3-30B-A3B）

这条线由四份文档组成：架构正文 `ARCHITECTURE.v4.zh-CN.md`、流程与训练对比 `ARCHITECTURE_FLOW.v4.zh-CN.md`、数学验证 `ARCHITECTURE_MATH.v4.zh-CN.md` 与一天实验方案 `EXPERIMENT_PLAN.v4-one-day.zh-CN.md`，另有微型数值核验 `ARCHITECTURE_MATH_CHECK.v4.json` 及其脚本。本节按快照版本描述；本分支第二次提交已按审核文档修订这四份文档，协议 ID 定为 `jev-v4-rowloop`，D 拆为 D-reg 与 D-ec 两个变体，并增加 GL1、GL2 两道门槛。

基座是 Qwen3-30B-A3B-Instruct-2507：48 层，隐藏维 2048，每层 128 个前馈专家、每 token 激活 8 个。第 0–31 层为共享前缀，第 32–43 层为循环段，两个生成尾 $T_0$、$T_1$ 都来源于第 44–47 层，共享只读基座权重，各有独立的 LoRA 与 KV 缓存。每行开始前选择动作 $(r,e)\in\{1,2,3,4\}\times\{0,1\}$，即循环次数与生成尾。

控制器有三种：执行状态基线 $R_4$ 只读 26 维位置与执行状态；表示控制器 $H_4$ 再加 2048 维首轮出口；四层决策分支 $D_4$ 让首轮出口流经过独立的四层网络后再读出。训练分两步：先用 $2\times10^8$ token 训练循环生成器 $G_{\rm loop}$ 与普通 LoRA 对照 $G_{\rm plain}$，冻结后再拟合控制器。数学验证的 9 项微型核验全部通过，对象是宽度为 4 的确定性小模型，不是 Qwen 执行器。

## 7. 跨版本结论

### 7.1 可分配空间取决于预算点和决策粒度

v2.1 在预算 1、每请求一次决策时，事后最优只有 0.0019；同一数据上预算 0.35 的事后上界为 0.0425。深度 8 到 16 的收益大且各文档一致，深度 16 到 32 几乎为零，所以预算 1 附近没有值得交换的深度。

v3 把预算移到 0.5、把决策粒度缩到每行。v3.1 按正式语义重做的第 0 阶段中，冻结模型的位置策略相对统一深度混合改善 0.0342 [0.0276, 0.0408]；v3.3 在 2,397 篇确认集上得到均匀深度减 R 为 0.0158 [0.0140, 0.0176]。两组数字在不同集合与不同 $\theta$ 上测得，方向一致，按行分配深度的收益稳定存在。R 同时含位置特征、按行分配与 KV 修正，“收益主要来自位置信息”只是描述，没有单因素对照支持（第 5.3 节）。

### 7.2 表示在位置信息之外的增益

四次测量的结果如下：

| 测量 | 点估计 | 区间 | 成本对齐 |
|---|---:|---|---|
| v3.1 第 0 阶段（冻结模型，300 题） | +0.0016 | [−0.0036, 0.0069] | 预算对齐 |
| v3.2 阶段一读出（367 篇） | +0.0038 | [−0.0039, 0.0116] | 多用 0.0025 成本，折算后约为零 |
| v3.2 表示岭回归诊断（367 篇） | +0.0058 | [−0.0009, 0.0127] | 多用 0.0020 成本，折算后约 +0.0035 至 +0.0038 |
| v3.3 实验 A（2,397 篇） | +0.0019 | [−0.0002, 0.0040] | 严格同成本 |

前三次测量的区间上端（0.0069、0.0116、0.0127）都高于 0.005，没有排除门槛量级的增益。其中 v3.2 表示岭回归的点估计 +0.0058 高于 0.005，但它多用了成本，折算到同成本后约为 +0.0035 至 +0.0038。v3.1 先导中读出相对位置日程的 +0.0051 同样成本未对齐、区间含零（第 3.3 节）。

只有 v3.3 的严格同成本检验给出上端低于 0.005 的区间，且只达到单侧检出。在 Huginn、冻结 $\theta_S$、预算 0.5 的条件下，表示读出带来的增益小于 0.005 nat/token，这一点由 v3.3 提供确认性证据。

### 7.3 控制梯度进入共享优化器状态会损害生成

v3.1 的参数项 +0.0121 把生成加权与控制损失两个因素混在一起，无法归因。v3.2 追加实验用只差控制损失的匹配臂测得 $h_{\rm gen}=+0.0016$ [0.0005, 0.0028]，v3.3 在三个种子上复现为 $h_C=+0.00168$ [0.00134, 0.00203]。后两次是单因素对照，点估计接近；v3.1 的 0.0121 约为它们的 7 倍，混有生成加权的差异，不能直接比较。

AdamW 首步的符号更新推导给出余弦接近零时损害仍会出现的机制，推导只覆盖第一步（第 4.2 节）。D 臂把控制梯度放进独立的 AdamW，生成损害的点估计降到 $h_D=+0.00037$，种子 t 区间 [−0.00071, 0.00146] 含零。C 与 D 还差裁剪对象与参数位移，降幅不能全部归因于优化器状态；D 臂仍与生成共享 LoRA 参数，共享参数本身是否造成损害没有单独检验。

### 7.4 评价方法的演进

同成本的处理逐版收紧。v3.1 与 v3.2 允许成本比在 [0.98, 1.02] 内浮动；在预算 0.5 附近，这相当于约 0.01 的相对成本，按 1.06–1.75 nat/单位成本的斜率折合 0.011–0.018 nat/token，大于待检验效应。v3.3 改用严格同成本插值，夹逼失败时报告不可估。

因果归因的要求也逐版收紧。v3.1 的归因对照同时改变两个因素，v3.2 追加实验和 v3.3 实验 B 引入只差一个因素的匹配臂。v3.3 还把主检验改为单侧 95% 下界并分别给出两个方向的结论；引用 v3.3 实验 A 时，需要同时给出单侧与双侧两种口径。

### 7.5 尚未回答的问题

以下问题在现有材料中没有答案：

1. 零 LoRA 初始化或更长训练下，控制梯度的损害有多大。v3.3 实验 B 只覆盖从 $\theta_S$ 出发的 93 次更新。
2. 联合训练对部署效果的总影响。v3.3 只有种子 17、交叉熵读出的部署次要量，C 与 D 优于 G。
3. Huginn 上的效应量能否迁移到 Qwen。Qwen 不是按循环方式预训练的，循环改造本身是否带来收益尚未测量。
4. 问题级分配深度的同成本收益。v3.1 的问题级策略超预算 2%，同成本诊断数字没有回执。

## 8. 溯源与记录问题

回执与配置之间有四类记录问题，影响能被独立复核的范围：

4. 本分支把 18 个文件中的集群用户 ID 替换为 `<cluster-user>`，涉及 v3.3 的配置、计划、slurm 输出、13 份阶段回执、`verify.json` 与 `scripts/a10/v33.sbatch`。替换前 v3.3 配置的 SHA256 前 16 位为 `75b4dff2f0462e01`，替换后为 `48375143ae484ac9`；两者都不同于回执记录的运行前哈希，代码哈希不受影响。回执与代码默认参数中的本机 Windows 路径保留原样，修改代码会破坏代码哈希。
